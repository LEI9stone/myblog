# 非暴力沟通阅后感

最近一直在读《非暴力沟通》，原因是我发现自身的沟通方式存在很大问题。无论是对家人、对朋友、对同事，和他们在沟通的过程中都存在很大的问题。而听到或看到一些不符合我心意的事情，我自身往往会情绪激动，音量变大，大吼大叫。所以我一直渴求能找到一种能让自己平和沟通的方式，无论在面对何种情况或境地下，都能用心感受和倾听自身以及他人的感受和需要。用不带主观评判、不带情绪化的方式进行沟通。

## 自己一直存在的问题

不知从何时起，亦或是从记事起吧。面对一些不符合自身心意、不符合我预期的事情，我往往会情绪激动，瞬间气血上脑，失去理智。由于一直无法改变这种现象，所以给我的生活带来了很多麻烦。

特别是在工作后，我的感受更加深刻。由于自己的这种脾气秉性，由于意见不同往往会和同事发生争吵，而争吵的后果是双方的身心具伤。事后冷静下来，我会后悔自己刚才的行为，也会和同事道歉，表达对刚才沟通过程中种种的歉意。所以我意识到自己不能再这样了，如果一直无法冷静的沟通，去观察和感受双方的需要，去倾听和理解对方的请求，那么我将会一直在这种**遇事冲动 ———— 情绪激动 ———— 大吼大叫 ————— 后悔 ————— 道歉** 循环中。我越来越希望自己能跳出这种循环，找到让自己能深刻观察事情的发展、充分感受双方的需要，进而冷静表达自己的观点。

我希望自己能今后不再因为语言的暴力而去伤害他人、家人。在面对家人时，特别是父母提出不同的见解时，我往往会下意识地否定他们的观点，进而用更大的音量来试图说服他们。但是这种行为更像封建主义专制主义，是对家人的压迫。所以，我希望自己不要再通过语言来伤害家人，我希望能更好的和父母、老婆、孩子进行友好的沟通，从而增进家人之间的感情。

## 《非暴力沟通》核心四要素

反复阅读《非暴力沟通》，总结下来需要吃透书中的四个核心要素，需要自己在生活中能运用自如，必须将这四个要素训练成自己的沟通回路。在遇到任何事情时，都要通过这四要素来进行有效沟通。

这四要素为：**`观察`、`感受`、`需要`、`请求`**。

| 步骤 |                核心要点                |                               示例对比                               |
| :--: | :------------------------------------: | :------------------------------------------------------------------: |
| 观察 |  客观描述事实，不添加评价、判断或指责  | ❌ "你总是迟到，从不尊重我"<br />✅ "你今天比约定时间晚到了 30 分钟" |
| 感受 |  表达自己的真实情绪，区分感受与想法。  |       ❌ "我觉得你不重视我"<br />✅ "我感到很焦虑，也有些失望"       |
| 需要 | 识别感受背后的核心需求（普遍人类需求） |       ❌ "你应该准时"<br />✅ "因为我需要可靠和尊重我们的约定"       |
| 请求 |    提出具体、可操作的请求，而非命令    |      ❌ "以后不准迟到"<br />✅ "下次见面能不能提前 10 分钟到？"      |

我认为使用这四步法将是有效沟通的关键。而这四步法让我想到了**“三思而后行”**这句论语。充分观察事情的发展、感受自身及对方的需要后，通过再三思考来权衡后果，然后提出具体的请求。这将使沟通更加有效，也能促进双方的情感交流。

### 关键应用场景

非暴力沟通适用于几乎所有人际互动场景：

- **亲密关系**：改善夫妻、亲子间的沟通质量，减少争吵
- **职场沟通**：提升团队协作效率，化解同事、上下级矛盾
- **家庭教育**：培养孩子的情绪管理能力与同理心
- **冲突调解**：帮助解决个人、群体甚至国际间的分歧
- **自我对话**：学会倾听内心声音，减少自我批评，提升自我接纳

使用非暴力沟通的四要素，能让我们跳出指责、评判、回避的沟通陷阱，学会既真诚表达自己，又尊重、理解他人。它强调的不是 "赢" 得争论，而是通过共情建立连接，找到满足双方需求的解决方案，最终实现 "双赢"。

## 我将如何在日常生活中践行非暴力沟通

1. 每日复盘，在睡前可以记录下这一天中和他人沟通的场景，分析自己是否使用了非暴力沟通的四要素，是否存在需要改进的地方。
2. 事后复盘，在前期运用非暴力沟通四要素可能无法收发自如，在遇到情绪起伏过大的事情后，需要事后立即进行复盘。将双方的沟通场景进行文字复述，分析是否使用了非暴力沟通的四要素，还需要如何改进才能达到更好的沟通效果。
3. 每日冥想，躺在床上后可以在脑海中快速过一遍今天的所有事情，分析自己是否使用了非暴力沟通的四要素，是否存在需要改进的地方。
4. 自我鞭策，我应该每天进行自我对话。比如今天需要完成的事情是否全部都完成了，如果未完成是什么原因导致的。在自我对话的过程中需要使用非暴力沟通的四要素来深入内心的需要，从而减少自我批评，而不至于陷入自我否定、自我摆烂的循环中，进而彻底摆烂、内耗。

### 每日复盘

这是NVC新手入门最有效的打底方法，文字化的复盘能把你「下意识的暴力沟通」转化为「有意识的觉察」，是形成肌肉记忆的核心动作，完美匹配四要素的刻意练习。

#### 把「纠错式」改成「四要素正向拆解」，杜绝自我批判

新手最容易踩的坑：复盘写成检讨书，比如“我今天又乱发脾气了，又评判别人了，做得太差了” ———— 这本身就是违背NVC的道德评判，会让复盘变成新的内耗。

建议固定无评判的复盘模版，严格贴合四要素：

:::info
```mermaid
flowchart LR
A[客观场景] --> B[我当时的\n原话/表达]
B --> C[符合/偏离\n NVC 的点]
C --> D[我当时的真实感受\n + 未被满足的需要]
D --> E[重来一次：用四\n要素表达的版本]
```

- **客观场景** → 只写可核对的事实，不贴道德标签
- **原话/表达** → 如实记录自己说了什么
- **符合/偏离** → 对照四要素，标出可改进处
- **感受与需要** → 命名情绪，并连到未满足的需要
- **四要素重述** → 用「观察 - 感受 - 需要 - 请求」再写一版
:::

#### 控制复盘量级，拒绝完美主义

不要复盘全天所有沟通，新手每天只挑 1 ~ 2 个最有代表性的场景（比如有情绪波动、沟通卡壳、发生冲突的场景）即可，否则会变成沉重的负担，很难长期坚持。

#### 必须补充「正向记录」

不经要记待改进的内容，一定要加一栏「今天那一次沟通用了NVC，带来了什么好结果」。正向强化比反复纠错，更能帮你快速把NVC变成本能的沟通习惯。

### 静思己过复盘

这个设计非常精准，完全抓住了NVC练习的核心场景：人在情绪上头的时，最容易陷入评判、指责、回避的暴力沟通，即使复盘能最快帮你建立「情绪触发 - 行为觉察」的链路，是新手突破“道理都懂，遇事就忘”的关键。

#### 先做「情绪急救」，再做复盘

如果情绪还没平复，立刻复盘很容易变成翻旧账、自我攻击，或是对他人的二次评判，完全偏离NVC的核心。

正确顺序：先停下来，用1~2分钟做自我连接（只做两件事：说出自己的真实感受、找到感受背后的需要，比如“我现在很愤怒，是因为我需要被尊重、被看见”），等情绪回落、恢复理性后，再做文字复盘。

#### 复盘要「双向拆解」，不要只盯着自己纠错

不要值分析自己有没有用四要素，一定要加一个环节：用NVC的视角拆解对方的表达 ———— 对方的话里，他的观察是什么？他藏在指责/抱怨背后的感受和未被满足的需要是什么？

这一步能帮自己跳出“我没有做错”的自我审视，真正建立NVC的共情思维，而不是把四要素变成一套束缚自己说话的条条框框。

#### 收尾要落地「最小行动预案」，而非空泛的改进承诺

复盘结尾不要只写“下次要好好说话”，要写清楚 **「下次遇到同类场景，我的第一句开口要说什么」**。

比如把“下次不要指责伴侣晚归”，落地成“下次遇到他晚归，我第一句说：‘你今天比约定时间晚了2小时到家，我很担心，也有点失落，我需要安全感和我们约定好的陪伴，下次能不能提前和我说一声？’“，把复盘成果变成可直接执行的话术，下次遇事就不会脑子空白。
