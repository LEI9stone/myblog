# 非暴力沟通每日复盘模板

**【模板核心原则】**

- 每日仅复盘1~2个核心沟通场景，不做全天全量复盘，避免执行负担；
- 先写正向记录，再做优化拆解，绝对禁止自我批评、写检讨书式复盘；
- 全程锚定NVC「观察 - 感受 - 需要 - 请求」四要素，区分评判与事实、想法与感受。

## 完整示例

- 今日NVC 正向践行记录(必填，先写)
    - 客观场景：下属提交的报表有3处数据错误
    - 我的NVC表达：”这份报表里有3处数据和原始凭证对不上，有点着急，因为这甲方做结算，需要数据零误差，你今天下午3点前修改好再给我可以吗？“
    - 结果：下属没有抵触，立刻核对修改，提前完成了提交
- 场景复盘
    - 客观场景/观察：晚上和妈妈打电话，她连续3次催我早点结婚，我中途挂了电话
    - 我当时的原话/行为：”你天天催，烦不烦啊，我的事不用你管”，说完直接挂了电话
    - NVC 匹配/ 偏离分析
        - 无符合四要素的点
        - 完全偏离：用了评判（天天催）、指责（烦不烦），没有表达自己的感受和需要，也没有提出具体请求。
    - 背后的感受与需要
        - 感受：烦躁、委屈、有压迫感
        - 需要：我需要边界感、被尊重、被理解我的人生节奏
    - NVC优化版表达
        - ”妈，你今天打电话3次提到了让我早点结婚，我听了之后有点烦躁，也有点委屈，我已经是成年人了，需要自己的人生节奏被尊重，也希望你能多关心我过得开不开心，而不是只催我结婚，以后我们打电话能不能先不聊这个话题呀“
    - 同类型场景避坑提醒
        - 下次妈妈在催婚，先深呼吸，不立刻反驳，先说出自己的感受，而不是直接指责
