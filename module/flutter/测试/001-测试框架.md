# Jest / Vitest vs `flutter_test`

Web 里常用 Jest 或 Vitest 做单元测试、组件测试和快照测试。

Flutter 里官方测试基础是：

```dart
flutter_test
```

它支持：

```text
unit test
widget test
golden test
```

可以这样映射：

| Jest / Vitest         | Flutter                         |
| --------------------- | ------------------------------- |
| `test()` / `it()`     | `test()` / `testWidgets()`      |
| `expect()`            | `expect()`                      |
| unit test             | `test` package / `flutter_test` |
| component test        | widget test                     |
| snapshot test         | golden test                     |
| mock function         | mocktail / Mockito              |
| fake timers           | `fake_async`                    |
| setup/teardown        | `setUp` / `tearDown`            |
| jsdom                 | Flutter test environment        |
| React Testing Library | WidgetTester                    |

---

## 1. Web Jest/Vitest

Web：

```ts
test('adds numbers', () => {
  expect(add(1, 2)).toBe(3);
});
```

组件测试：

```tsx
render(<Button>Submit</Button>);
expect(screen.getByText('Submit')).toBeInTheDocument();
```

---

## 2. Flutter unit test

Dart：

```dart
import 'package:flutter_test/flutter_test.dart';

void main() {
  test('adds numbers', () {
    expect(add(1, 2), 3);
  });
}
```

`test()` 用于普通 Dart 逻辑测试：

```text
formatter
mapper
repository fake
calculator
validator
state reducer
```

---

## 3. Flutter widget test

```dart
testWidgets('shows submit button', (tester) async {
  await tester.pumpWidget(
    const MaterialApp(
      home: Scaffold(
        body: Text('Submit'),
      ),
    ),
  );

  expect(find.text('Submit'), findsOneWidget);
});
```

`testWidgets()` 类似 Web component test。

它通过：

```dart
WidgetTester
```

构建 Widget、触发交互、断言 UI。

---

## 4. 用户交互测试

Web：

```ts
await user.click(screen.getByText('Submit'));
```

Flutter：

```dart
await tester.tap(find.text('Submit'));
await tester.pump();
```

输入：

```dart
await tester.enterText(
  find.byType(TextField),
  'keyword',
);
await tester.pump();
```

等待动画/异步：

```dart
await tester.pumpAndSettle();
```

---

## 5. Finder

React Testing Library：

```ts
screen.getByText('Submit');
screen.getByRole('button');
```

Flutter：

```dart
find.text('Submit')
find.byType(ElevatedButton)
find.byKey(const ValueKey('submit_button'))
find.byIcon(Icons.search)
```

常见断言：

```dart
expect(find.text('Submit'), findsOneWidget);
expect(find.byType(ProductCard), findsNWidgets(3));
expect(find.text('Error'), findsNothing);
```

---

## 6. Mock

Jest：

```ts
const fn = vi.fn();
expect(fn).toHaveBeenCalled();
```

Flutter 常用：

```text
mocktail
Mockito
Fake class
```

很多时候 Fake 比 Mock 更简单：

```dart
class FakeProductRepository implements ProductRepository {
  @override
  Future<List<Product>> fetchProducts() async {
    return [fakeProduct];
  }
}
```

---

## 7. Snapshot vs Golden

Jest snapshot：

```ts
expect(component).toMatchSnapshot();
```

Flutter Golden Test：

```dart
await expectLater(
  find.byType(ProductCard),
  matchesGoldenFile('goldens/product_card.png'),
);
```

Golden Test 是图像级对比，更接近视觉回归测试。

---

## 8. 常用命令

Web：

```bash
npm test
vitest
jest
```

Flutter：

```bash
flutter test
```

指定文件：

```bash
flutter test test/product_card_test.dart
```

生成覆盖率：

```bash
flutter test --coverage
```

---

一句话理解：

```text
Jest/Vitest 是 Web/JS 测试工具；
flutter_test 是 Flutter 官方测试基础。
普通逻辑用 test，
Widget UI 用 testWidgets + WidgetTester，
视觉快照用 golden test。
```
