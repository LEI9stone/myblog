# Local State vs Widget State

Web 里的 Local State 通常指只属于当前组件或局部 UI 的状态，比如展开/收起、输入框临时值、hover、选中 tab。

Flutter 里对应的是 Widget State，常用：

```dart
StatefulWidget
StateProvider
Controller
ValueNotifier
```

其中最基础的是 `StatefulWidget` 的 `State`。

可以这样映射：

| Web Local State       | Flutter Widget State              |
| --------------------- | --------------------------------- |
| `useState`            | `StatefulWidget` State            |
| `useReducer`          | `State` + reducer 方法 / Notifier |
| local component state | `State<T>` 字段                   |
| `setState` setter     | `setState(() {})`                 |
| local input state     | `TextEditingController`           |
| hover/pressed         | local bool state                  |
| tab index             | local state / `TabController`     |
| open/closed           | local bool state                  |
| component-only state  | Widget State                      |

---

## 1. Web Local State

React：

```tsx
function ProductCard() {
  const [expanded, setExpanded] = useState(false);

  return <button onClick={() => setExpanded(!expanded)}>Toggle</button>;
}
```

这个 `expanded` 只影响当前组件。

---

## 2. Flutter Widget State

Flutter：

```dart
class ProductCard extends StatefulWidget {
  const ProductCard({super.key});

  @override
  State<ProductCard> createState() => _ProductCardState();
}

class _ProductCardState extends State<ProductCard> {
  var expanded = false;

  @override
  Widget build(BuildContext context) {
    return InkWell(
      onTap: () {
        setState(() {
          expanded = !expanded;
        });
      },
      child: expanded ? ExpandedContent() : CompactContent(),
    );
  }
}
```

这里的 `expanded` 就是 Widget State。

---

## 3. 适合放 Widget State 的状态

适合：

```text
展开/收起
hover/pressed/focused
局部动画开关
当前 tab index
局部 loading
局部选中项
输入框 controller
ScrollController
PageController
```

特点：

```text
只影响当前 Widget 或很小的子树；
不需要跨页面共享；
销毁 Widget 时状态也可以销毁。
```

---

## 4. TextEditingController

输入框局部状态常用 controller：

```dart
class SearchBoxState extends State<SearchBox> {
  late final TextEditingController controller;

  @override
  void initState() {
    super.initState();
    controller = TextEditingController();
  }

  @override
  void dispose() {
    controller.dispose();
    super.dispose();
  }
}
```

这类 controller 通常就是 Widget State 的一部分。

---

## 5. 什么时候不要用 Widget State

如果状态需要：

```text
多个页面共享
刷新后保持
由服务端数据驱动
参与业务逻辑
需要缓存
需要测试复杂状态迁移
多个组件同时读写
```

就不要只放在 `StatefulWidget` 里，考虑：

```text
Riverpod Provider
Notifier
AsyncNotifier
Repository
本地存储
```

---

## 6. Local Provider

有些状态虽然是局部的，但用 Riverpod 管更方便，比如页面内多个组件共享：

```dart
final selectedTabProvider = StateProvider.autoDispose<int>((ref) => 0);
```

如果只在一个页面生命周期内有效，可以用：

```dart
autoDispose
```

页面离开后自动清理。

---

## 7. 判断标准

| 问题                               | 如果答案是 yes                 |
| ---------------------------------- | ------------------------------ |
| 只影响当前组件？                   | `StatefulWidget`               |
| 只用于一个页面，但多个子组件共享？ | 页面级 Provider                |
| 多页面都要用？                     | App-level Provider             |
| 来自服务端？                       | FutureProvider / AsyncNotifier |
| 是输入/滚动/动画控制对象？         | Controller 放 State 中         |
| 需要持久化？                       | Storage + Provider             |

一句话理解：

```text
Web Local State 对应 Flutter Widget State；
只属于局部 UI 的状态用 StatefulWidget/Controller 管理即可。
状态一旦跨组件、跨页面、异步缓存或业务化，就提升到 Provider/Notifier。
```
