# React `useState` vs `StatefulWidget` State

React 的 `useState` 用来在 Function Component 中保存局部状态。

Flutter 中对应的是 `StatefulWidget` 的 `State` 对象，通过字段保存状态，通过 `setState()` 触发 rebuild。

可以这样映射：

| React `useState`               | Flutter `StatefulWidget`        |
| ------------------------------ | ------------------------------- |
| `const [x, setX] = useState()` | `State` 字段                    |
| setter 更新状态                | `setState(() { ... })`          |
| function component re-render   | `build()` 重新执行              |
| state 保存在组件实例中         | state 保存在 `State<T>` 对象中  |
| lazy initial state             | `initState()` 初始化            |
| derived initial props          | `initState` / `didUpdateWidget` |
| unmount cleanup                | `dispose()`                     |
| local UI state                 | local widget state              |

---

## 1. React useState

React：

```tsx
function Counter() {
  const [count, setCount] = useState(0);

  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

状态变化后：

```text
setCount → component re-render
```

---

## 2. Flutter StatefulWidget State

Flutter：

```dart
class Counter extends StatefulWidget {
  const Counter({super.key});

  @override
  State<Counter> createState() => _CounterState();
}

class _CounterState extends State<Counter> {
  var count = 0;

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () {
        setState(() {
          count++;
        });
      },
      child: Text('$count'),
    );
  }
}
```

状态变化后：

```text
setState → build 重新执行
```

---

## 3. 状态放在哪里

React：

```tsx
const [expanded, setExpanded] = useState(false);
```

Flutter：

```dart
var expanded = false;
```

放在：

```dart
class _CardState extends State<Card> {
  var expanded = false;
}
```

这类状态适合：

```text
展开/收起
tab 当前 index
hover/pressed
局部 loading
动画开关
输入框局部状态
```

## 4. 初始化状态

React：

```tsx
const [count, setCount] = useState(() => initialCount);
```

Flutter：

```dart
@override
void initState() {
  super.initState();
  count = widget.initialCount;
}
```

完整：

```dart
late int count;

@override
void initState() {
  super.initState();
  count = widget.initialCount;
}
```

## 5. props 变化后的状态同步

React：

```tsx
useEffect(() => {
  setValue(props.value);
}, [props.value]);
```

Flutter：

```dart
@override
void didUpdateWidget(covariant MyWidget oldWidget) {
  super.didUpdateWidget(oldWidget);

  if (oldWidget.value != widget.value) {
    value = widget.value;
  }
}
```

注意：是否要把 props 复制到 local state，要谨慎。很多时候直接使用 `widget.value` 更简单。

---

## 6. setState 注意事项

Flutter：

```dart
setState(() {
  loading = true;
});
```

`setState` 里应该只做同步状态修改，不要直接写耗时异步逻辑：

```dart
setState(() {
  // 修改字段
});
```

异步后更新：

```dart
Future<void> submit() async {
  setState(() {
    loading = true;
  });

  await request();

  if (!mounted) return;

  setState(() {
    loading = false;
  });
}
```

`mounted` 用来确认 State 还在树上，避免组件销毁后继续更新状态。

## 7. 局部状态 vs 全局状态

React 中：

```text
useState 适合组件局部状态；
跨组件共享状态可能用 Context/Zustand/Redux。
```

Flutter 中：

```text
StatefulWidget State 适合局部状态；
跨组件共享状态更适合 Riverpod/Provider/Bloc。
```

判断：

| 状态类型           | Flutter 推荐                   |
| ------------------ | ------------------------------ |
| 只影响当前 Widget  | `StatefulWidget`               |
| 页面内多个组件共享 | 页面级 Provider / Notifier     |
| 跨页面共享         | Riverpod / Repository state    |
| 需要缓存/异步请求  | FutureProvider / AsyncNotifier |
| 输入框控制         | TextEditingController          |
| 动画控制           | AnimationController            |

---

一句话理解：

```text
React useState 把局部状态放在 Function Component 里；
Flutter StatefulWidget 把局部状态放在 State 对象里。
更新时 React 调 setter，Flutter 调 setState，
最终都会重新执行 UI 构建逻辑。
```
