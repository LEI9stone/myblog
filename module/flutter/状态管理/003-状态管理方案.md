# Redux / Zustand / Jotai vs Riverpod

Web 里 Redux、Zustand、Jotai 都是状态管理方案。

Flutter 里 Riverpod 是常见状态管理方案，既能管理全局状态，也能管理异步数据、派生状态、依赖注入和业务逻辑。

可以这样映射：

| Web 状态库           | Flutter / Riverpod                                   |
| -------------------- | ---------------------------------------------------- |
| Redux store          | ProviderContainer / ProviderScope                    |
| Redux slice          | NotifierProvider / StateNotifierProvider             |
| Redux action         | Notifier method                                      |
| Redux reducer        | Notifier state update                                |
| Redux selector       | `ref.watch(provider.select(...))` / derived Provider |
| Zustand store        | Notifier / StateProvider                             |
| Jotai atom           | Provider / StateProvider                             |
| async query state    | FutureProvider / AsyncNotifier                       |
| derived atom         | computed Provider                                    |
| dependency injection | Provider                                             |
| global state         | ProviderScope 下的 provider graph                    |

---

## 1. Redux vs Riverpod

Redux：

```ts
dispatch(addToCart(product));
```

Riverpod：

```dart
ref.read(cartProvider.notifier).add(product);
```

Redux 典型心智：

```text
store
action
reducer
selector
dispatch
```

Riverpod 典型心智：

```text
provider
state
notifier method
ref.watch
ref.read
```

可以理解为：

```text
Redux 通过 action/reducer 更新 store；
Riverpod 通过 Notifier 方法更新 provider state。
```

## 2. Zustand vs Riverpod

Zustand：

```ts
const useCartStore = create((set) => ({
  items: [],
  add: (item) =>
    set((state) => ({
      items: [...state.items, item],
    })),
}));
```

Riverpod：

```dart
final cartProvider =
    NotifierProvider<CartNotifier, CartState>(CartNotifier.new);

class CartNotifier extends Notifier<CartState> {
  @override
  CartState build() {
    return const CartState(items: []);
  }

  void add(Product product) {
    state = state.copyWith(
      items: [...state.items, product],
    );
  }
}
```

Zustand 和 Riverpod 的体感更接近：

```text
都有一个状态容器；
状态和操作方法可以放在一起；
组件订阅需要的状态。
```

---

## 3. Jotai vs Riverpod

Jotai：

```ts
const countAtom = atom(0);
const doubledAtom = atom((get) => get(countAtom) * 2);
```

Riverpod：

```dart
final countProvider = StateProvider<int>((ref) => 0);

final doubledProvider = Provider<int>((ref) {
  final count = ref.watch(countProvider);
  return count * 2;
});
```

Jotai 的 atom 和 Riverpod 的 provider 很像：

```text
atom/provider 都是可组合的状态单元；
可以派生；
可以被组件订阅。
```

---

## 4. 读取状态：useStore/useAtom vs ref.watch

Redux/Zustand/Jotai：

```ts
const count = useStore((state) => state.count);
const [value, setValue] = useAtom(countAtom);
```

Riverpod：

```dart
final count = ref.watch(countProvider);
```

只调用方法，不订阅 UI 更新：

```dart
ref.read(cartProvider.notifier).add(product);
```

大致映射：

| Web         | Riverpod                               |
| ----------- | -------------------------------------- |
| 订阅状态    | `ref.watch(provider)`                  |
| 读取一次    | `ref.read(provider)`                   |
| 派生选择    | `select` / derived Provider            |
| 调用 action | `ref.read(provider.notifier).method()` |

## 5. 异步状态

Web 里可能用：

```text
Redux thunk / saga
Zustand async action
Jotai async atom
React Query
SWR
```

Riverpod 中常用：

```dart
FutureProvider
AsyncNotifier
AsyncValue
```

例如：

```dart
final productsProvider = FutureProvider<List<Product>>((ref) async {
  final repository = ref.watch(productRepositoryProvider);
  return repository.fetchProducts();
});
```

UI：

```dart
final products = ref.watch(productsProvider);

switch (products) {
  case AsyncLoading():
    return const LoadingView();
  case AsyncError(:final error):
    return ErrorView(error: error);
  case AsyncData(:final value):
    return ProductList(products: value);
}
```

## 6. Riverpod 的特点

Riverpod 不只是全局状态库，也常承担：

```text
状态管理
异步数据管理
依赖注入
缓存
派生状态
生命周期清理
测试替换依赖
```

例如 repository 注入：

```dart
final productRepositoryProvider = Provider<ProductRepository>((ref) {
  return RemoteProductRepository();
});
```

业务状态再依赖它：

```dart
final productsProvider = FutureProvider((ref) {
  final repository = ref.watch(productRepositoryProvider);
  return repository.fetchProducts();
});
```

## 7. 怎么类比

| 你熟悉的 Web 方案              | Riverpod 中更像什么              |
| ------------------------------ | -------------------------------- |
| Redux slice                    | NotifierProvider                 |
| Redux selector                 | Provider / select                |
| Zustand store                  | NotifierProvider / StateProvider |
| Jotai atom                     | Provider / StateProvider         |
| React Query query              | FutureProvider / AsyncNotifier   |
| Context provider               | ProviderScope / Provider         |
| dependency injection container | Provider graph                   |

一句话理解：

```text
Redux 更像集中式 store + action/reducer；
Zustand 更像轻量 store；
Jotai 更像 atom 状态图；
Riverpod 更像 Flutter 里的 provider 状态图，
同时覆盖状态管理、异步数据、派生状态和依赖注入。
```
