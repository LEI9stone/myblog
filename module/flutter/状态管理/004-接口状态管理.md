# Server State vs `AsyncValue` / `FutureProvider`

Web 里 Server State 通常指“来自服务端的数据状态”，常用 React Query、SWR、Redux async action 等管理。

Flutter + Riverpod 里常用：

```dart
FutureProvider
AsyncNotifier
AsyncValue
```

来表达服务端数据的 loading / error / data 状态。

可以这样映射：

| Web Server State  | Flutter / Riverpod                             |
| ----------------- | ---------------------------------------------- |
| React Query query | `FutureProvider` / `AsyncNotifier`             |
| `isLoading`       | `AsyncLoading`                                 |
| `error`           | `AsyncError`                                   |
| `data`            | `AsyncData`                                    |
| `refetch`         | `ref.invalidate(provider)` / notifier method   |
| cache key         | provider + parameters                          |
| stale cache       | provider cache / keepAlive / invalidation      |
| dependent query   | provider dependency                            |
| query params      | family provider                                |
| mutation          | notifier method / repository call              |
| optimistic update | update provider state before request completes |

---

## 1. Server State 是什么

Web 里通常区分：

```text
Client State：前端本地 UI 状态
Server State：服务端返回的数据状态
```

例如：

```text
商品列表
订单详情
用户信息
分类数据
搜索结果
```

这类状态通常有：

```text
loading
error
data
refresh
cache
pagination
```

---

## 2. FutureProvider

Flutter + Riverpod：

```dart
final productsProvider = FutureProvider<List<Product>>((ref) async {
  final repository = ref.watch(productRepositoryProvider);
  return repository.fetchProducts();
});
```

UI 中读取：

```dart
final products = ref.watch(productsProvider);
```

`products` 的类型是：

```dart
AsyncValue<List<Product>>
```

它天然包含三种状态：

```text
AsyncLoading
AsyncError
AsyncData
```

---

## 3. AsyncValue 渲染 UI

```dart
switch (products) {
  case AsyncLoading():
    return const LoadingView();

  case AsyncError(:final error):
    return ErrorView(error: error);

  case AsyncData(:final value):
    return ProductList(products: value);
}
```

对应 Web：

```tsx
if (isLoading) return <Loading />;
if (error) return <ErrorView />;
return <ProductList products={data} />;
```

---

## 4. refetch / refresh

React Query：

```ts
queryClient.invalidateQueries(['products']);
```

Riverpod：

```dart
ref.invalidate(productsProvider);
```

或者刷新当前 provider：

```dart
ref.refresh(productsProvider);
```

在 UI 中：

```dart
RefreshIndicator(
  onRefresh: () async {
    ref.invalidate(productsProvider);
  },
  child: ProductList(...),
)
```

---

## 5. 带参数请求：family

React Query：

```ts
useQuery(['product', id], () => fetchProduct(id));
```

Riverpod：

```dart
final productProvider =
    FutureProvider.family<Product, String>((ref, id) async {
  final repository = ref.watch(productRepositoryProvider);
  return repository.fetchProduct(id);
});
```

使用：

```dart
final product = ref.watch(productProvider(productId));
```

这里：

```text
provider + productId
≈ query key
```

## 6. AsyncNotifier

如果服务端状态不只是“一次请求”，还需要：

```text
刷新
分页
筛选
提交
局部更新
乐观更新
```

可以用 `AsyncNotifier`：

```dart
final productListProvider =
    AsyncNotifierProvider<ProductListNotifier, List<Product>>(
  ProductListNotifier.new,
);

class ProductListNotifier extends AsyncNotifier<List<Product>> {
  @override
  Future<List<Product>> build() async {
    final repository = ref.watch(productRepositoryProvider);
    return repository.fetchProducts();
  }

  Future<void> reload() async {
    state = const AsyncLoading();
    state = await AsyncValue.guard(() async {
      final repository = ref.read(productRepositoryProvider);
      return repository.fetchProducts();
    });
  }
}
```

使用：

```dart
ref.read(productListProvider.notifier).reload();
```

---

## 7. FutureProvider vs AsyncNotifier 怎么选

| 场景             | 推荐                    |
| ---------------- | ----------------------- |
| 简单 GET 请求    | `FutureProvider`        |
| 带参数 GET 请求  | `FutureProvider.family` |
| 多状态、多操作   | `AsyncNotifier`         |
| 分页列表         | `AsyncNotifier`         |
| 刷新、追加、筛选 | `AsyncNotifier`         |
| 只读配置数据     | `FutureProvider`        |
| 需要乐观更新     | `AsyncNotifier`         |

---

## 8. Server State 不等于 UI State

不要把所有状态都塞进一个地方。

| 状态          | 示例               | 推荐                               |
| ------------- | ------------------ | ---------------------------------- |
| Server State  | 商品列表、订单详情 | `FutureProvider` / `AsyncNotifier` |
| UI State      | 当前 tab、弹窗开关 | `StatefulWidget` / `StateProvider` |
| Form State    | 输入框内容         | Controller / Form / Provider       |
| Derived State | 筛选后的列表       | Provider 派生                      |

一句话理解：

```text
Web 的 Server State 通常由 React Query/SWR 管理；
Flutter + Riverpod 中，
简单服务端请求用 FutureProvider，
复杂异步业务状态用 AsyncNotifier，
UI 通过 AsyncValue 统一处理 loading/error/data。
```
