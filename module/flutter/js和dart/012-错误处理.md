# 错误处理：try/catch vs Dart Exception/Error

JavaScript/TypeScript 和 Dart 都支持 `try/catch`，也都可以在 `async/await` 中捕获异步错误。

但 Dart 对异常类型的区分更明确：常见业务可恢复问题通常用 `Exception`，程序错误或不该捕获的问题通常是 `Error`。

| JavaScript / TypeScript | Dart                        |
| ----------------------- | --------------------------- |
| `try/catch`             | `try/catch`                 |
| `throw new Error()`     | `throw Exception()`         |
| `Error`                 | `Exception` / `Error`       |
| `catch (error)`         | `catch (error, stackTrace)` |
| 自定义 Error class      | 自定义 Exception class      |
| `finally`               | `finally`                   |
| `Promise.reject()`      | `Future.error()`            |
| async error             | Future exception            |
| type narrowing          | `on SomeException catch`    |

---

## 1. 基本 try/catch

TypeScript：

```ts
try {
  const user = await fetchUser();
} catch (error) {
  console.error(error);
}
```

Dart：

```dart
try {
  final user = await fetchUser();
} catch (error, stackTrace) {
  debugPrint('$error');
}
```

Dart 的 `catch` 可以拿到两个值：

```text
error
stackTrace
```

这比 JavaScript 里默认只拿 `error` 更直接。

---

## 2. 精确捕获异常类型

TypeScript 通常要手动判断：

```ts
try {
  await request();
} catch (error) {
  if (error instanceof ApiError) {
    // handle api error
  }
}
```

Dart 可以直接用 `on`：

```dart
try {
  await request();
} on DioException catch (error) {
  // handle network error
} on FormatException catch (error) {
  // handle parse error
} catch (error) {
  // fallback
}
```

心智映射：

```text
TS: catch 后自己 instanceof 判断
Dart: on XxxException catch 直接分支捕获
```

---

## 3. Exception vs Error

Dart 中通常这样区分：

| Dart        | 适合表示                       |
| ----------- | ------------------------------ |
| `Exception` | 可预期、可处理的异常           |
| `Error`     | 程序错误、断言失败、类型错误等 |

业务中更常见：

```dart
throw Exception('Request failed');
```

或者自定义：

```dart
class ApiException implements Exception {
  const ApiException(this.message);

  final String message;

  @override
  String toString() => message;
}
```

不太推荐业务代码随意 `throw Error()`。

---

## 4. async/await 错误处理

TypeScript：

```ts
async function submit() {
  try {
    await save();
  } catch (error) {
    showToast('Save failed');
  }
}
```

Dart：

```dart
Future<void> submit() async {
  try {
    await save();
  } catch (error) {
    showToast('Save failed');
  }
}
```

两者心智基本一致：

```text
await 的 Future/Promise 失败时，会进入 catch。
```

---

## 5. finally

TypeScript：

```ts
try {
  await submit();
} catch (error) {
  // handle error
} finally {
  setLoading(false);
}
```

Dart：

```dart
try {
  await submit();
} catch (error) {
  // handle error
} finally {
  setLoading(false);
}
```

适合做：

```text
关闭 loading
释放资源
清理临时状态
```

---

## 6. Future.error

TypeScript：

```ts
return Promise.reject(new Error('Failed'));
```

Dart：

```dart
return Future.error(Exception('Failed'));
```

但在 `async` 函数里，更常见的是直接：

```dart
throw Exception('Failed');
```

例如：

```dart
Future<User> fetchUser() async {
  final response = await dio.get('/user');

  if (response.statusCode != 200) {
    throw Exception('Fetch user failed');
  }

  return User.fromJson(response.data);
}
```

---

## 7. Flutter UI 中的错误状态

React 中常见：

```text
loading / error / data
```

Flutter 里也一样，只是承载方式不同：

```text
try/catch
FutureBuilder snapshot.hasError
Riverpod AsyncValue.error
Repository 返回 Result 类型
```

例如 Riverpod 心智：

```dart
switch (state) {
  case AsyncData(:final value):
    return DataView(value);
  case AsyncError(:final error):
    return ErrorView(error: error);
  case AsyncLoading():
    return const LoadingView();
}
```

---

一句话理解：

```text
TypeScript 和 Dart 都用 try/catch 处理同步和异步错误；
Dart 额外提供 on XxxException catch 做类型化捕获，
业务异常通常用 Exception，
程序级错误通常属于 Error。
```
