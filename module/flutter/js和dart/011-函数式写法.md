# 函数式写法：JS 高阶函数 vs Dart 函数对象

JavaScript/TypeScript 和 Dart 都支持把函数当作值传递，也都支持高阶函数、匿名函数、闭包、链式集合操作。

可以这样映射：

| JavaScript / TypeScript | Dart                              |
| ----------------------- | --------------------------------- |
| function                | function                          |
| arrow function          | arrow function `=>`               |
| callback                | callback                          |
| higher-order function   | higher-order function             |
| closure                 | closure                           |
| `Array.map()`           | `Iterable.map()`                  |
| `Array.filter()`        | `Iterable.where()`                |
| `Array.reduce()`        | `Iterable.fold()` / `reduce()`    |
| function type           | `Function` / 精确函数类型         |
| `(x: T) => R`           | `R Function(T x)`                 |
| optional callback       | nullable function `VoidCallback?` |
| React event handler     | Flutter callback                  |

---

## 1. 函数作为值

TypeScript：

```ts
const add = (a: number, b: number) => a + b;
```

Dart：

```dart
final add = (int a, int b) => a + b;
```

也可以显式声明函数类型：

```dart
int Function(int a, int b) add = (a, b) => a + b;
```

---

## 2. 高阶函数

TypeScript：

```ts
function withLog<T>(fn: () => T): T {
  console.log('before');
  return fn();
}
```

Dart：

```dart
T withLog<T>(T Function() fn) {
  debugPrint('before');
  return fn();
}
```

核心映射：

```text
TS: () => T
Dart: T Function()
```

---

## 3. 集合函数式操作

TypeScript：

```ts
const names = products
  .filter((product) => product.enabled)
  .map((product) => product.title);
```

Dart：

```dart
final names = products
    .where((product) => product.enabled)
    .map((product) => product.title)
    .toList();
```

注意 Dart 的 `map()`、`where()` 返回的是 `Iterable`，如果需要 List，要加：

```dart
.toList()
```

常见映射：

| TypeScript | Dart              |
| ---------- | ----------------- |
| `map`      | `map`             |
| `filter`   | `where`           |
| `find`     | `firstWhere`      |
| `some`     | `any`             |
| `every`    | `every`           |
| `reduce`   | `reduce` / `fold` |
| `forEach`  | `forEach`         |

---

## 4. Callback 类型

TypeScript：

```ts
type OnTap = () => void;
type OnChange = (value: string) => void;
```

Dart：

```dart
typedef OnTap = void Function();
typedef OnChange = void Function(String value);
```

Flutter 中常见：

```dart
final VoidCallback? onTap;
final ValueChanged<String>? onChanged;
```

对应心智：

| Flutter              | 含义                      |
| -------------------- | ------------------------- |
| `VoidCallback`       | `void Function()`         |
| `ValueChanged<T>`    | `void Function(T value)`  |
| `GestureTapCallback` | 点击回调                  |
| `AsyncCallback`      | `Future<void> Function()` |

---

## 5. Flutter 组件里的函数参数

React：

```tsx
<Button onClick={() => submit()} />
```

Flutter：

```dart
ElevatedButton(
  onPressed: () => submit(),
  child: const Text('Submit'),
)
```

如果函数签名刚好匹配，也可以直接传：

```dart
ElevatedButton(
  onPressed: submit,
  child: const Text('Submit'),
)
```

---

## 6. 闭包

TypeScript：

```ts
function createCounter() {
  let count = 0;

  return () => {
    count++;
    return count;
  };
}
```

Dart：

```dart
int Function() createCounter() {
  var count = 0;

  return () {
    count++;
    return count;
  };
}
```

Dart 闭包也可以捕获外层变量。

---

## 7. Dart 函数类型更建议写精确

Dart 里可以写：

```dart
Function callback;
```

但这太宽泛，类似 TypeScript 里的：

```ts
Function;
```

更推荐写精确签名：

```dart
void Function() onTap;
String Function(Product product) titleBuilder;
Future<void> Function() onRefresh;
```

这样类型更安全，IDE 提示也更好。

---

一句话理解：

```text
JavaScript/TypeScript 和 Dart 都支持函数式写法；
JS 常用 arrow function 和 Array 高阶函数；
Dart 用函数对象、精确 Function 类型、Iterable 操作和 Flutter callback 承载类似模式。
```
