# Array/Object/Map vs List/Map/Record/Class

JavaScript/TypeScript 常用：

```ts
Array;
Object;
Map;
```

Dart 常用：

```dart
List
Map
Record
Class
```

它们都能表达集合和结构化数据，但 Dart 更鼓励用明确类型的 `class` 表达业务模型。

| JavaScript / TypeScript | Dart                                   |
| ----------------------- | -------------------------------------- |
| `Array<T>` / `T[]`      | `List<T>`                              |
| object literal          | `Map` / `Record` / `class`             |
| plain object as DTO     | `class` model / `Map<String, dynamic>` |
| `Record<string, T>`     | `Map<String, T>`                       |
| `Map<K, V>`             | `Map<K, V>`                            |
| tuple `[A, B]`          | Record `(A, B)`                        |
| named tuple/object      | named Record `({A a, B b})` / class    |
| interface object        | class                                  |
| JSON object             | `Map<String, dynamic>` / model class   |

---

## 1. Array vs List

TypeScript：

```ts
const names: string[] = ['Tom', 'Jerry'];
const products: Array<Product> = [];
```

Dart：

```dart
final names = <String>['Tom', 'Jerry'];
final products = <Product>[];
```

或显式类型：

```dart
List<String> names = ['Tom', 'Jerry'];
List<Product> products = [];
```

常见方法映射：

| TypeScript Array  | Dart List              |
| ----------------- | ---------------------- |
| `arr.map(fn)`     | `list.map(fn)`         |
| `arr.filter(fn)`  | `list.where(fn)`       |
| `arr.find(fn)`    | `list.firstWhere(...)` |
| `arr.some(fn)`    | `list.any(fn)`         |
| `arr.every(fn)`   | `list.every(fn)`       |
| `arr.includes(x)` | `list.contains(x)`     |
| `arr.push(x)`     | `list.add(x)`          |
| `arr.length`      | `list.length`          |

---

## 2. Object Literal vs Map

TypeScript 里 object 很常见：

```ts
const user = {
  id: '1',
  name: 'Tom',
};
```

Dart 如果只是键值表，可以用 `Map`：

```dart
final user = {
  'id': '1',
  'name': 'Tom',
};
```

它的类型通常会被推断成：

```dart
Map<String, String>
```

如果值类型混合：

```dart
final user = {
  'id': '1',
  'age': 18,
};
```

可能会推断成：

```dart
Map<String, Object>
```

JSON 场景常见：

```dart
Map<String, dynamic> json
```

---

## 3. Plain Object DTO vs Class Model

TypeScript 经常用 interface 描述普通对象：

```ts
type Product = {
  id: string;
  title: string;
  price: number;
};
```

Dart 更推荐用 class：

```dart
class Product {
  const Product({
    required this.id,
    required this.title,
    required this.price,
  });

  final String id;
  final String title;
  final double price;
}
```

JSON 转换通常写：

```dart
factory Product.fromJson(Map<String, dynamic> json) {
  return Product(
    id: json['id'] as String,
    title: json['title'] as String,
    price: (json['price'] as num).toDouble(),
  );
}
```

实际项目里常配合：

```text
json_serializable
freezed
```

减少手写序列化。

## 4. JavaScript Map vs Dart Map

TypeScript：

```ts
const cache = new Map<string, Product>();
cache.set('1', product);
const item = cache.get('1');
```

Dart：

```dart
final cache = <String, Product>{};
cache['1'] = product;
final item = cache['1'];
```

也可以显式：

```dart
final cache = Map<String, Product>();
```

Dart 的 `{}` 字面量默认常用于 `Map`：

```dart
final map = <String, int>{};
```

而 List 用：

```dart
final list = <int>[];
```

Set 用：

```dart
final set = <int>{1, 2, 3};
```

---

## 5. Tuple vs Record

TypeScript tuple：

```ts
const point: [number, number] = [10, 20];
```

Dart Record：

```dart
final point = (10, 20);
```

读取：

```dart
final x = point.$1;
final y = point.$2;
```

Dart 也支持命名 Record：

```dart
final point = (x: 10, y: 20);

final x = point.x;
final y = point.y;
```

适合：

```text
临时组合多个返回值
轻量数据结构
不值得单独建 class 的场景
```

---

## 6. Record vs Class 怎么选

| 场景           | 推荐                           |
| -------------- | ------------------------------ |
| 临时返回多个值 | Record                         |
| 业务模型       | Class                          |
| JSON DTO       | Class + fromJson               |
| 键值缓存       | Map                            |
| 列表数据       | List                           |
| 状态模型       | Class / sealed class / Freezed |

比如临时返回分页结果：

```dart
({List<Product> items, bool hasMore}) parseResult() {
  return (items: [], hasMore: false);
}
```

但如果是业务实体：

```dart
class Product {
  final String id;
  final String title;
  final double price;
}
```

更适合用 class。

---

一句话理解：

```text
JavaScript/TypeScript 里 Array/Object/Map 覆盖了大量数据表达；
Dart 里 List 表达数组，Map 表达键值表，Record 表达轻量组合，Class 表达明确业务模型。
```
