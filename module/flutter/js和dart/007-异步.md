# Promise/async/await vs Future/async/await

TypeScript/JavaScript 用 `Promise` 表示异步结果。

Dart 用 `Future` 表示异步结果。

两者都支持 `async/await`，开发体验非常接近。

| JavaScript / TypeScript  | Dart                                         |
| ------------------------ | -------------------------------------------- |
| `Promise<T>`             | `Future<T>`                                  |
| `async function`         | `Future<T> async` 函数                       |
| `await promise`          | `await future`                               |
| `Promise.resolve(value)` | `Future.value(value)`                        |
| `Promise.reject(error)`  | `Future.error(error)`                        |
| `.then()`                | `.then()`                                    |
| `.catch()`               | `.catchError()` / `try-catch`                |
| `.finally()`             | `.whenComplete()`                            |
| `Promise.all()`          | `Future.wait()`                              |
| `Promise.race()`         | `Future.any()`                               |
| `setTimeout()`           | `Future.delayed()` / `Timer`                 |
| microtask                | `Future.microtask()` / `scheduleMicrotask()` |

---

## 1. 基本用法映射

TypeScript：

```ts
async function fetchUser(): Promise<User> {
  const response = await fetch('/api/user');
  return response.json();
}
```

Dart：

```dart
Future<User> fetchUser() async {
  final response = await dio.get('/api/user');
  return User.fromJson(response.data);
}
```

核心结构一样：

```text
async 函数返回 Promise<T>
async 函数返回 Future<T>
```

---

## 2. `await`

TypeScript：

```ts
const user = await fetchUser();
```

Dart：

```dart
final user = await fetchUser();
```

二者都表示：

```text
等待异步结果完成；
成功则拿到值；
失败则抛出异常。
```

---

## 3. 错误处理

TypeScript：

```ts
try {
  const user = await fetchUser();
} catch (error) {
  console.error(error);
}
```

Dart：

```dart
try {
  final user = await fetchUser();
} catch (error, stackTrace) {
  debugPrint('$error');
}
```

Dart 的 `catch` 可以同时拿到：

```dart
error
stackTrace
```

也可以限定异常类型：

```dart
try {
  final user = await fetchUser();
} on DioException catch (error) {
  // handle dio error
} catch (error) {
  // fallback
}
```

---

## 4. `.then()` 链式调用

TypeScript：

```ts
fetchUser()
  .then((user) => {
    console.log(user);
  })
  .catch((error) => {
    console.error(error);
  });
```

Dart：

```dart
fetchUser()
    .then((user) {
      debugPrint('$user');
    })
    .catchError((error) {
      debugPrint('$error');
    });
```

Flutter/Dart 业务代码里通常更推荐：

```dart
try {
  final user = await fetchUser();
} catch (error) {
  // handle error
}
```

---

## 5. 并发请求

TypeScript：

```ts
const [user, products] = await Promise.all([fetchUser(), fetchProducts()]);
```

Dart：

```dart
final results = await Future.wait([
  fetchUser(),
  fetchProducts(),
]);

final user = results[0] as User;
final products = results[1] as List<Product>;
```

如果想保留更明确的类型，通常会写：

```dart
final userFuture = fetchUser();
final productsFuture = fetchProducts();

final user = await userFuture;
final products = await productsFuture;
```

这样两个 Future 会先启动，再分别等待。

---

## 6. 延迟执行

TypeScript：

```ts
await new Promise((resolve) => setTimeout(resolve, 1000));
```

Dart：

```dart
await Future.delayed(const Duration(seconds: 1));
```

带返回值：

```dart
final value = await Future.delayed(
  const Duration(seconds: 1),
  () => 'done',
);
```

---

## 7. async 函数返回值

TypeScript：

```ts
async function getName() {
  return 'Tom';
}
```

返回类型是：

```ts
Promise<string>;
```

Dart：

```dart
Future<String> getName() async {
  return 'Tom';
}
```

返回类型是：

```dart
Future<String>
```

如果不返回值：

TypeScript：

```ts
async function submit(): Promise<void> {}
```

Dart：

```dart
Future<void> submit() async {}
```

---

## 8. FutureBuilder

Flutter UI 中可以直接基于 `Future` 渲染：

```dart
FutureBuilder<User>(
  future: fetchUser(),
  builder: (context, snapshot) {
    if (snapshot.connectionState == ConnectionState.waiting) {
      return const CircularProgressIndicator();
    }

    if (snapshot.hasError) {
      return Text('Error: ${snapshot.error}');
    }

    final user = snapshot.data!;
    return Text(user.name);
  },
)
```

React 中类似心智是：

```text
useEffect 发请求
useState 保存 loading/error/data
根据状态渲染 UI
```

不过在实际 Flutter 应用中，如果用了 Riverpod，通常会用：

```text
FutureProvider / AsyncValue
```

来管理异步状态。

---

一句话理解：

```text
Promise 是 JavaScript 的异步结果；
Future 是 Dart 的异步结果；
两者都配合 async/await 使用，心智模型非常接近。
```
