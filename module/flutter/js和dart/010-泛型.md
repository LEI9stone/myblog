# 泛型：TypeScript Generics vs Dart Generics

TypeScript 和 Dart 都支持泛型，用来让函数、类、接口、集合在保持类型安全的同时复用逻辑。

可以这样映射：

| TypeScript                    | Dart                        |
| ----------------------------- | --------------------------- |
| `Array<T>`                    | `List<T>`                   |
| `Map<K, V>`                   | `Map<K, V>`                 |
| `Promise<T>`                  | `Future<T>`                 |
| generic function              | generic function            |
| generic class                 | generic class               |
| `T extends X`                 | `T extends X`               |
| default generic type          | Dart 支持默认类型参数较有限 |
| conditional generic type      | 无直接等价                  |
| mapped type                   | 无直接等价                  |
| structural generic constraint | nominal generic constraint  |

---

## 1. 泛型函数

TypeScript：

```ts
function identity<T>(value: T): T {
  return value;
}
```

Dart：

```dart
T identity<T>(T value) {
  return value;
}
```

使用：

```dart
final name = identity<String>('Tom');
final count = identity<int>(1);
```

多数情况下 Dart 可以自动推断：

```dart
final name = identity('Tom');
final count = identity(1);
```

## 2. 泛型集合

TypeScript：

```ts
const names: string[] = ['Tom', 'Jerry'];
const products: Array<Product> = [];
```

Dart：

```dart
final names = <String>['Tom', 'Jerry'];
final products = <Product>[];
```

或：

```dart
List<String> names = ['Tom', 'Jerry'];
List<Product> products = [];
```

Map：

```ts
const cache = new Map<string, Product>();
```

Dart：

```dart
final cache = <String, Product>{};
```

---

## 3. 泛型类

TypeScript：

```ts
class ApiResponse<T> {
  constructor(
    public data: T,
    public message: string
  ) {}
}
```

Dart：

```dart
class ApiResponse<T> {
  const ApiResponse({
    required this.data,
    required this.message,
  });

  final T data;
  final String message;
}
```

使用：

```dart
final response = ApiResponse<Product>(
  data: product,
  message: 'ok',
);
```

## 4. 泛型约束

TypeScript：

```ts
function getId<T extends { id: string }>(item: T): string {
  return item.id;
}
```

Dart 不能直接用“对象形状”约束，因为 Dart 是名义类型。通常要先定义抽象类型：

```dart
abstract class HasId {
  String get id;
}

String getId<T extends HasId>(T item) {
  return item.id;
}
```

然后实现：

```dart
class Product implements HasId {
  const Product({required this.id});

  @override
  final String id;
}
```

核心差异：

```text
TypeScript 泛型约束可以看结构；
Dart 泛型约束通常看明确类型。
```

## 5. `Future<T>` vs `Promise<T>`

TypeScript：

```ts
async function fetchProduct(): Promise<Product> {
  return product;
}
```

Dart：

```dart
Future<Product> fetchProduct() async {
  return product;
}
```

列表异步结果：

```ts
Promise<Product[]>;
```

Dart：

```dart
Future<List<Product>>
```

## 6. 泛型 Repository

Web/Flutter 业务代码中都常见泛型 Repository 或 API Response。

TypeScript：

```ts
type PageResult<T> = {
  items: T[];
  hasMore: boolean;
};
```

Dart：

```dart
class PageResult<T> {
  const PageResult({
    required this.items,
    required this.hasMore,
  });

  final List<T> items;
  final bool hasMore;
}
```

使用：

```dart
Future<PageResult<Product>> fetchProducts() async {
  // ...
}
```

## 7. Dart 没有 TypeScript 那种类型编程能力

TypeScript 泛型经常和这些能力配合：

```ts
Partial<T>
Pick<T, K>
Omit<T, K>
Record<K, V>
ReturnType<T>
T extends X ? A : B
keyof T
```

Dart 没有直接对应的 mapped types、conditional types、`keyof` 类型运算。

Dart 项目通常通过：

```text
明确 class
拆分 DTO/Model
copyWith
Freezed
json_serializable
extension
```

来解决类似问题。

---

一句话理解：

```text
TypeScript 泛型既能做类型复用，也能做复杂类型编程；
Dart 泛型更偏运行在明确 class、List、Map、Future、Repository 等模型上的类型安全复用。
```
