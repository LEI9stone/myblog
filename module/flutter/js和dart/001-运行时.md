# JavaScript Runtime vs Dart Runtime

JavaScript 代码需要运行在 JavaScript Runtime 里，比如浏览器 V8、Node.js、Bun、Deno。

Dart 代码运行在 Dart Runtime 里。Flutter 开发时由 Dart VM 支持热重载和调试；发布时通常会编译成目标平台的机器码或 JavaScript。

可以这样映射：

| JavaScript                         | Dart / Flutter                        |
| ---------------------------------- | ------------------------------------- |
| JavaScript Runtime                 | Dart Runtime                          |
| V8 / JavaScriptCore / SpiderMonkey | Dart VM / AOT Runtime                 |
| Node.js                            | Dart CLI Runtime                      |
| Browser JS Engine                  | Flutter Web 编译后的 JS/Wasm 运行环境 |
| JIT                                | Dart VM JIT                           |
| Build 后 JS Bundle                 | AOT 编译产物                          |
| Event Loop                         | Dart Event Loop                       |
| Promise Microtask                  | Future Microtask                      |
| Web Worker                         | Isolate                               |
| npm 包生态                         | pub.dev 包生态                        |

---

## 1. Web 中的 JavaScript Runtime

Web 前端代码运行在浏览器 JS 引擎里：

```text
Chrome: V8
Safari: JavaScriptCore
Firefox: SpiderMonkey
```

浏览器还提供 Web APIs：

```text
DOM
fetch
localStorage
setTimeout
WebSocket
Canvas
IndexedDB
```

所以 Web Runtime 实际上是：

```text
JS Engine + Browser APIs
```

Node.js 则是：

```text
V8 + Node APIs
```

---

## 2. Flutter 中的 Dart Runtime

Flutter 开发和运行涉及几种模式：

| 模式        | 运行方式                              |
| ----------- | ------------------------------------- |
| Debug       | Dart VM JIT                           |
| Profile     | 接近 Release，保留性能分析能力        |
| Release     | AOT 编译成本地机器码                  |
| Flutter Web | 编译成 JavaScript / Wasm 运行在浏览器 |

开发时：

```text
Dart VM 支持 JIT，所以可以 Hot Reload。
```

发布到 iOS/Android 时：

```text
Dart 通常 AOT 编译成本地代码。
```

---

## 3. JIT vs AOT

JavaScript 通常由运行时 JIT 优化：

```text
下载 JS → 解释/编译 → JIT 优化 → 执行
```

Flutter 开发时用 JIT：

```text
修改 Dart → Hot Reload → 快速更新运行中 App
```

Flutter 发布时用 AOT：

```text
Dart 代码 → Ahead-of-Time 编译 → 原生机器码
```

可以理解为：

| 场景       | Web JS                     | Flutter Dart        |
| ---------- | -------------------------- | ------------------- |
| 开发       | JS Runtime 执行源码/Bundle | Dart VM JIT         |
| 热更新体验 | HMR                        | Hot Reload          |
| 生产       | JS 引擎 JIT 优化           | AOT 编译产物        |
| 启动性能   | 依赖 JS 下载和解析         | 原生 AOT 启动更直接 |

---

## 4. Event Loop 映射

JavaScript 有事件循环：

```text
Call Stack
Microtask Queue
Macrotask Queue
Event Loop
```

Dart 也有事件循环：

```text
Event Queue
Microtask Queue
Event Loop
```

对应关系：

| JavaScript         | Dart                                    |
| ------------------ | --------------------------------------- |
| `Promise.then()`   | `Future.microtask()` / completed Future |
| `setTimeout()`     | `Timer`                                 |
| `async/await`      | `async/await`                           |
| `queueMicrotask()` | `scheduleMicrotask()`                   |
| Web Worker         | Isolate                                 |

---

## 5. 单线程与并发

JavaScript 主线程通常负责：

```text
执行 JS
处理事件
操作 DOM
布局绘制协调
```

Dart/Flutter 主 isolate 通常负责：

```text
执行 Dart UI 逻辑
构建 Widget
调度渲染
处理事件
```

重计算任务在 Web 里可能用：

```text
Web Worker
```

Flutter/Dart 中对应：

```text
Isolate
compute()
```

---

## 6. 最大心智差异

Web 开发里，JavaScript Runtime 通常依附于浏览器，很多能力来自 Web API。

Flutter 中，Dart Runtime 不提供 DOM、CSSOM、localStorage 这类浏览器 API。Flutter 通过自己的框架和插件访问 UI、存储、网络、相机、定位等能力。

所以不是：

```text
Dart = 换了语法的 JavaScript
```

而是：

```text
Dart Runtime + Flutter Framework + Flutter Engine
```

共同构成应用运行环境。

一句话理解：

```text
JavaScript Runtime 负责执行 JS，并依赖浏览器或 Node 提供宿主能力；
Dart Runtime 负责执行 Dart，Flutter 再提供 Widget、渲染和跨平台能力。
```
