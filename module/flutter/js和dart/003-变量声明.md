# `let/const` vs `final/const/var`

**`let/const` vs `final/const/var`**

JavaScript/TypeScript 常用：

```ts
let
const
```

Dart 常用：

```dart
var
final
const
```

它们都和“变量是否可重新赋值”有关，但 Dart 的 `final` 和 `const` 区分更细。

| JavaScript / TypeScript | Dart                                 | 含义                     |
| ----------------------- | ------------------------------------ | ------------------------ |
| `let`                   | `var`                                | 可重新赋值的变量         |
| `const`                 | `final`                              | 只能赋值一次，运行时确定 |
| `const` 常量值          | `const`                              | 编译时常量               |
| 显式类型声明            | 显式类型声明                         | 直接写类型               |
| `as const`              | `const` object / enum / sealed value | 更接近不可变常量语义     |

---

## 1. `let` vs `var`

TypeScript：

```ts
let count = 1;
count = 2;
```

Dart：

```dart
var count = 1;
count = 2;
```

也可以显式声明类型：

```dart
int count = 1;
count = 2;
```

所以：

```text
TS let ≈ Dart var / 显式类型变量
```

---

## 2. `const` vs `final`

TypeScript：

```ts
const name = 'Tom';
```

Dart 更常用：

```dart
final name = 'Tom';
```

`final` 表示：

```text
变量只能赋值一次；
值可以在运行时才确定。
```

例如：

```dart
final now = DateTime.now();
```

这在 Dart 中合法，因为 `final` 不要求编译期确定。

对应 TypeScript：

```ts
const now = new Date();
```

两者都不能重新赋值：

```dart
final name = 'Tom';
name = 'Jerry'; // error
```

---

## 3. Dart `const` 是编译时常量

Dart 的 `const` 比 TypeScript 的 `const` 更严格。

Dart：

```dart
const appName = 'Rouzao';
```

它要求值在编译期就能确定。

合法：

```dart
const size = 16;
const title = 'Home';
const duration = Duration(seconds: 1);
```

不合法：

```dart
const now = DateTime.now(); // error
```

因为当前时间必须运行时才知道。

应该写：

```dart
final now = DateTime.now();
```

---

## 4. `const` 在 Flutter Widget 中很常见

Flutter 中经常看到：

```dart
const Text('Hello')
```

或：

```dart
const SizedBox(height: 12)
```

这表示这个 Widget 配置是编译时常量，可以复用，减少 rebuild 成本。

React 中没有完全一样的写法。可以粗略理解为：

```text
React memo 优化的是组件重复渲染；
Flutter const 优化的是不可变 Widget 对象的重复创建。
```

---

## 5. 对象不可变性的差异

TypeScript：

```ts
const user = { name: 'Tom' };
user.name = 'Jerry'; // 可以
```

`const` 只限制变量不能重新绑定，不限制对象内部属性变化。

Dart：

```dart
final user = User(name: 'Tom');
```

`final` 也只是限制 `user` 变量不能重新赋值，不等于对象内部一定不可变。

是否不可变取决于类字段：

```dart
class User {
  final String name;

  const User({required this.name});
}
```

如果字段也是 `final`，对象才更接近不可变数据模型。

---

## 6. Dart 推荐用法

Flutter/Dart 中常见习惯是：

```text
能用 const 就用 const
不能用 const 就用 final
确实需要重新赋值才用 var
需要强调类型时写显式类型
```

例如：

```dart
const pageSize = 20;

final user = await fetchUser();

var count = 0;
count++;

String title = 'Home';
```

---

一句话理解：

```text
TypeScript 的 let 对应 Dart 的 var；
TypeScript 的 const 大多数时候对应 Dart 的 final；
Dart 的 const 是更严格的编译时常量，尤其常用于 Flutter Widget 和常量对象。
```
