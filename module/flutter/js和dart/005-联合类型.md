# Union Type vs sealed class / enum / Freezed

TypeScript 的 Union Type 可以表达“一个值可能是几种类型之一”。

Dart 没有 TypeScript 那种直接的 `A | B` 类型语法，通常用 `sealed class`、`enum` 或 Freezed 来表达类似概念。

| TypeScript                | Dart                           |
| ------------------------- | ------------------------------ |
| `A \| B`                  | `sealed class`                 |
| string literal union      | `enum`                         |
| discriminated union       | `sealed class` / Freezed union |
| object union              | `sealed class` 子类            |
| `type: 'xxx'` 判别字段    | 子类类型 / pattern matching    |
| exhaustiveness check      | sealed class + switch          |
| utility union composition | 通常拆模型或用 Freezed         |

---

## 1. TypeScript Union Type

TypeScript 可以直接写：

```ts
type Status = 'idle' | 'loading' | 'success' | 'error';
```

也可以写对象联合：

```ts
type LoadState =
  | { type: 'loading' }
  | { type: 'success'; data: Product[] }
  | { type: 'error'; message: string };
```

这种模式在前端很常见：

```text
用一个 type 字段区分状态；
不同状态携带不同数据。
```

---

## 2. 简单枚举状态：用 Dart enum

如果只是几个固定值，没有额外数据：

TypeScript：

```ts
type Status = 'idle' | 'loading' | 'success' | 'error';
```

Dart：

```dart
enum Status {
  idle,
  loading,
  success,
  error,
}
```

适合：

```text
固定状态
固定分类
固定模式
不需要每个状态携带不同字段
```

例如：

```dart
final status = Status.loading;
```

---

## 3. 携带不同数据：用 sealed class

如果每种状态携带的数据不同，Dart 更适合用 `sealed class`。

TypeScript：

```ts
type LoadState =
  | { type: 'loading' }
  | { type: 'success'; data: Product[] }
  | { type: 'error'; message: string };
```

Dart：

```dart
sealed class LoadState {
  const LoadState();
}

final class Loading extends LoadState {
  const Loading();
}

final class Success extends LoadState {
  const Success(this.data);

  final List<Product> data;
}

final class Failure extends LoadState {
  const Failure(this.message);

  final String message;
}
```

使用时：

```dart
switch (state) {
  case Loading():
    return const Text('Loading');
  case Success(:final data):
    return ProductList(data);
  case Failure(:final message):
    return Text(message);
}
```

核心映射：

```text
TypeScript 用 type 字段做判别；
Dart 用子类类型做判别。
```

---

## 4. Freezed Union

Flutter 项目里也常用 Freezed 来写 union，减少样板代码。

Dart + Freezed：

```dart
@freezed
sealed class LoadState with _$LoadState {
  const factory LoadState.loading() = Loading;
  const factory LoadState.success(List<Product> data) = Success;
  const factory LoadState.error(String message) = Failure;
}
```

它适合：

```text
状态模型较多
需要 copyWith
需要 JSON 序列化
需要不可变数据模型
希望少写样板代码
```

常见生成文件：

```dart
part 'load_state.freezed.dart';
part 'load_state.g.dart';
```

---

## 5. enum vs sealed class vs Freezed 怎么选

| 场景                                  | 推荐                        |
| ------------------------------------- | --------------------------- |
| 只有固定状态值                        | `enum`                      |
| 每个状态携带不同数据                  | `sealed class`              |
| 状态复杂且需要不可变/copyWith/codegen | Freezed                     |
| 要和 JSON 强绑定                      | Freezed + json_serializable |
| 要最少依赖                            | 手写 `sealed class`         |
| 要最少样板代码                        | Freezed                     |

简单判断：

```text
没有额外数据：enum
有额外数据：sealed class
数据模型复杂：Freezed
```

---

## 6. 和 TypeScript 的主要差异

TypeScript：

```text
一个 type 可以组合很多对象形状；
通过字段值缩小类型；
类型在编译后被擦除。
```

Dart：

```text
通过明确的类层级表达不同状态；
通过 is/switch/pattern matching 缩小类型；
类型是语言核心模型的一部分。
```

TypeScript 更轻量：

```ts
type Result<T> = { ok: true; data: T } | { ok: false; error: string };
```

Dart 更显式：

```dart
sealed class Result<T> {
  const Result();
}

final class Ok<T> extends Result<T> {
  const Ok(this.data);

  final T data;
}

final class Err<T> extends Result<T> {
  const Err(this.error);

  final String error;
}
```

---

一句话理解：

```text
TypeScript 用 Union Type 直接描述“几种形状之一”；
Dart 用 enum 表达简单枚举，
用 sealed class 表达带数据的联合状态，
用 Freezed 降低复杂联合模型的样板代码。
```
