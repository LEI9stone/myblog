# Module Import/Export vs Dart Import/Export

JavaScript/TypeScript 用 ES Module 管理模块：

```ts
import
export
export default
```

Dart 也有模块导入导出机制：

```dart
import
export
part / part of
```

但 Dart 没有 `default export`，也不推荐像前端那样频繁用 barrel 文件隐藏来源。

| JavaScript / TypeScript | Dart                       |
| ----------------------- | -------------------------- |
| `import`                | `import`                   |
| `export`                | `export`                   |
| `export default`        | 无直接等价                 |
| named export            | 普通公开声明               |
| namespace import        | import prefix              |
| path alias              | package import             |
| barrel export           | `export` 文件              |
| dynamic import          | deferred import / 条件导入 |
| private module member   | `_` 前缀私有成员           |
| file module scope       | library scope              |

---

## 1. 基本 import

TypeScript：

```ts
import { ProductCard } from './ProductCard';
import { fetchProducts } from '@/services/product';
```

Dart：

```dart
import 'package:rouzao_app/core/widgets/product_card.dart';
import 'package:rouzao_app/features/product/data/product_repository.dart';
```

Flutter 项目中常见两种路径：

```dart
import 'product_card.dart';
```

和：

```dart
import 'package:rouzao_app/core/widgets/product_card.dart';
```

大型项目里更推荐 `package:` import，路径更稳定。

---

## 2. Dart 没有 default export

TypeScript：

```ts
export default ProductCard;
```

导入：

```ts
import ProductCard from './ProductCard';
```

Dart 没有默认导出。文件里的公开声明都可以被 import：

```dart
class ProductCard extends StatelessWidget {
  const ProductCard({super.key});

  @override
  Widget build(BuildContext context) {
    return const SizedBox();
  }
}
```

使用：

```dart
import 'package:rouzao_app/core/widgets/product_card.dart';

const ProductCard();
```

所以 Dart 更像：

```text
只使用 named export，没有 default export。
```

---

## 3. 公开与私有

TypeScript：

```ts
export function formatPrice() {}
function internalHelper() {}
```

Dart 不靠 `export` 关键字决定单个成员是否公开，而是靠命名。

公开：

```dart
String formatPrice(num value) {
  return '¥$value';
}
```

私有：

```dart
String _formatPriceInternal(num value) {
  return '¥$value';
}
```

Dart 中以下划线 `_` 开头的标识符是 library-private：

```text
只能在当前 Dart library 内访问。
```

通常一个 `.dart` 文件就是一个 library，除非使用 `part` 组合多个文件。

---

## 4. import prefix

TypeScript：

```ts
import * as productApi from './productApi';

productApi.fetchProducts();
```

Dart：

```dart
import 'package:rouzao_app/features/product/data/product_api.dart' as product_api;

product_api.fetchProducts();
```

适合处理命名冲突：

```dart
import 'dart:math' as math;

final value = math.max(1, 2);
```

---

## 5. show / hide

Dart 可以只导入部分符号：

```dart
import 'package:rouzao_app/core/theme/app_theme.dart' show AppColors;
```

也可以隐藏部分符号：

```dart
import 'package:rouzao_app/core/theme/app_theme.dart' hide AppTextStyles;
```

类比 TypeScript：

```ts
import { AppColors } from './appTheme';
```

但 Dart 的 `hide` 在 Web 前端里不常见。

---

## 6. export

TypeScript：

```ts
export { ProductCard } from './ProductCard';
export * from './types';
```

Dart：

```dart
export 'src/product_card.dart';
export 'src/product_model.dart';
```

这常用于 package 对外暴露 API，或者做 barrel 文件。

例如：

```text
lib/widgets.dart
```

```dart
export 'core/widgets/product_card.dart';
export 'core/widgets/empty_state.dart';
```

然后使用方可以：

```dart
import 'package:rouzao_app/widgets.dart';
```

不过在业务 Flutter App 里，过度 barrel export 可能让依赖来源不清晰，需要克制使用。

---

## 7. part / part of

Dart 还有前端开发者不太熟悉的：

```dart
part
part of
```

常见于代码生成。

源文件：

```dart
part 'product_model.g.dart';
part 'product_model.freezed.dart';
```

生成文件：

```dart
part of 'product_model.dart';
```

它表示这些文件共同组成同一个 Dart library。

这不是普通 import/export，而是把多个文件拼成一个 library 单元。

Flutter 项目里常见于：

```text
json_serializable
freezed
riverpod_generator
drift
```

---

## 8. 条件导入

Web 项目里可能用构建工具做平台差异：

```ts
if (isBrowser) {
  // browser code
}
```

Dart 支持条件导入：

```dart
import 'storage_stub.dart'
    if (dart.library.io) 'storage_io.dart'
    if (dart.library.html) 'storage_web.dart';
```

适合跨平台差异实现。

---

一句话理解：

```text
TypeScript 用 ES Module 的 import/export/default export 组织模块；
Dart 用 import/export 组织 library，
没有 default export，
用 _ 前缀表达私有，
用 part 配合代码生成，
用 package import 保持 Flutter 项目路径稳定。
```
