# Browser Target vs iOS / Android Target

Web 开发的目标运行环境是浏览器。

Flutter 移动端开发的目标运行环境是 iOS / Android App 容器。

两者都可以跑 UI 和业务逻辑，但平台能力、构建、调试、发布、权限、安全模型都不同。

可以这样映射：

| Browser Target         | iOS / Android Target                  |
| ---------------------- | ------------------------------------- |
| Chrome/Safari/Firefox  | iOS / Android                         |
| Browser runtime        | Flutter Engine + native host          |
| DOM/CSS                | Widget / RenderObject                 |
| Web APIs               | Flutter plugins / platform channels   |
| URL navigation         | Navigator / route stack               |
| localStorage/IndexedDB | shared_preferences / drift            |
| browser permissions    | native permissions                    |
| deploy to CDN          | App Store / Play Store / enterprise   |
| responsive viewport    | screen size / safe area / orientation |
| browser devtools       | Flutter DevTools + platform tools     |

---

## 1. Browser Target

Web App 运行在浏览器里：

```text
HTML
CSS
JavaScript
DOM
Web APIs
Browser security model
```

浏览器提供：

```text
fetch
localStorage
IndexedDB
Canvas
WebSocket
Geolocation
Clipboard
Notification
Service Worker
```

发布方式通常是：

```text
构建静态资源
部署到服务器/CDN
用户打开 URL
```

---

## 2. iOS / Android Target

Flutter App 运行在原生 App 容器中：

```text
Dart code
Flutter Framework
Flutter Engine
iOS/Android native host
platform plugins
```

平台提供：

```text
相机
相册
定位
推送
文件系统
安全存储
蓝牙
支付
分享
深链
传感器
```

这些能力通常通过 Flutter plugin 调用，而不是 Web API。

---

## 3. 渲染差异

Browser Target：

```text
HTML/CSS → DOM/CSSOM → Browser rendering
```

Flutter iOS/Android：

```text
Widget → Element → RenderObject → Flutter Engine → Skia/Impeller
```

所以 Flutter 不使用 DOM 和 CSS。

---

## 4. 权限差异

Web：

```ts
navigator.geolocation.getCurrentPosition(...)
```

浏览器弹权限提示。

Flutter：

```text
添加平台权限声明
运行时请求权限
处理用户拒绝
```

例如定位需要：

```text
iOS Info.plist
Android AndroidManifest.xml
permission_handler/geolocator plugin
```

移动端权限比 Web 更平台化。

---

## 5. 发布差异

Web：

```text
build → upload dist → CDN 生效
```

移动端：

```text
build → sign → upload App Store / Play Store → review → release
```

Flutter iOS/Android 发布涉及：

```text
Bundle ID / Application ID
签名证书
Provisioning Profile
版本号 build number
应用商店审核
灰度发布
崩溃监控
```

---

## 6. 更新差异

Web：

```text
部署新 bundle，用户刷新后获得新版本。
```

移动 App：

```text
用户需要通过应用商店更新；
有审核和发布节奏；
线上版本会长期共存。
```

这意味着 Flutter App 要更重视：

```text
接口兼容
本地数据库 migration
旧版本兼容
feature flag
灰度发布
```

---

## 7. 调试差异

Web：

```text
Browser DevTools
```

Flutter：

```text
Flutter DevTools
Xcode
Android Studio
adb
simulator/emulator logs
device logs
proxy 抓包
```

---

## 8. Flutter Web 例外

Flutter 也可以 target Web：

```bash
flutter build web
```

但 Flutter Web 不是传统 DOM/CSS App。它仍然用 Flutter 的渲染模型，只是运行在浏览器中。

---

一句话理解：

```text
Browser Target 面向浏览器、DOM、CSS 和 Web APIs；
iOS/Android Target 面向原生 App、Flutter Engine、平台权限和应用商店。
从 Web 转 Flutter 时，最大变化是：
运行环境从浏览器变成移动操作系统上的原生 App 容器。
```
