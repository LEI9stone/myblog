# Margin/Padding vs `Padding` / `Container.margin`

Web 里 `margin` 和 `padding` 都是 CSS Box Model 的一部分：

```text
margin：元素外部间距
padding：元素内部间距
```

Flutter 里没有所有 Widget 通用的 `margin` / `padding` 属性，而是通过 Widget 组合表达。

可以这样映射：

| CSS / Web           | Flutter                                             |
| ------------------- | --------------------------------------------------- |
| `padding`           | `Padding` / `Container.padding`                     |
| `margin`            | 外层 `Padding` / `Container.margin`                 |
| `padding: 16px`     | `EdgeInsets.all(16)`                                |
| `padding: 8px 12px` | `EdgeInsets.symmetric(vertical: 8, horizontal: 12)` |
| `margin-top`        | 外层 `Padding` / `SizedBox(height: ...)`            |
| `gap`               | `SizedBox` / `spacing`                              |
| collapse margin     | 无 margin collapse                                  |
| negative margin     | 无直接推荐写法，特殊情况用 `Transform` / `Stack`    |

---

## 1. Padding

Web：

```css
.card {
  padding: 16px;
}
```

Flutter：

```dart
Padding(
  padding: const EdgeInsets.all(16),
  child: child,
)
```

或者：

```dart
Container(
  padding: const EdgeInsets.all(16),
  child: child,
)
```

如果只是加内边距，更推荐 `Padding`，表达更明确。

---

## 2. Margin

Web：

```css
.card {
  margin: 12px;
}
```

Flutter：

```dart
Container(
  margin: const EdgeInsets.all(12),
  child: child,
)
```

或者用外层 `Padding` 表达外部间距：

```dart
Padding(
  padding: const EdgeInsets.all(12),
  child: child,
)
```

在 Flutter 里，`margin` 可以理解为：

```text
Container 提供的便利属性；
本质上相当于在外面包一层 Padding。
```

---

## 3. EdgeInsets 写法

CSS：

```css
padding: 16px;
```

Dart：

```dart
const EdgeInsets.all(16)
```

CSS：

```css
padding: 8px 12px;
```

Dart：

```dart
const EdgeInsets.symmetric(
  vertical: 8,
  horizontal: 12,
)
```

CSS：

```css
padding: 4px 8px 12px 16px;
```

Dart：

```dart
const EdgeInsets.fromLTRB(16, 4, 8, 12)
```

注意顺序不同：

```text
CSS: top right bottom left
Flutter fromLTRB: left top right bottom
```

单边：

```dart
const EdgeInsets.only(top: 12)
```

---

## 4. 垂直间距

Web：

```css
.title {
  margin-bottom: 8px;
}
```

Flutter 常见：

```dart
Column(
  crossAxisAlignment: CrossAxisAlignment.start,
  children: const [
    Text('Title'),
    SizedBox(height: 8),
    Text('Subtitle'),
  ],
)
```

或者新版本：

```dart
Column(
  spacing: 8,
  children: const [
    Text('Title'),
    Text('Subtitle'),
  ],
)
```

对于列表项之间的间距，也常用：

```dart
ListView.separated(
  itemCount: items.length,
  separatorBuilder: (context, index) => const SizedBox(height: 12),
  itemBuilder: (context, index) => ItemCard(item: items[index]),
)
```

---

## 5. 没有 margin collapse

Web 中块级元素垂直 margin 可能发生折叠：

```css
h1 {
  margin-bottom: 16px;
}

p {
  margin-top: 12px;
}
```

实际间距不一定是 `28px`，可能发生 margin collapse。

Flutter 没有 margin collapse。

你写：

```dart
Column(
  children: const [
    Padding(
      padding: EdgeInsets.only(bottom: 16),
      child: Text('Title'),
    ),
    Padding(
      padding: EdgeInsets.only(top: 12),
      child: Text('Subtitle'),
    ),
  ],
)
```

两个间距会直接叠加。

所以 Flutter 中更推荐统一由父级管理间距：

```dart
Column(
  spacing: 16,
  children: const [
    Text('Title'),
    Text('Subtitle'),
  ],
)
```

或者用中间的 `SizedBox`。

---

## 6. 负 margin

Web：

```css
.badge {
  margin-top: -8px;
}
```

Flutter 没有推荐的负 margin API。

常见替代：

```dart
Transform.translate(
  offset: const Offset(0, -8),
  child: Badge(),
)
```

或者用：

```dart
Stack
Positioned
```

表达重叠布局。

---

一句话理解：

```text
Web 的 margin/padding 是 CSS 盒模型属性；
Flutter 的 padding/margin 是通过 Widget 组合表达：
内部间距用 Padding，
外部间距用外层 Padding 或 Container.margin，
元素之间的间距常用 SizedBox、spacing 或 ListView.separated。
```
