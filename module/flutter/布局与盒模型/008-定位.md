# `position: absolute/fixed/sticky` vs `Positioned` / `Overlay` / `Sliver`

Web 里用 `position` 控制元素脱离普通文档流后的定位方式：

```css
position: absolute;
position: fixed;
position: sticky;
```

Flutter 没有 CSS `position`，对应场景通常分别用：

```dart
Positioned
Overlay
SliverPersistentHeader / SliverAppBar
```

可以这样映射：

| CSS Position            | Flutter                                                 |
| ----------------------- | ------------------------------------------------------- |
| `absolute`              | `Stack` + `Positioned`                                  |
| `relative` 定位上下文   | `Stack`                                                 |
| `fixed`                 | `Overlay` / `Scaffold` 固定槽位 / route overlay         |
| `sticky`                | `SliverPersistentHeader` / `SliverAppBar(pinned: true)` |
| `inset: 0`              | `Positioned.fill`                                       |
| `top/right/bottom/left` | `Positioned(top/right/bottom/left)`                     |
| 全局弹层                | `OverlayEntry` / `showDialog` / `showModalBottomSheet`  |
| 吸顶导航                | `SliverAppBar` / `SliverPersistentHeader`               |

---

## 1. `absolute` vs `Stack + Positioned`

Web：

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

Flutter：

```dart
Stack(
  children: [
    ProductImage(),
    Positioned(
      top: 8,
      right: 8,
      child: Badge(),
    ),
  ],
)
```

映射心智：

```text
CSS: relative parent + absolute child
Flutter: Stack parent + Positioned child
```

---

## 2. `Positioned.fill` vs `inset: 0`

Web：

```css
.overlay {
  position: absolute;
  inset: 0;
}
```

Flutter：

```dart
Positioned.fill(
  child: ColoredBox(
    color: Colors.black38,
  ),
)
```

常用于：

```text
遮罩层
loading overlay
图片渐变层
全区域点击层
```

---

## 3. `fixed` vs `Scaffold` 固定区域

Web：

```css
.tabbar {
  position: fixed;
  bottom: 0;
}
```

Flutter 里如果是页面结构的一部分，优先用 `Scaffold`：

```dart
Scaffold(
  body: PageContent(),
  bottomNavigationBar: BottomNavigationBar(
    items: [],
  ),
)
```

顶部固定：

```dart
Scaffold(
  appBar: AppBar(
    title: const Text('Home'),
  ),
  body: PageContent(),
)
```

这比在整个页面外层套 `Stack + Positioned` 更符合 Flutter 页面结构。

---

## 4. `fixed` vs `Overlay`

Web 中很多固定层：

```text
toast
tooltip
dropdown
modal
global loading
```

Flutter 更适合用：

```text
Overlay
showDialog
showModalBottomSheet
SnackBar
```

例如弹窗：

```dart
showDialog(
  context: context,
  builder: (context) {
    return const AlertDialog(
      title: Text('Confirm'),
    );
  },
);
```

如果需要自定义浮层：

```dart
final entry = OverlayEntry(
  builder: (context) => Positioned(
    top: 80,
    right: 16,
    child: FloatingPanel(),
  ),
);

Overlay.of(context).insert(entry);
```

---

## 5. `sticky` vs Sliver

Web：

```css
.header {
  position: sticky;
  top: 0;
}
```

Flutter：

```dart
CustomScrollView(
  slivers: [
    SliverPersistentHeader(
      pinned: true,
      delegate: HeaderDelegate(),
    ),
    SliverList(...),
  ],
)
```

更简单的吸顶 AppBar：

```dart
CustomScrollView(
  slivers: [
    SliverAppBar(
      pinned: true,
      title: const Text('Products'),
    ),
    SliverList(...),
  ],
)
```

`pinned: true` 可以理解为：

```text
滚动到顶部后保持吸顶。
```

---

## 6. 怎么选

| 需求                      | Flutter 推荐                   |
| ------------------------- | ------------------------------ |
| 卡片角标、图片覆盖按钮    | `Stack + Positioned`           |
| 局部遮罩                  | `Stack + Positioned.fill`      |
| 底部 TabBar               | `Scaffold.bottomNavigationBar` |
| 顶部导航栏                | `Scaffold.appBar`              |
| 弹窗                      | `showDialog`                   |
| 底部弹层                  | `showModalBottomSheet`         |
| Toast/Snack               | `ScaffoldMessenger`            |
| Tooltip/Dropdown/全局浮层 | `OverlayEntry`                 |
| 吸顶 Header               | `SliverPersistentHeader`       |
| 吸顶 AppBar               | `SliverAppBar(pinned: true)`   |

一句话理解：

```text
CSS absolute 通常映射到 Stack + Positioned；
CSS fixed 通常映射到 Scaffold 固定槽位或 Overlay；
CSS sticky 通常映射到 SliverAppBar / SliverPersistentHeader。
```
