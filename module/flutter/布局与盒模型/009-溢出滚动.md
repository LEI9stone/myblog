# `overflow: scroll` vs `SingleChildScrollView` / `ListView` / `CustomScrollView`

Web 里给容器设置：

```css
overflow: scroll;
overflow-y: auto;
```

就可以让内容超出后滚动。

Flutter 里滚动不是一个样式属性，而是一类明确的滚动 Widget：

```dart
SingleChildScrollView
ListView
GridView
CustomScrollView
```

可以这样映射：

| Web                | Flutter                                   |
| ------------------ | ----------------------------------------- |
| `overflow-y: auto` | `SingleChildScrollView` / `ListView`      |
| `overflow-x: auto` | 横向 `SingleChildScrollView` / `ListView` |
| 长列表滚动         | `ListView.builder`                        |
| 网格滚动           | `GridView.builder`                        |
| 页面整体滚动       | `CustomScrollView` / `ListView`           |
| 多段复杂滚动       | `CustomScrollView` + Sliver               |
| scroll container   | ScrollView Widget                         |
| sticky header      | SliverPersistentHeader                    |
| infinite scroll    | ScrollController / pagination state       |

---

## 1. Flutter 没有 `overflow: scroll`

Web：

```css
.panel {
  height: 400px;
  overflow-y: auto;
}
```

Flutter：

```dart
SizedBox(
  height: 400,
  child: SingleChildScrollView(
    child: Content(),
  ),
)
```

或者列表：

```dart
SizedBox(
  height: 400,
  child: ListView(
    children: [...],
  ),
)
```

在 Flutter 中：

```text
滚动能力来自 ScrollView Widget，
不是普通 Widget 的 overflow 属性。
```

---

## 2. SingleChildScrollView

适合一个整体内容块滚动：

```dart
SingleChildScrollView(
  child: Column(
    children: [
      Banner(),
      ProfileSection(),
      SettingsSection(),
    ],
  ),
)
```

适合：

```text
表单页
详情页
少量内容
内容高度不确定但不是长列表
```

不适合：

```text
大量列表项
上千条数据
分页商品流
```

因为它通常会把 child 整体布局出来。

---

## 3. ListView

适合列表滚动。

静态少量：

```dart
ListView(
  children: [
    ItemTile(),
    ItemTile(),
  ],
)
```

动态长列表：

```dart
ListView.builder(
  itemCount: items.length,
  itemBuilder: (context, index) {
    return ItemTile(item: items[index]);
  },
)
```

`ListView.builder` 类似 Web 里的虚拟列表思路：

```text
按需构建可见区域附近的 item。
```

---

## 4. 横向滚动

Web：

```css
.tabs {
  overflow-x: auto;
  white-space: nowrap;
}
```

Flutter：

```dart
SingleChildScrollView(
  scrollDirection: Axis.horizontal,
  child: Row(
    children: [
      TabChip(),
      TabChip(),
    ],
  ),
)
```

或者：

```dart
ListView.builder(
  scrollDirection: Axis.horizontal,
  itemCount: tabs.length,
  itemBuilder: (context, index) {
    return TabChip(tab: tabs[index]);
  },
)
```

---

## 5. CustomScrollView

如果页面由多个滚动段组成：

```text
Banner
分类入口
吸顶 Tab
商品网格
加载更多
```

更适合：

```dart
CustomScrollView(
  slivers: [
    SliverToBoxAdapter(child: Banner()),
    SliverToBoxAdapter(child: CategorySection()),
    SliverPersistentHeader(
      pinned: true,
      delegate: TabHeaderDelegate(),
    ),
    SliverGrid(...),
    SliverToBoxAdapter(child: LoadMoreFooter()),
  ],
)
```

它对应 Web 中较复杂的滚动页面，但实现方式不是简单嵌套多个 `overflow: auto` 容器，而是统一交给一个滚动视图管理。

---

## 6. 避免嵌套滚动混乱

Web 里常见多个容器各自滚动：

```css
.page {
  overflow-y: auto;
}

.sidebar {
  overflow-y: auto;
}
```

Flutter 中嵌套多个滚动 Widget 容易出现：

```text
高度无界
滚动冲突
性能问题
手势冲突
```

常见解决方式：

```dart
shrinkWrap: true
physics: NeverScrollableScrollPhysics()
```

但更推荐从结构上改成：

```text
单一 CustomScrollView + Sliver 组合
```

---

## 7. 怎么选

| 场景             | 推荐                                 |
| ---------------- | ------------------------------------ |
| 单块内容需要滚动 | `SingleChildScrollView`              |
| 普通长列表       | `ListView.builder`                   |
| 分隔列表         | `ListView.separated`                 |
| 横向少量内容     | 横向 `SingleChildScrollView` + `Row` |
| 横向长列表       | 横向 `ListView.builder`              |
| 网格列表         | `GridView.builder`                   |
| 多段复杂页面     | `CustomScrollView` + Sliver          |
| 吸顶/折叠头部    | `CustomScrollView` + Sliver          |

一句话理解：

```text
Web 用 overflow: scroll 让容器滚动；
Flutter 用明确的滚动 Widget：
单块内容用 SingleChildScrollView，
长列表用 ListView.builder，
复杂组合滚动用 CustomScrollView + Sliver。
```
