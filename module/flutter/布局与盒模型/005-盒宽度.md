# Width/Height vs Constraints

Web 里经常直接给元素写：

```css
width: 200px;
height: 100px;
```

Flutter 里也可以写 `width` / `height`，但底层真正决定布局的是 Constraints，也就是父级给子级的尺寸约束。

可以这样映射：

| CSS / Web      | Flutter                                      |
| -------------- | -------------------------------------------- |
| `width`        | `SizedBox(width)` / `Container(width)`       |
| `height`       | `SizedBox(height)` / `Container(height)`     |
| `min-width`    | `BoxConstraints(minWidth)`                   |
| `max-width`    | `BoxConstraints(maxWidth)`                   |
| `min-height`   | `BoxConstraints(minHeight)`                  |
| `max-height`   | `BoxConstraints(maxHeight)`                  |
| `width: 100%`  | `double.infinity` / `Expanded` / constraints |
| `height: auto` | child natural size under constraints         |
| intrinsic size | `IntrinsicWidth` / `IntrinsicHeight`，少用   |
| viewport size  | `MediaQuery.sizeOf(context)`                 |

---

## 1. Web 的 width/height

Web：

```css
.card {
  width: 200px;
  height: 100px;
}
```

浏览器会结合：

```text
盒模型
父容器
display 类型
position
min/max
overflow
box-sizing
```

计算最终尺寸。

---

## 2. Flutter 的 width/height 只是“请求尺寸”

Flutter：

```dart
Container(
  width: 200,
  height: 100,
  child: child,
)
```

或更明确：

```dart
SizedBox(
  width: 200,
  height: 100,
  child: child,
)
```

但这个尺寸不是绝对命令，而是受父级约束影响。

如果父级不允许 200 宽，子级就不能真的变成 200。

核心规则：

```text
父级给约束；
子级在约束内选择尺寸；
父级决定子级位置。
```

---

## 3. Constraints 是什么

Flutter 中约束通常包括：

```text
minWidth
maxWidth
minHeight
maxHeight
```

可以理解为父级对子级说：

```text
你的宽度必须在 minWidth 到 maxWidth 之间；
你的高度必须在 minHeight 到 maxHeight 之间。
```

例如：

```dart
BoxConstraints(
  minWidth: 100,
  maxWidth: 300,
  minHeight: 50,
  maxHeight: 200,
)
```

---

## 4. ConstrainedBox

Web：

```css
.card {
  min-width: 100px;
  max-width: 300px;
}
```

Flutter：

```dart
ConstrainedBox(
  constraints: const BoxConstraints(
    minWidth: 100,
    maxWidth: 300,
  ),
  child: child,
)
```

也可以用：

```dart
SizedBox(
  width: 200,
  child: child,
)
```

处理固定尺寸。

---

## 5. `width: 100%`

Web：

```css
.button {
  width: 100%;
}
```

Flutter 常见几种写法。

在有明确父约束时：

```dart
SizedBox(
  width: double.infinity,
  child: ElevatedButton(
    onPressed: onPressed,
    child: const Text('Submit'),
  ),
)
```

在 Row/Column 中占剩余空间：

```dart
Expanded(
  child: ElevatedButton(
    onPressed: onPressed,
    child: const Text('Submit'),
  ),
)
```

注意：

```text
double.infinity 不是“无限大”地画出去，
而是请求填满父级允许的最大宽度。
```

---

## 6. height auto

Web：

```css
.card {
  height: auto;
}
```

Flutter 通常不写高度，让 child 自己决定：

```dart
Container(
  padding: const EdgeInsets.all(16),
  child: Text(description),
)
```

或者：

```dart
Column(
  mainAxisSize: MainAxisSize.min,
  children: [...],
)
```

`mainAxisSize: MainAxisSize.min` 类似让 Column 主轴尺寸尽量贴合内容。

---

## 7. 常见布局报错

Flutter 中如果约束冲突，容易出现：

```text
BoxConstraints forces an infinite width
RenderFlex children have non-zero flex but incoming height constraints are unbounded
A RenderFlex overflowed by xx pixels
```

这些通常不是“宽高写错”这么简单，而是：

```text
某个 Widget 在没有明确边界的地方请求了无限尺寸；
或者 Row/Column 里的子元素没有得到合适约束。
```

典型修复：

```dart
Expanded
Flexible
SizedBox
ConstrainedBox
SingleChildScrollView
```

---

一句话理解：

```text
Web 开发常从 width/height 理解元素尺寸；
Flutter 要从 Constraints 理解布局：
width/height 只是子 Widget 的尺寸意图，
最终尺寸必须服从父级传下来的约束。
```
