# `min/max-width` vs `BoxConstraints`

Web 里用 `min-width`、`max-width`、`min-height`、`max-height` 控制元素尺寸边界。

Flutter 里对应的是 `BoxConstraints`，常通过 `ConstrainedBox`、`Container.constraints`、`SizedBox` 等 Widget 使用。

可以这样映射：

| CSS / Web      | Flutter                                    |
| -------------- | ------------------------------------------ |
| `min-width`    | `BoxConstraints(minWidth: ...)`            |
| `max-width`    | `BoxConstraints(maxWidth: ...)`            |
| `min-height`   | `BoxConstraints(minHeight: ...)`           |
| `max-height`   | `BoxConstraints(maxHeight: ...)`           |
| `width` 固定值 | tight constraints / `SizedBox(width: ...)` |
| `width: 100%`  | `maxWidth` 约束内填满 / `double.infinity`  |
| `width: auto`  | child 在约束内自然取尺寸                   |
| `clamp()`      | `constraints.constrain...` / `num.clamp()` |

---

## 1. Web 写法

```css
.card {
  min-width: 160px;
  max-width: 320px;
  min-height: 80px;
}
```

含义：

```text
宽度不能小于 160；
宽度不能大于 320；
高度不能小于 80。
```

---

## 2. Flutter 写法

```dart
ConstrainedBox(
  constraints: const BoxConstraints(
    minWidth: 160,
    maxWidth: 320,
    minHeight: 80,
  ),
  child: child,
)
```

也可以写在 `Container`：

```dart
Container(
  constraints: const BoxConstraints(
    minWidth: 160,
    maxWidth: 320,
  ),
  child: child,
)
```

不过如果只是约束，`ConstrainedBox` 意图更清晰。

---

## 3. 固定宽高其实也是约束

Web：

```css
width: 200px;
height: 100px;
```

Flutter：

```dart
SizedBox(
  width: 200,
  height: 100,
  child: child,
)
```

可以理解为给 child 一个 tight constraint：

```text
minWidth = maxWidth = 200
minHeight = maxHeight = 100
```

所以固定尺寸本质上也是一种约束。

---

## 4. 最大宽度容器

Web 常见：

```css
.container {
  max-width: 1200px;
  margin: 0 auto;
}
```

Flutter：

```dart
Center(
  child: ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 1200),
    child: PageContent(),
  ),
)
```

如果还要左右内边距：

```dart
Center(
  child: ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 1200),
    child: Padding(
      padding: const EdgeInsets.symmetric(horizontal: 16),
      child: PageContent(),
    ),
  ),
)
```

---

## 5. min/max 与父级约束的关系

Flutter 的 `BoxConstraints` 不是绝对命令，它仍然要和父级约束合并。

例如父级最大只给 300 宽：

```text
parent maxWidth = 300
child maxWidth = 500
```

最终 child 也不能超过 300。

也就是说：

```text
Flutter 中子级约束必须服从父级传下来的约束。
```

---

## 6. LayoutBuilder 里读取约束

如果需要根据可用宽度决定布局：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    final width = constraints.maxWidth;

    if (width < 360) {
      return CompactCard();
    }

    return RegularCard();
  },
)
```

这很像 Web 的 container query：

```css
@container (max-width: 360px) {
  ...
}
```

---

## 7. 常见约束工具

| Flutter Widget         | 用途                     |
| ---------------------- | ------------------------ |
| `ConstrainedBox`       | 添加 min/max 约束        |
| `SizedBox`             | 固定宽高或空白尺寸       |
| `LimitedBox`           | 在无界约束下限制最大尺寸 |
| `FractionallySizedBox` | 按父级比例取尺寸         |
| `AspectRatio`          | 固定宽高比               |
| `FittedBox`            | 缩放 child 适配空间      |
| `LayoutBuilder`        | 读取父级约束并分支布局   |

---

一句话理解：

```text
CSS 用 min/max-width 直接限制元素尺寸；
Flutter 用 BoxConstraints 表达 min/max 边界，
并且所有尺寸都必须在父级传下来的约束范围内协商出来。
```
