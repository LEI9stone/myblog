# `z-index` vs `Stack` 层级

Web 里用 `z-index` 控制元素在 z 轴上的叠放顺序。

Flutter 里没有通用的 `z-index` 属性，常见层级由 `Stack.children` 的顺序、`Overlay`、`Navigator`、`Material` elevation 等共同决定。

可以这样映射：

| Web                          | Flutter                                     |
| ---------------------------- | ------------------------------------------- |
| `z-index`                    | `Stack.children` 顺序                       |
| stacking context             | `Stack` / `Overlay` / route layer           |
| `position` + `z-index`       | `Stack` + child order                       |
| modal layer                  | `showDialog` / `Navigator` / `OverlayEntry` |
| fixed overlay                | `Overlay`                                   |
| box-shadow/elevation         | `Material.elevation` / shadow               |
| `transform` stacking context | 绘制顺序 + layer                            |
| `pointer-events`             | `IgnorePointer` / `AbsorbPointer`           |

---

## 1. Stack 的绘制顺序

Web：

```css
.background {
  z-index: 1;
}

.badge {
  z-index: 2;
}
```

Flutter：

```dart
Stack(
  children: [
    Background(), // 先绘制，在下面
    Badge(),      // 后绘制，在上面
  ],
)
```

规则很简单：

```text
Stack.children 越靠后，视觉层级越高。
```

---

## 2. Positioned 不决定层级

Flutter 中 `Positioned` 只负责位置，不负责层级。

```dart
Stack(
  children: [
    Positioned(
      top: 0,
      child: A(),
    ),
    Positioned(
      top: 0,
      child: B(),
    ),
  ],
)
```

如果 A 和 B 重叠：

```text
B 在 A 上面
```

因为 B 在 children 列表里更靠后。

---

## 3. 没有局部 z-index 数字

Web 可以：

```css
.modal {
  z-index: 1000;
}

.toast {
  z-index: 2000;
}
```

Flutter 不通过数字层级管理普通 Widget。

如果你想让某个元素在另一个元素上面，通常：

```text
调整 Stack children 顺序
放到更外层 Stack
使用 Overlay
使用 Navigator 弹层
```

---

## 4. Overlay 对应全局浮层

Web：

```text
modal / tooltip / dropdown / toast
```

常用高 `z-index`。

Flutter 中常用：

```dart
OverlayEntry
showDialog
showModalBottomSheet
Navigator
```

例如：

```dart
showDialog(
  context: context,
  builder: (context) => const AlertDialog(
    title: Text('Confirm'),
  ),
)
```

这类浮层不依赖当前局部 `Stack`，而是在更高的 overlay/route 层显示。

---

## 5. elevation 不是 z-index

Flutter Material 里有：

```dart
Card(
  elevation: 4,
  child: child,
)
```

`elevation` 主要影响阴影和 Material 视觉层级，不等于 CSS `z-index`。

它不会让一个 Widget 自动覆盖所有后面的 Widget。

简单理解：

```text
z-index 控制叠放顺序；
elevation 控制 Material 阴影和视觉高度。
```

---

## 6. 点击命中顺序

在 `Stack` 中，如果多个元素重叠，通常上层元素先参与命中测试。

如果要让上层元素不拦截点击，可以用：

```dart
IgnorePointer(
  child: OverlayDecoration(),
)
```

如果要吸收点击但不传给下面：

```dart
AbsorbPointer(
  child: BlockingLayer(),
)
```

对应 Web：

```css
pointer-events: none;
```

大致映射为：

```dart
IgnorePointer
```

---

## 7. 常见用法

图片角标：

```dart
Stack(
  children: [
    ProductImage(),
    Positioned(
      top: 8,
      right: 8,
      child: DiscountBadge(),
    ),
  ],
)
```

遮罩层：

```dart
Stack(
  children: [
    Content(),
    Positioned.fill(
      child: ColoredBox(
        color: Colors.black38,
      ),
    ),
    Center(
      child: LoadingIndicator(),
    ),
  ],
)
```

---

一句话理解：

```text
Web 用 z-index 数字控制层级；
Flutter 局部层级主要由 Stack.children 顺序决定，
越靠后的 child 越在上面；
全局弹层用 Overlay、Dialog、BottomSheet 或 Navigator。
```
