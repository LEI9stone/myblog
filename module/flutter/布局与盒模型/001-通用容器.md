# `div` 容器 vs `Container` / `SizedBox` / `Padding`

Web 里 `<div>` 是最常用的通用容器。

Flutter 里没有真正等价的 `<div>`。常见替代不是一个 Widget，而是一组按职责选择的 Widget：

| Web `<div>` 用途     | Flutter                                   |
| -------------------- | ----------------------------------------- |
| 包一层结构           | 自定义 Widget / `Builder` / 普通父 Widget |
| 设置宽高             | `SizedBox`                                |
| 设置 padding         | `Padding`                                 |
| 设置 margin          | `Container.margin` / 外层 `Padding`       |
| 设置背景色           | `ColoredBox` / `Container`                |
| 设置边框、圆角、阴影 | `DecoratedBox` / `Container.decoration`   |
| 横向排列             | `Row`                                     |
| 纵向排列             | `Column`                                  |
| 居中                 | `Center`                                  |
| 对齐                 | `Align`                                   |
| 点击容器             | `GestureDetector` / `InkWell`             |
| 滚动容器             | `SingleChildScrollView` / `ListView`      |

---

## 1. 不要把所有 `div` 都翻译成 `Container`

Web：

```html
<div class="card">
  <div class="title">Product</div>
</div>
```

Flutter 初学者容易写成：

```dart
Container(
  child: Container(
    child: Text('Product'),
  ),
)
```

但 Flutter 更推荐按目的拆：

```dart
Padding(
  padding: const EdgeInsets.all(16),
  child: Text('Product'),
)
```

如果只是加间距，就用 `Padding`，不需要 `Container`。

---

## 2. 只设置尺寸：`SizedBox`

Web：

```html
<div style="width: 100px; height: 40px"></div>
```

Flutter：

```dart
const SizedBox(
  width: 100,
  height: 40,
)
```

如果只是留空白：

```dart
const SizedBox(height: 12)
```

比空 `Container` 更清晰。

---

## 3. 只设置内边距：`Padding`

Web：

```css
.box {
  padding: 16px;
}
```

Flutter：

```dart
Padding(
  padding: const EdgeInsets.all(16),
  child: child,
)
```

---

## 4. 背景、边框、圆角：`Container` / `DecoratedBox`

Web：

```css
.card {
  background: white;
  border: 1px solid #eee;
  border-radius: 8px;
}
```

Flutter：

```dart
Container(
  decoration: BoxDecoration(
    color: Colors.white,
    border: Border.all(color: const Color(0xFFEEEEEE)),
    borderRadius: BorderRadius.circular(8),
  ),
  child: child,
)
```

如果只需要背景色：

```dart
ColoredBox(
  color: Colors.white,
  child: child,
)
```

---

## 5. margin 的心智差异

Web：

```css
.card {
  margin: 12px;
}
```

Flutter 可以写：

```dart
Container(
  margin: const EdgeInsets.all(12),
  child: child,
)
```

也可以更显式：

```dart
Padding(
  padding: const EdgeInsets.all(12),
  child: child,
)
```

在 Flutter 中，`margin` 不是所有 Widget 的通用属性，它只是 `Container` 提供的便利能力。

---

## 6. Container 是便利组合，不是基础容器

`Container` 可以同时做很多事：

```dart
Container(
  width: 200,
  height: 80,
  margin: const EdgeInsets.all(12),
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(8),
  ),
  child: const Text('Product'),
)
```

它很方便，但也容易滥用。

更 Flutter 的写法是：

```text
只要尺寸：SizedBox
只要间距：Padding
只要背景：ColoredBox
只要装饰：DecoratedBox
多个职责组合时：Container
```

---

一句话理解：

```text
div 是 Web 的通用结构容器；
Flutter 没有万能 div，
而是用 SizedBox、Padding、Container、DecoratedBox、Row、Column 等 Widget 按职责组合 UI。
```
