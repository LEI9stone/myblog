# Request Cancellation vs `CancelToken`

Web 里取消请求常用：

```ts
AbortController
AbortSignal
axios cancel
```

Flutter/Dart 中如果使用 `dio`，对应的是：

```dart
CancelToken
```

它可以取消尚未完成的 HTTP 请求，常用于搜索、页面离开、重复请求去重等场景。

可以这样映射：

| Web                    | Flutter / Dio                     |
| ---------------------- | --------------------------------- |
| `AbortController`      | `CancelToken`                     |
| `AbortSignal`          | `cancelToken`                     |
| `controller.abort()`   | `cancelToken.cancel()`            |
| request aborted error  | `DioExceptionType.cancel`         |
| cancel on unmount      | `dispose()` 中 cancel             |
| cancel previous search | 保存旧 `CancelToken` 并 cancel    |
| route leave cleanup    | provider dispose / widget dispose |

---

## 1. Web AbortController

Web fetch：

```ts
const controller = new AbortController();

fetch('/api/search', {
  signal: controller.signal,
});

controller.abort();
```

React 中常见：

```tsx
useEffect(() => {
  const controller = new AbortController();

  fetch('/api/products', {
    signal: controller.signal,
  });

  return () => controller.abort();
}, []);
```

---

## 2. Dio CancelToken

Flutter / Dio：

```dart
final cancelToken = CancelToken();

dio.get(
  '/search',
  queryParameters: {'keyword': keyword},
  cancelToken: cancelToken,
);

cancelToken.cancel('cancel search request');
```

如果请求被取消，会抛出 `DioException`，类型通常是：

```dart
DioExceptionType.cancel
```

判断：

```dart
try {
  await dio.get('/search', cancelToken: cancelToken);
} on DioException catch (error) {
  if (error.type == DioExceptionType.cancel) {
    return;
  }

  rethrow;
}
```

## 3. 搜索场景：取消上一次请求

Web 搜索输入常见：

```text
用户快速输入
取消旧请求
只保留最后一次搜索
```

Dio：

```dart
CancelToken? searchCancelToken;

Future<void> search(String keyword) async {
  searchCancelToken?.cancel('new search started');

  final token = CancelToken();
  searchCancelToken = token;

  try {
    final response = await dio.get(
      '/search',
      queryParameters: {'keyword': keyword},
      cancelToken: token,
    );

    // handle response
  } on DioException catch (error) {
    if (error.type == DioExceptionType.cancel) {
      return;
    }

    rethrow;
  }
}
```

## 4. 页面销毁时取消请求

Flutter `StatefulWidget`：

```dart
late final CancelToken cancelToken;

@override
void initState() {
  super.initState();
  cancelToken = CancelToken();
}

@override
void dispose() {
  cancelToken.cancel('page disposed');
  super.dispose();
}
```

Provider 中：

```dart
final productsProvider = FutureProvider.autoDispose((ref) async {
  final cancelToken = CancelToken();

  ref.onDispose(() {
    cancelToken.cancel('provider disposed');
  });

  final repository = ref.watch(productRepositoryProvider);

  return repository.fetchProducts(
    cancelToken: cancelToken,
  );
});
```

---

## 5. Repository 透传 CancelToken

```dart
class ProductRepository {
  ProductRepository(this.dio);

  final Dio dio;

  Future<List<Product>> fetchProducts({
    CancelToken? cancelToken,
  }) async {
    final response = await dio.get(
      '/products',
      cancelToken: cancelToken,
    );

    return parseProducts(response.data);
  }
}
```

这样页面或 provider 可以决定是否取消请求。

---

## 6. 取消不是失败态

请求取消通常不应该展示错误页。

例如：

```dart
on DioException catch (error) {
  if (error.type == DioExceptionType.cancel) {
    return;
  }

  state = AsyncError(error, stackTrace);
}
```

取消请求更多是：

```text
清理资源
避免旧请求覆盖新结果
页面离开时不再处理回调
```

---

## 7. 常见使用场景

适合取消请求：

```text
搜索关键字快速变化
筛选条件快速变化
页面离开
Tab 切换
重复点击刷新
只接受最新请求结果
大文件上传/下载手动取消
```

不一定需要取消：

```text
短小请求
提交订单这种必须完成的业务请求
服务端已经处理但客户端取消没有意义的操作
```

---

一句话理解：

```text
Web 用 AbortController 取消 fetch/axios 请求；
Dio 用 CancelToken 取消请求。
取消后要识别 DioExceptionType.cancel，
通常不展示错误态，
主要用于防止旧请求污染新状态或页面销毁后继续处理结果。
```
