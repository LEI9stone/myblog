# TypeScript DTO vs Dart Model

Web/TypeScript 中 DTO 通常用 `type` 或 `interface` 描述接口返回的数据结构。

Dart/Flutter 中通常用 `class`、`freezed class`、`json_serializable` model 来表达接口数据和业务模型。

可以这样映射：

| TypeScript DTO         | Dart Model                           |
| ---------------------- | ------------------------------------ |
| `interface ProductDto` | `class ProductDto`                   |
| `type Product = {}`    | `class Product` / Freezed model      |
| optional field         | nullable field                       |
| `string \| null`       | `String?`                            |
| `number`               | `int` / `double` / `num` / `Decimal` |
| `boolean`              | `bool`                               |
| array field            | `List<T>`                            |
| object field           | nested model                         |
| enum string            | `enum` + json mapping                |
| JSON mapper            | `fromJson` / `toJson`                |
| utility types          | `copyWith` / model split             |

---

## 1. TypeScript DTO

TypeScript：

```ts
type ProductDto = {
  id: string;
  title: string;
  price: number;
  imageUrl?: string | null;
};
```

这个类型主要在编译期工作。

运行时 API 返回的数据还是普通 JavaScript object。

---

## 2. Dart Model

Dart：

```dart
class ProductDto {
  const ProductDto({
    required this.id,
    required this.title,
    required this.price,
    this.imageUrl,
  });

  final String id;
  final String title;
  final double price;
  final String? imageUrl;

  factory ProductDto.fromJson(Map<String, dynamic> json) {
    return ProductDto(
      id: json['id'] as String,
      title: json['title'] as String,
      price: (json['price'] as num).toDouble(),
      imageUrl: json['imageUrl'] as String?,
    );
  }
}
```

Dart Model 是运行时代码的一部分，不只是类型声明。

---

## 3. json_serializable 写法

```dart
@JsonSerializable()
class ProductDto {
  const ProductDto({
    required this.id,
    required this.title,
    required this.price,
    this.imageUrl,
  });

  final String id;
  final String title;
  final double price;
  final String? imageUrl;

  factory ProductDto.fromJson(Map<String, dynamic> json) =>
      _$ProductDtoFromJson(json);

  Map<String, dynamic> toJson() => _$ProductDtoToJson(this);
}
```

需要：

```dart
part 'product_dto.g.dart';
```

然后运行：

```bash
dart run build_runner build
```

## 4. Freezed Model

复杂业务模型常用 Freezed：

```dart
@freezed
abstract class ProductDto with _$ProductDto {
  const factory ProductDto({
    required String id,
    required String title,
    required double price,
    String? imageUrl,
  }) = _ProductDto;

  factory ProductDto.fromJson(Map<String, dynamic> json) =>
      _$ProductDtoFromJson(json);
}
```

它会生成：

```text
fromJson / toJson
copyWith
==
hashCode
toString
不可变字段
```

## 5. DTO vs Domain Model

Web 中有时直接把 DTO 当业务类型用。

Flutter 中更推荐区分：

```text
DTO：接口数据结构
Domain Model：App 内业务模型
```

例如：

```dart
class ProductDto {
  final String productId;
  final int priceCent;
}
```

转换成：

```dart
class Product {
  final String id;
  final Decimal price;
}
```

Mapper：

```dart
extension ProductDtoMapper on ProductDto {
  Product toDomain() {
    return Product(
      id: productId,
      price: Decimal.fromInt(priceCent) / Decimal.fromInt(100),
    );
  }
}
```

## 6. 数字类型注意

TypeScript：

```ts
price: number;
```

Dart 要更明确：

| 场景        | Dart      |
| ----------- | --------- |
| 整数        | `int`     |
| 小数        | `double`  |
| 不确定数字  | `num`     |
| 金额/高精度 | `Decimal` |

价格类数据不建议随意用 `double` 做精确计算，电商场景更适合：

```dart
Decimal
int cents
```

---

## 7. Optional 字段

TypeScript：

```ts
imageUrl?: string | null
```

Dart：

```dart
final String? imageUrl;
```

Dart 没有 `undefined`，字段缺失或 JSON null 通常都映射成 `null`。

如果需要区分“字段缺失”和“字段为 null”，需要自定义解析逻辑。

---

## 8. 推荐结构

```text
features/product/
  data/
    models/
      product_dto.dart
    repositories/
      product_repository.dart
  domain/
    models/
      product.dart
```

小项目可以合并 DTO 和 domain model；复杂业务建议拆分。

---

一句话理解：

```text
TypeScript DTO 多数是编译期类型声明；
Dart Model 是真实的运行时代码，
通常用 class/freezed + json_serializable 表达。
简单项目可以 DTO=Model，
复杂项目更推荐 DTO 和 Domain Model 分层。
```
