# fetch / axios vs dio

Web 里常用：

```ts
fetch;
axios;
```

Flutter/Dart 里常用：

```dart
dio
http
```

其中 `dio` 更接近 axios，支持拦截器、全局配置、请求取消、超时、FormData、文件上传下载等能力。

可以这样映射：

| Web                  | Flutter / Dart                      |
| -------------------- | ----------------------------------- |
| `fetch`              | `http` package / `dio`              |
| `axios`              | `dio`                               |
| axios instance       | Dio instance                        |
| baseURL              | `BaseOptions(baseUrl: ...)`         |
| headers              | `Options(headers: ...)`             |
| interceptors         | `dio.interceptors`                  |
| request cancellation | `CancelToken`                       |
| timeout              | `connectTimeout` / `receiveTimeout` |
| FormData             | `FormData`                          |
| file upload          | `MultipartFile`                     |
| response.data        | `response.data`                     |
| HTTP error handling  | `DioException`                      |

---

## 1. fetch

Web：

```ts
const response = await fetch('/api/products');
const data = await response.json();
```

Dart 如果用基础 `http` 包会比较接近：

```dart
final response = await http.get(Uri.parse('/api/products'));
final data = jsonDecode(response.body);
```

但 Flutter 业务项目里如果需要更完整能力，常用 `dio`。

---

## 2. axios vs dio

axios：

```ts
const api = axios.create({
  baseURL: 'https://api.example.com',
  timeout: 10000,
});

const response = await api.get('/products');
const data = response.data;
```

dio：

```dart
final dio = Dio(
  BaseOptions(
    baseUrl: 'https://api.example.com',
    connectTimeout: const Duration(seconds: 10),
    receiveTimeout: const Duration(seconds: 10),
  ),
);

final response = await dio.get('/products');
final data = response.data;
```

心智非常接近：

```text
axios instance
≈ Dio instance
```

---

## 3. GET / POST

axios：

```ts
await api.get('/products', {
  params: { page: 1 },
});

await api.post('/orders', {
  productId: '123',
});
```

dio：

```dart
await dio.get(
  '/products',
  queryParameters: {
    'page': 1,
  },
);

await dio.post(
  '/orders',
  data: {
    'productId': '123',
  },
);
```

---

## 4. Headers

axios：

```ts
await api.get('/profile', {
  headers: {
    Authorization: `Bearer ${token}`,
  },
});
```

dio：

```dart
await dio.get(
  '/profile',
  options: Options(
    headers: {
      'Authorization': 'Bearer $token',
    },
  ),
);
```

通常 token 会放到 interceptor 里统一处理。

---

## 5. Interceptor

axios：

```ts
api.interceptors.request.use((config) => {
  config.headers.Authorization = `Bearer ${token}`;
  return config;
});
```

dio：

```dart
dio.interceptors.add(
  InterceptorsWrapper(
    onRequest: (options, handler) {
      options.headers['Authorization'] = 'Bearer $token';
      handler.next(options);
    },
    onError: (error, handler) {
      handler.next(error);
    },
  ),
);
```

适合：

```text
添加 token
统一日志
统一错误处理
刷新 token
请求签名
```

---

## 6. 错误处理

axios：

```ts
try {
  await api.get('/products');
} catch (error) {
  if (axios.isAxiosError(error)) {
    console.log(error.response?.status);
  }
}
```

dio：

```dart
try {
  await dio.get('/products');
} on DioException catch (error) {
  final statusCode = error.response?.statusCode;
  final data = error.response?.data;
}
```

Dio 错误统一是：

```dart
DioException
```

里面包含：

```text
requestOptions
response
type
error
stackTrace
```

---

## 7. Cancel Token

axios：

```ts
const controller = new AbortController();

await fetch('/search', {
  signal: controller.signal,
});

controller.abort();
```

dio：

```dart
final cancelToken = CancelToken();

dio.get(
  '/search',
  cancelToken: cancelToken,
);

cancelToken.cancel('cancel search request');
```

适合：

```text
搜索输入快速变化
页面离开取消请求
重复请求去重
```

---

## 8. 文件上传

axios：

```ts
const formData = new FormData();
formData.append('file', file);

await api.post('/upload', formData);
```

dio：

```dart
final formData = FormData.fromMap({
  'file': await MultipartFile.fromFile(filePath),
});

await dio.post(
  '/upload',
  data: formData,
);
```

## 9. 在 Flutter 项目中的位置

通常不要在 Widget 里直接写 dio 请求。

推荐：

```text
core/network/dio_provider.dart
features/product/data/product_repository.dart
```

例如：

```dart
class ProductRepository {
  ProductRepository(this.dio);

  final Dio dio;

  Future<List<Product>> fetchProducts() async {
    final response = await dio.get('/products');
    return parseProducts(response.data);
  }
}
```

UI 通过 provider/notifier 读取 repository 结果。

---

一句话理解：

```text
fetch 是浏览器原生请求 API；
axios 是 Web 常用高级 HTTP client；
dio 是 Flutter/Dart 里最接近 axios 的 HTTP client，
支持实例配置、拦截器、超时、取消、上传下载和统一错误处理。
```
