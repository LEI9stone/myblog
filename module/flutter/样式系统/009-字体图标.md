# SVG / IconFont / Image vs `flutter_svg` / `Icon` / `Image`

Web 里常用：

```text
SVG
IconFont
img
background-image
```

Flutter 里常用：

```dart
flutter_svg
Icon
Image
CachedNetworkImage
```

可以这样映射：

| Web                   | Flutter                                   |
| --------------------- | ----------------------------------------- |
| inline SVG            | `SvgPicture.string` / 自定义绘制          |
| `.svg` 文件           | `SvgPicture.asset` / `SvgPicture.network` |
| IconFont              | `Icon` / `IconData` / 自定义字体图标      |
| `<img>`               | `Image.asset` / `Image.network`           |
| `background-image`    | `DecorationImage`                         |
| `object-fit: cover`   | `BoxFit.cover`                            |
| `object-fit: contain` | `BoxFit.contain`                          |
| lazy image            | `CachedNetworkImage` / 自定义懒加载       |
| image placeholder     | placeholder Widget                        |
| broken image fallback | errorBuilder / errorWidget                |

---

## 1. SVG 文件

Web：

```html
<img src="/icons/search.svg" />
```

Flutter 需要依赖：

```yaml
flutter_svg: ^2.x.x
```

使用：

```dart
SvgPicture.asset(
  'assets/icons/ic_search.svg',
  width: 24,
  height: 24,
)
```

网络 SVG：

```dart
SvgPicture.network(
  'https://example.com/icon.svg',
)
```

当前项目中如果已经声明：

```yaml
flutter:
  assets:
    - assets/icons/
```

就可以直接使用：

```dart
SvgPicture.asset('assets/icons/ic_search.svg')
```

---

## 2. Icon

Web IconFont：

```html
<i class="icon icon-search"></i>
```

Flutter Material 图标：

```dart
Icon(
  Icons.search,
  size: 24,
  color: Colors.black,
)
```

按钮图标：

```dart
IconButton(
  icon: const Icon(Icons.search),
  onPressed: onSearch,
)
```

Flutter 的 `Icon` 本质上是基于字体图标：

```text
IconData + Icon font
```

如果使用 Material Icons，需要：

```yaml
flutter:
  uses-material-design: true
```

---

## 3. 自定义 IconFont

Web 中可能有：

```css
@font-face {
  font-family: 'iconfont';
}
```

Flutter 也可以注册字体：

```yaml
flutter:
  fonts:
    - family: AppIcons
      fonts:
        - asset: assets/fonts/app_icons.ttf
```

然后定义：

```dart
class AppIcons {
  static const search = IconData(
    0xe001,
    fontFamily: 'AppIcons',
  );
}
```

使用：

```dart
const Icon(AppIcons.search)
```

不过在 Flutter 项目里，如果已有 SVG 图标资源，通常直接用 `flutter_svg` 更直观。

---

## 4. 图片资源

Web：

```html
<img src="/images/banner.png" />
```

Flutter 本地图片：

```dart
Image.asset(
  'assets/images/banner.png',
)
```

网络图片：

```dart
Image.network(
  imageUrl,
)
```

常见尺寸和适配：

```dart
Image.network(
  imageUrl,
  width: double.infinity,
  height: 180,
  fit: BoxFit.cover,
)
```

对应 Web：

```css
width: 100%;
height: 180px;
object-fit: cover;
```

---

## 5. 背景图

Web：

```css
.card {
  background-image: url('/banner.png');
  background-size: cover;
  background-position: center;
}
```

Flutter：

```dart
Container(
  decoration: const BoxDecoration(
    image: DecorationImage(
      image: AssetImage('assets/images/banner.png'),
      fit: BoxFit.cover,
      alignment: Alignment.center,
    ),
  ),
)
```

网络背景图：

```dart
BoxDecoration(
  image: DecorationImage(
    image: NetworkImage(imageUrl),
    fit: BoxFit.cover,
  ),
)
```

## 6. 图片加载失败和占位

Flutter 原生网络图可以写：

```dart
Image.network(
  imageUrl,
  loadingBuilder: (context, child, loadingProgress) {
    if (loadingProgress == null) {
      return child;
    }

    return const CircularProgressIndicator();
  },
  errorBuilder: (context, error, stackTrace) {
    return const Icon(Icons.broken_image);
  },
)
```

实际项目里更常用：

```dart
CachedNetworkImage(
  imageUrl: imageUrl,
  placeholder: (context, url) => const LoadingSkeleton(),
  errorWidget: (context, url, error) => const Icon(Icons.broken_image),
)
```

## 7. 怎么选

| 场景               | 推荐                 |
| ------------------ | -------------------- |
| Material 内置图标  | `Icon(Icons.xxx)`    |
| 项目 SVG 图标      | `SvgPicture.asset`   |
| 自定义字体图标     | `IconData` + font    |
| 本地位图           | `Image.asset`        |
| 网络图片           | `Image.network`      |
| 需要缓存的网络图片 | `CachedNetworkImage` |
| 背景图             | `DecorationImage`    |
| 圆形头像           | `ClipOval` + `Image` |

一句话理解：

```text
Web 用 SVG、IconFont、img 和 background-image 表达图标与图片；
Flutter 中 SVG 用 flutter_svg，
字体图标用 Icon/IconData，
普通图片用 Image，
背景图用 BoxDecoration.image。
```
