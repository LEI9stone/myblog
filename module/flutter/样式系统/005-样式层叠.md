# CSS Cascade vs Flutter 显式样式传递

Web 里样式依赖 CSS Cascade，也就是层叠规则。一个元素最终样式可能来自浏览器默认样式、全局 CSS、父级继承、class、id、inline style、media query 等多个来源。

Flutter 没有 CSS 层叠系统。样式通常通过 Widget 参数、Theme、InheritedWidget 或组件封装显式传递。

| Web CSS Cascade       | Flutter                                  |
| --------------------- | ---------------------------------------- |
| CSS 层叠              | 显式 Widget 参数                         |
| selector 命中元素     | 无 selector                              |
| inheritance           | `Theme.of(context)` / `DefaultTextStyle` |
| global CSS            | `ThemeData` / App token                  |
| class 覆盖            | 组件参数覆盖                             |
| inline style 优先级高 | 构造参数直接决定                         |
| specificity           | 无 CSS specificity                       |
| `!important`          | 无直接等价                               |
| media query 覆盖样式  | `MediaQuery` / `LayoutBuilder` 分支      |
| CSS variable 继承     | `ThemeExtension` / `InheritedWidget`     |

---

## 1. Web 的 Cascade

Web：

```css
button {
  color: black;
}

.primary {
  color: blue;
}

#submit {
  color: red;
}
```

HTML：

```html
<button id="submit" class="primary">Submit</button>
```

最终颜色取决于：

```text
选择器优先级
声明顺序
继承关系
!important
浏览器默认样式
```

所以 Web 样式常见问题是：

```text
这个样式到底从哪里来的？
为什么被覆盖了？
为什么这个 class 不生效？
```

---

## 2. Flutter 没有 CSS 选择器

Flutter：

```dart
Text(
  'Submit',
  style: TextStyle(color: Colors.red),
)
```

这个 `Text` 的颜色直接由参数决定。

不会有某个全局 `.primary button span` 选择器突然影响它。

Flutter 更强调：

```text
样式从父 Widget、Theme 或构造参数显式传入。
```

---

## 3. Theme 是 Flutter 中最接近继承样式的机制

Web：

```css
body {
  color: #222;
  font-family: system-ui;
}
```

Flutter：

```dart
MaterialApp(
  theme: ThemeData(
    textTheme: const TextTheme(
      bodyMedium: TextStyle(
        color: Color(0xFF222222),
        fontSize: 14,
      ),
    ),
  ),
  home: const HomePage(),
)
```

使用：

```dart
Text(
  'Product',
  style: Theme.of(context).textTheme.bodyMedium,
)
```

这类似：

```text
从当前上下文读取全局主题样式。
```

---

## 4. DefaultTextStyle

Flutter 中 `Text` 可以继承 `DefaultTextStyle`：

```dart
DefaultTextStyle(
  style: const TextStyle(
    color: Colors.black,
    fontSize: 14,
  ),
  child: Column(
    children: const [
      Text('Title'),
      Text('Description'),
    ],
  ),
)
```

这有点像 CSS 里父元素的字体继承。

但范围更明确：

```text
只影响该 Widget 子树；
只影响会读取 DefaultTextStyle 的 Text；
不会像 CSS selector 那样任意命中。
```

---

## 5. 局部覆盖 Theme

Web：

```css
.dark-section {
  --text-color: white;
}
```

Flutter：

```dart
Theme(
  data: Theme.of(context).copyWith(
    textTheme: Theme.of(context).textTheme.apply(
      bodyColor: Colors.white,
      displayColor: Colors.white,
    ),
  ),
  child: const DarkSection(),
)
```

这表示：

```text
DarkSection 子树下使用局部 Theme。
```

对应 Web 心智：

```text
局部作用域里的变量或样式覆盖。
```

---

## 6. 组件参数替代 class 覆盖

Web：

```tsx
<Button className="primary large" />
```

Flutter 更常见：

```dart
AppButton(
  variant: AppButtonVariant.primary,
  size: AppButtonSize.large,
  onPressed: onSubmit,
  child: const Text('Submit'),
)
```

组件内部根据参数决定样式：

```dart
final backgroundColor = switch (variant) {
  AppButtonVariant.primary => AppColors.primary,
  AppButtonVariant.secondary => AppColors.secondary,
};
```

也就是说：

```text
Web 用 class 组合样式；
Flutter 用明确参数表达变体。
```

---

## 7. 没有 specificity 和 !important

Web 里经常遇到：

```css
.card .title {
  color: red !important;
}
```

Flutter 没有 `!important`。

如果样式不对，通常检查：

```text
这个 Widget 的 style 参数是什么？
有没有从 Theme 读取？
有没有被外层 DefaultTextStyle/Theme 覆盖？
组件内部有没有写死样式？
```

问题更偏“数据从哪里传进来”，而不是“选择器谁优先”。

---

一句话理解：

```text
CSS Cascade 是样式通过选择器、继承、优先级和声明顺序层叠到 DOM 上；
Flutter 没有 CSS 层叠，
样式通过 Widget 参数、Theme、DefaultTextStyle、InheritedWidget 和组件参数显式传递。
```
