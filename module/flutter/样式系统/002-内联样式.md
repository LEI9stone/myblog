# Inline Style vs Flutter Widget 构造参数

Web 里的 inline style 是直接在元素上写样式：

```tsx
<div style={{ padding: 16, color: 'red' }} />
```

Flutter 里没有 CSS inline style，但 Widget 的构造参数很像“显式样式参数”：

```dart
Container(
  padding: const EdgeInsets.all(16),
  color: Colors.red,
)
```

可以这样映射：

| Web Inline Style  | Flutter                                  |
| ----------------- | ---------------------------------------- |
| `style={{ ... }}` | Widget 构造参数                          |
| `padding`         | `padding: EdgeInsets...`                 |
| `margin`          | `margin: EdgeInsets...` / 外层 `Padding` |
| `color`           | `color` / `TextStyle.color`              |
| `backgroundColor` | `color` / `BoxDecoration.color`          |
| `borderRadius`    | `BorderRadius.circular(...)`             |
| `boxShadow`       | `BoxShadow`                              |
| `fontSize`        | `TextStyle(fontSize: ...)`               |
| `display`         | 选择 `Row` / `Column` / `Stack`          |
| `width/height`    | `SizedBox` / `Container(width/height)`   |

---

## 1. React inline style

React：

```tsx
<div
  style={{
    padding: 16,
    borderRadius: 8,
    backgroundColor: '#fff',
  }}
>
  Product
</div>
```

Flutter：

```dart
Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(8),
  ),
  child: const Text('Product'),
)
```

两者都很显式，但差异是：

```text
React inline style 是 CSS 属性对象；
Flutter 参数是强类型 Dart 对象。
```

---

## 2. 样式是强类型对象

Web：

```tsx
style={{ fontSize: 14 }}
```

Flutter：

```dart
const TextStyle(fontSize: 14)
```

Web：

```tsx
style={{ borderRadius: 8 }}
```

Flutter：

```dart
BorderRadius.circular(8)
```

Web：

```tsx
style={{ boxShadow: '0 4px 12px rgba(0,0,0,0.12)' }}
```

Flutter：

```dart
BoxShadow(
  color: Colors.black.withValues(alpha: 0.12),
  blurRadius: 12,
  offset: const Offset(0, 4),
)
```

Flutter 的样式通常不是字符串，而是明确类型。

---

## 3. 布局不是 style，而是 Widget

Web：

```tsx
<div style={{ display: 'flex', alignItems: 'center' }}>...</div>
```

Flutter：

```dart
Row(
  crossAxisAlignment: CrossAxisAlignment.center,
  children: [...],
)
```

这点很关键：

```text
Web 通过 style.display 切换布局模式；
Flutter 通过选择不同 Widget 表达布局。
```

所以不要找：

```dart
style: { display: 'flex' }
```

而是直接写：

```dart
Row
Column
Stack
Wrap
GridView
```

---

## 4. 样式复用方式不同

React inline style 如果到处复制，会变难维护。Flutter 也一样。

Flutter 通常通过：

```text
Theme
AppColors
AppTextStyles
自定义 Widget
extension/helper
```

复用样式。

例如：

```dart
Text(
  'Title',
  style: Theme.of(context).textTheme.titleMedium,
)
```

或：

```dart
AppCard(
  child: ProductInfo(),
)
```

---

## 5. 构造参数可以是行为参数

Flutter Widget 构造参数不只是样式，也包括：

```text
布局
内容
交互
状态
回调
语义
```

例如：

```dart
ElevatedButton(
  onPressed: onSubmit,
  style: ElevatedButton.styleFrom(
    minimumSize: const Size.fromHeight(48),
  ),
  child: const Text('Submit'),
)
```

对应 React：

```tsx
<button onClick={onSubmit} style={{ minHeight: 48 }}>
  Submit
</button>
```

---

## 6. const 构造参数

Flutter 中很多构造参数可以配合 `const`：

```dart
const Padding(
  padding: EdgeInsets.all(16),
  child: Text('Hello'),
)
```

这有利于减少不必要对象创建。

Web inline style 每次 render 创建对象时，可能还会影响 memo 比较；Flutter 里 `const` 是常用优化手段。

---

一句话理解：

```text
Web inline style 是写在元素上的 CSS 属性对象；
Flutter Widget 构造参数是强类型的 UI 配置。
样式、布局、交互都通过不同 Widget 和参数显式表达。
```
