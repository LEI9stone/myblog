# CSS Class vs Widget 参数

Web 里常用 CSS class 给元素挂样式：

```html
<div class="card primary"></div>
```

Flutter 里没有 `className` 和 CSS 选择器，样式通常直接通过 Widget 参数、`Theme`、自定义组件参数传入。

可以这样映射：

| Web                 | Flutter                                      |
| ------------------- | -------------------------------------------- |
| `class="card"`      | Widget 参数                                  |
| CSS selector        | 无直接等价                                   |
| `.card { ... }`     | `Container(decoration: ...)` / 自定义 Widget |
| `className`         | 无直接等价                                   |
| CSS Modules         | 局部 Widget 封装                             |
| Tailwind class      | 组合 Widget 参数                             |
| conditional class   | 条件传参 / 条件 Widget                       |
| design system class | Theme / AppTextStyles / AppColors            |
| variant class       | Widget variant 参数                          |

---

## 1. Web 的 CSS Class

Web：

```html
<div class="product-card featured">Product</div>
```

```css
.product-card {
  padding: 16px;
  border-radius: 8px;
}

.featured {
  border-color: red;
}
```

React 中：

```tsx
<div className="product-card featured">Product</div>
```

核心是：

```text
HTML/JSX 负责结构；
CSS class 负责样式。
```

---

## 2. Flutter 用 Widget 参数表达样式

Flutter：

```dart
Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circular(8),
    border: Border.all(color: Colors.red),
  ),
  child: const Text('Product'),
)
```

这里没有 `className`，样式直接由 Widget 参数描述：

```text
padding
decoration
color
borderRadius
TextStyle
alignment
constraints
```

---

## 3. class 复用 vs 自定义 Widget 复用

Web：

```css
.card {
  padding: 16px;
  border-radius: 8px;
  background: white;
}
```

Flutter 更常见是封装组件：

```dart
class AppCard extends StatelessWidget {
  const AppCard({
    super.key,
    required this.child,
  });

  final Widget child;

  @override
  Widget build(BuildContext context) {
    return Container(
      padding: const EdgeInsets.all(16),
      decoration: BoxDecoration(
        color: Colors.white,
        borderRadius: BorderRadius.circular(8),
      ),
      child: child,
    );
  }
}
```

使用：

```dart
AppCard(
  child: Text('Product'),
)
```

心智映射：

```text
Web 通过 class 复用样式；
Flutter 通过自定义 Widget 复用样式和结构。
```

---

## 4. 条件 class vs 条件参数

React：

```tsx
<div className={active ? 'tab active' : 'tab'}>Tab</div>
```

Flutter：

```dart
Container(
  decoration: BoxDecoration(
    color: active ? Colors.black : Colors.white,
  ),
  child: const Text('Tab'),
)
```

或者封装成参数：

```dart
AppTab(
  active: active,
  label: 'Tab',
)
```

---

## 5. Tailwind 类比

Web Tailwind：

```tsx
<div className="p-4 rounded-lg bg-white text-sm">Product</div>
```

Flutter：

```dart
Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(8),
  ),
  child: const Text(
    'Product',
    style: TextStyle(fontSize: 14),
  ),
)
```

Flutter 写法更显式，也更依赖组件封装减少重复。

---

## 6. Theme 负责全局样式

Web：

```css
:root {
  --primary-color: #111;
}
```

Flutter：

```dart
ThemeData(
  colorScheme: ColorScheme.fromSeed(
    seedColor: Colors.black,
  ),
)
```

使用：

```dart
Theme.of(context).colorScheme.primary
Theme.of(context).textTheme.titleMedium
```

项目中也常见：

```dart
AppColors.primary
AppTextStyles.title
AppTheme
```

---

一句话理解：

```text
Web 用 CSS class 把样式挂到 DOM 元素上；
Flutter 没有 className 和选择器，
样式通过 Widget 参数、Theme 和自定义 Widget 显式传递与复用。
```
