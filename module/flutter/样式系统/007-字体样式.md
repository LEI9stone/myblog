# Font/Text Style vs `TextStyle`

Web 里文本样式由 CSS 控制：

```css
font-size
font-weight
line-height
letter-spacing
color
text-align
```

Flutter 中对应的是：

```dart
TextStyle
Text
RichText
TextSpan
DefaultTextStyle
ThemeData.textTheme
```

可以这样映射：

| CSS Text / Font           | Flutter                       |
| ------------------------- | ----------------------------- |
| `font-size`               | `TextStyle.fontSize`          |
| `font-weight`             | `TextStyle.fontWeight`        |
| `line-height`             | `TextStyle.height`            |
| `letter-spacing`          | `TextStyle.letterSpacing`     |
| `color`                   | `TextStyle.color`             |
| `font-family`             | `TextStyle.fontFamily`        |
| `text-align`              | `Text.textAlign`              |
| `text-decoration`         | `TextStyle.decoration`        |
| `font-style: italic`      | `TextStyle.fontStyle`         |
| `text-overflow: ellipsis` | `TextOverflow.ellipsis`       |
| `white-space: nowrap`     | `maxLines: 1`                 |
| typography scale          | `TextTheme` / `AppTextStyles` |

---

## 1. 基本文本样式

Web：

```css
.title {
  font-size: 18px;
  font-weight: 600;
  color: #111;
  line-height: 1.4;
}
```

Flutter：

```dart
Text(
  'Product',
  style: const TextStyle(
    fontSize: 18,
    fontWeight: FontWeight.w600,
    color: Color(0xFF111111),
    height: 1.4,
  ),
)
```

---

## 2. line-height 差异

Web：

```css
line-height: 20px;
```

Flutter 的 `height` 是字号倍数：

```dart
const TextStyle(
  fontSize: 14,
  height: 20 / 14,
)
```

如果 Web 是：

```css
font-size: 14px;
line-height: 20px;
```

Flutter 对应：

```dart
TextStyle(
  fontSize: 14,
  height: 1.428,
)
```

---

## 3. text-align

Web：

```css
text-align: center;
```

Flutter：

```dart
Text(
  'Title',
  textAlign: TextAlign.center,
)
```

注意 `textAlign` 是 `Text` 的参数，不是 `TextStyle` 的参数。

---

## 4. 文本省略

Web：

```css
.title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

Flutter：

```dart
Text(
  title,
  maxLines: 1,
  overflow: TextOverflow.ellipsis,
)
```

多行省略：

```dart
Text(
  description,
  maxLines: 2,
  overflow: TextOverflow.ellipsis,
)
```

---

## 5. Rich Text

Web：

```html
<p>Price: <strong>¥99</strong></p>
```

Flutter：

```dart
RichText(
  text: TextSpan(
    style: const TextStyle(
      color: Colors.black,
      fontSize: 14,
    ),
    children: [
      const TextSpan(text: 'Price: '),
      TextSpan(
        text: '¥99',
        style: const TextStyle(
          fontWeight: FontWeight.w700,
          color: Colors.red,
        ),
      ),
    ],
  ),
)
```

更常用：

```dart
Text.rich(
  TextSpan(
    children: [
      const TextSpan(text: 'Price: '),
      TextSpan(
        text: '¥99',
        style: const TextStyle(fontWeight: FontWeight.bold),
      ),
    ],
  ),
)
```

---

## 6. Theme text styles

Web 里可能有：

```css
.text-title {
}
.text-body {
}
.text-caption {
}
```

Flutter：

```dart
Theme.of(context).textTheme.titleMedium
Theme.of(context).textTheme.bodyMedium
Theme.of(context).textTheme.labelSmall
```

或者项目自定义：

```dart
AppTextStyles.title
AppTextStyles.body
AppTextStyles.caption
```

推荐把常用字号、字重、行高沉淀到主题或 token 中，而不是每处硬编码。

---

## 7. 字体资源

Web：

```css
@font-face {
  font-family: 'BrandFont';
  src: url('/fonts/BrandFont.woff2');
}
```

Flutter：

```yaml
flutter:
  fonts:
    - family: BrandFont
      fonts:
        - asset: assets/fonts/BrandFont.ttf
```

使用：

```dart
TextStyle(
  fontFamily: 'BrandFont',
)
```

---

一句话理解：

```text
Web 用 CSS 控制字体和文本样式；
Flutter 用 TextStyle 控制字体样式，
用 Text 参数控制对齐、省略等文本行为，
用 TextTheme/AppTextStyles 统一管理 typography。
```
