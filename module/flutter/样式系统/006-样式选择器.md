# CSS Selector vs Widget Composition

Web 里用 CSS Selector 选择 DOM 节点并应用样式：

```css
.card > .title:hover {
  color: red;
}
```

Flutter 没有 CSS Selector，也没有 DOM 节点选择器。Flutter 更依赖 Widget Composition，也就是通过组合 Widget 和传递参数来表达结构、样式和行为。

| Web CSS Selector    | Flutter Widget Composition       |
| ------------------- | -------------------------------- |
| `.card`             | `AppCard` Widget                 |
| `.card .title`      | `AppCard` 内部的 `Text`          |
| `.card > .title`    | 父子 Widget 组合                 |
| `.card:hover`       | `MouseRegion` / `InkWell` / 状态 |
| `.card.active`      | `AppCard(active: true)`          |
| `:first-child`      | 构建 children 时判断 index       |
| `:last-child`       | 构建 children 时判断 index       |
| `nth-child`         | `ListView.builder` index         |
| descendant selector | 明确传参 / 封装组件              |
| global selector     | Theme / 全局 Widget 封装         |

---

## 1. Web Selector 心智

Web：

```html
<div class="product-card active">
  <h3 class="title">Cup</h3>
  <p class="price">¥99</p>
</div>
```

```css
.product-card.active .title {
  color: red;
}
```

样式可以从外部通过 selector 命中内部 DOM。

---

## 2. Flutter 没有 selector

Flutter：

```dart
ProductCard(
  product: product,
  active: true,
)
```

组件内部决定怎么渲染：

```dart
class ProductCard extends StatelessWidget {
  const ProductCard({
    super.key,
    required this.product,
    required this.active,
  });

  final Product product;
  final bool active;

  @override
  Widget build(BuildContext context) {
    return Container(
      child: Text(
        product.title,
        style: TextStyle(
          color: active ? Colors.red : Colors.black,
        ),
      ),
    );
  }
}
```

也就是说：

```text
外部不能用 selector 随便命中 ProductCard 内部的 Text；
需要通过组件参数、Theme 或插槽式 child/builder 设计来控制。
```

---

## 3. class 组合 vs 参数组合

Web：

```tsx
<div className={clsx('card', active && 'active', disabled && 'disabled')} />
```

Flutter：

```dart
ProductCard(
  active: active,
  disabled: disabled,
)
```

组件内部：

```dart
final opacity = disabled ? 0.4 : 1.0;
final borderColor = active ? Colors.red : Colors.transparent;
```

心智变化：

```text
Web 用 class + selector 管变体；
Flutter 用参数 + Widget 组合管变体。
```

---

## 4. 子选择器 vs 显式结构

Web：

```css
.list > .item:not(:last-child) {
  margin-bottom: 12px;
}
```

Flutter：

```dart
ListView.separated(
  itemCount: items.length,
  separatorBuilder: (context, index) => const SizedBox(height: 12),
  itemBuilder: (context, index) {
    return ItemCard(item: items[index]);
  },
)
```

或者：

```dart
Column(
  children: [
    for (final item in items) ...[
      ItemCard(item: item),
      const SizedBox(height: 12),
    ],
  ],
)
```

Flutter 通常在构建 children 时直接控制结构。

---

## 5. `:hover` / `:active` 映射

Web：

```css
.button:hover {
  background: #eee;
}
```

Flutter：

```dart
InkWell(
  onTap: onTap,
  onHover: (hovering) {
    // update hover state
  },
  child: child,
)
```

或者 Material button style：

```dart
ButtonStyle(
  backgroundColor: WidgetStateProperty.resolveWith((states) {
    if (states.contains(WidgetState.hovered)) {
      return Colors.grey.shade100;
    }
    return Colors.white;
  }),
)
```

---

## 6. 全局样式 vs Theme

Web：

```css
button {
  font-size: 14px;
}
```

Flutter：

```dart
ThemeData(
  elevatedButtonTheme: ElevatedButtonThemeData(
    style: ElevatedButton.styleFrom(
      textStyle: const TextStyle(fontSize: 14),
    ),
  ),
)
```

Flutter 中全局样式通常通过 Theme 配置具体组件族，而不是写全局 selector。

---

## 7. Composition 的优势和代价

优势：

```text
组件边界清晰
样式来源明确
类型安全
重构更可控
不会被远处 selector 意外影响
```

代价：

```text
需要提前设计组件参数
不能随意从外部覆盖内部节点
样式复用更多依赖组件封装
```

---

一句话理解：

```text
CSS Selector 是“从外部选择 DOM 节点并施加样式”；
Flutter Widget Composition 是“通过组合 Widget、传递参数、封装组件来决定 UI”。
Flutter 不靠选择器命中内部节点，而靠组件 API 暴露可定制能力。
```
