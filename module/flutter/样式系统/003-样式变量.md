# CSS Variables vs `ThemeExtension` / `InheritedWidget`

Web 里用 CSS Variables 定义可复用设计变量：

```css
:root {
  --color-primary: #111111;
  --space-md: 16px;
}
```

Flutter 里没有 CSS Variables，常见替代是：

```dart
ThemeData
ThemeExtension
InheritedWidget
Provider / Riverpod
AppColors / AppTextStyles
```

可以这样映射：

| CSS Variables            | Flutter                                      |
| ------------------------ | -------------------------------------------- |
| `:root { --color: ... }` | `ThemeData` / `ThemeExtension`               |
| `var(--color-primary)`   | `Theme.of(context).extension<...>()`         |
| 全局设计 token           | `AppColors` / `AppSpacing` / `AppTextStyles` |
| 主题切换                 | `ThemeMode` / `ThemeData`                    |
| 局部覆盖变量             | 局部 `Theme` / `InheritedWidget`             |
| CSS cascade              | Flutter widget tree 继承                     |
| runtime style variable   | `InheritedWidget` / Provider state           |

---

## 1. CSS Variables 的心智

Web：

```css
:root {
  --color-primary: #111111;
  --radius-card: 8px;
}

.card {
  color: var(--color-primary);
  border-radius: var(--radius-card);
}
```

核心是：

```text
在父级定义变量；
子元素通过 var(...) 使用；
变量可以随着 CSS 级联和作用域变化。
```

## 2. Flutter ThemeData

Flutter 内置主题系统是：

```dart
ThemeData
```

例如：

```dart
MaterialApp(
  theme: ThemeData(
    colorScheme: ColorScheme.fromSeed(
      seedColor: Colors.black,
    ),
    textTheme: const TextTheme(
      titleMedium: TextStyle(fontSize: 16),
    ),
  ),
  home: const HomePage(),
)
```

使用：

```dart
final colorScheme = Theme.of(context).colorScheme;
final textTheme = Theme.of(context).textTheme;
```

可以理解为：

```text
ThemeData 是 Flutter Material 体系里的全局主题变量集合。
```

## 3. ThemeExtension

如果内置 `ThemeData` 不够放业务设计 token，可以用 `ThemeExtension`。

例如定义业务颜色：

```dart
@immutable
class AppThemeColors extends ThemeExtension<AppThemeColors> {
  const AppThemeColors({
    required this.productCardBackground,
    required this.discountText,
  });

  final Color productCardBackground;
  final Color discountText;

  @override
  AppThemeColors copyWith({
    Color? productCardBackground,
    Color? discountText,
  }) {
    return AppThemeColors(
      productCardBackground:
          productCardBackground ?? this.productCardBackground,
      discountText: discountText ?? this.discountText,
    );
  }

  @override
  AppThemeColors lerp(
    ThemeExtension<AppThemeColors>? other,
    double t,
  ) {
    if (other is! AppThemeColors) {
      return this;
    }

    return AppThemeColors(
      productCardBackground: Color.lerp(
        productCardBackground,
        other.productCardBackground,
        t,
      )!,
      discountText: Color.lerp(
        discountText,
        other.discountText,
        t,
      )!,
    );
  }
}
```

注册：

```dart
ThemeData(
  extensions: const [
    AppThemeColors(
      productCardBackground: Colors.white,
      discountText: Colors.red,
    ),
  ],
)
```

使用：

```dart
final colors = Theme.of(context).extension<AppThemeColors>()!;

Text(
  'Discount',
  style: TextStyle(color: colors.discountText),
)
```

心智映射：

```text
CSS custom properties
≈ Flutter ThemeExtension
```

## 4. InheritedWidget

`InheritedWidget` 是 Flutter 里“沿 Widget Tree 向下传递数据”的底层机制。

`Theme.of(context)` 本质上也是基于类似机制工作的。

可以理解为：

```text
CSS Variables 通过 DOM 树向下继承；
InheritedWidget 通过 Widget Tree 向下提供数据。
```

简单示意：

```dart
class AppTokens extends InheritedWidget {
  const AppTokens({
    super.key,
    required this.spacing,
    required super.child,
  });

  final double spacing;

  static AppTokens of(BuildContext context) {
    return context.dependOnInheritedWidgetOfExactType<AppTokens>()!;
  }

  @override
  bool updateShouldNotify(AppTokens oldWidget) {
    return spacing != oldWidget.spacing;
  }
}
```

使用：

```dart
final spacing = AppTokens.of(context).spacing;
```

不过业务项目里通常不直接手写 `InheritedWidget`，而是用：

```text
Theme
Provider
Riverpod
```

## 5. CSS Cascade vs Widget Tree 继承

Web：

```css
.page {
  --color-primary: red;
}

.card {
  color: var(--color-primary);
}
```

Flutter 可以局部覆盖 Theme：

```dart
Theme(
  data: Theme.of(context).copyWith(
    colorScheme: Theme.of(context).colorScheme.copyWith(
      primary: Colors.red,
    ),
  ),
  child: const ProductSection(),
)
```

这个 `Theme` 只影响它下面的 Widget。

对应心智：

```text
CSS 变量可以局部覆盖；
Flutter Theme 也可以在 Widget 子树中局部覆盖。
```

## 6. AppColors vs ThemeExtension

很多 Flutter 项目也会直接写静态 token：

```dart
class AppColors {
  static const primary = Color(0xFF111111);
  static const danger = Color(0xFFE53935);
}
```

使用：

```dart
Text(
  'Delete',
  style: TextStyle(color: AppColors.danger),
)
```

这种方式简单，但它不是上下文感知的：

```text
不随 Theme.of(context) 变化；
不天然支持暗色模式；
不支持局部主题覆盖。
```

所以选择上：

| 场景                  | 推荐                           |
| --------------------- | ------------------------------ |
| 固定设计 token        | `AppColors` / `AppSpacing`     |
| 需要明暗主题切换      | `ThemeData` / `ThemeExtension` |
| 需要局部覆盖          | `Theme` / `InheritedWidget`    |
| 需要运行时状态驱动    | Provider / Riverpod            |
| Material 组件颜色字体 | `ThemeData`                    |
| 业务专属 token        | `ThemeExtension`               |

---

一句话理解：

```text
CSS Variables 是 Web 里沿 DOM/CSS 级联传递的设计变量；
Flutter 里通常用 ThemeData 和 ThemeExtension 管主题变量，
用 InheritedWidget 或 Provider/Riverpod 沿 Widget Tree 传递上下文数据。
```
