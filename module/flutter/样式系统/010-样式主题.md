# Light/Dark Theme vs `ThemeData`

Web 里常用 CSS 变量、`prefers-color-scheme`、class 切换来实现明暗主题。

Flutter 里通常用：

```dart
ThemeData
ThemeMode
ColorScheme
ThemeExtension
```

来管理 light/dark theme。

可以这样映射：

| Web                       | Flutter                                              |
| ------------------------- | ---------------------------------------------------- |
| light theme CSS variables | `ThemeData.light()` / light `ThemeData`              |
| dark theme CSS variables  | `ThemeData.dark()` / dark `ThemeData`                |
| `prefers-color-scheme`    | `ThemeMode.system`                                   |
| `.dark` class             | `ThemeMode.dark`                                     |
| `:root { --color }`       | `ColorScheme` / `ThemeExtension`                     |
| `var(--color-primary)`    | `Theme.of(context).colorScheme.primary`              |
| theme provider            | `ThemeMode` state / Riverpod Provider                |
| component theme           | `ButtonTheme` / `CardTheme` / `InputDecorationTheme` |

---

## 1. Web 明暗主题

Web 常见写法：

```css
:root {
  --color-bg: #ffffff;
  --color-text: #111111;
}

.dark {
  --color-bg: #111111;
  --color-text: #ffffff;
}
```

使用：

```css
.page {
  background: var(--color-bg);
  color: var(--color-text);
}
```

或者跟随系统：

```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #111111;
    --color-text: #ffffff;
  }
}
```

---

## 2. Flutter ThemeData

Flutter 中通常在 `MaterialApp` 配置：

```dart
MaterialApp(
  theme: AppTheme.light,
  darkTheme: AppTheme.dark,
  themeMode: ThemeMode.system,
  home: const HomePage(),
)
```

含义：

| Flutter            | 含义             |
| ------------------ | ---------------- |
| `theme`            | 浅色主题         |
| `darkTheme`        | 深色主题         |
| `themeMode`        | 当前使用哪个主题 |
| `ThemeMode.system` | 跟随系统         |
| `ThemeMode.light`  | 强制浅色         |
| `ThemeMode.dark`   | 强制深色         |

---

## 3. ColorScheme

Flutter Material 主题推荐用 `ColorScheme` 管颜色：

```dart
ThemeData(
  colorScheme: const ColorScheme.light(
    primary: Color(0xFF111111),
    surface: Color(0xFFFFFFFF),
    error: Color(0xFFE53935),
  ),
)
```

深色：

```dart
ThemeData(
  colorScheme: const ColorScheme.dark(
    primary: Color(0xFFFFFFFF),
    surface: Color(0xFF111111),
    error: Color(0xFFFF6B6B),
  ),
)
```

使用：

```dart
final colors = Theme.of(context).colorScheme;

Container(
  color: colors.surface,
  child: Text(
    'Title',
    style: TextStyle(color: colors.onSurface),
  ),
)
```

---

## 4. TextTheme

Web 中常用：

```css
body {
  color: var(--color-text);
}
```

Flutter 中可以通过 `TextTheme` 配置：

```dart
ThemeData(
  textTheme: const TextTheme(
    bodyMedium: TextStyle(
      fontSize: 14,
      color: Color(0xFF111111),
    ),
  ),
)
```

使用：

```dart
Text(
  'Product',
  style: Theme.of(context).textTheme.bodyMedium,
)
```

---

## 5. Component Theme

Web 中可能写：

```css
.button {
  background: var(--color-primary);
}
```

Flutter 中可以配置组件主题：

```dart
ThemeData(
  elevatedButtonTheme: ElevatedButtonThemeData(
    style: ElevatedButton.styleFrom(
      backgroundColor: const Color(0xFF111111),
      foregroundColor: Colors.white,
    ),
  ),
)
```

常见组件主题：

```text
AppBarTheme
CardTheme
InputDecorationTheme
ElevatedButtonThemeData
TextButtonThemeData
BottomNavigationBarThemeData
NavigationBarThemeData
DialogTheme
```

---

## 6. ThemeExtension

如果 `ColorScheme` 不够表达业务 token，可以用 `ThemeExtension`：

```dart
final appColors = Theme.of(context).extension<AppThemeColors>()!;
```

适合放：

```text
商品卡片颜色
价格颜色
促销标签颜色
业务状态颜色
自定义阴影/间距/圆角
```

可以理解为：

```text
ThemeData 是 Flutter 官方主题容器；
ThemeExtension 是业务设计 token 的扩展入口。
```

---

## 7. 主题切换

Web：

```ts
document.documentElement.classList.toggle('dark');
```

Flutter 中通常通过状态控制：

```dart
MaterialApp(
  theme: AppTheme.light,
  darkTheme: AppTheme.dark,
  themeMode: themeMode,
)
```

`themeMode` 可以来自：

```text
StatefulWidget state
Riverpod Provider
本地存储 shared_preferences
系统设置 ThemeMode.system
```

---

一句话理解：

```text
Web 用 CSS variables、media query 或 .dark class 做明暗主题；
Flutter 用 ThemeData 定义 light/dark theme，
用 ThemeMode 决定当前主题，
用 Theme.of(context) 在 Widget Tree 中读取主题值。
```
