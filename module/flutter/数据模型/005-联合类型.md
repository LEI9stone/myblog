# enum / string literal union vs Dart enum

TypeScript 里常用 string literal union 表达固定字符串集合：

```ts
type OrderStatus = 'pending' | 'paid' | 'shipped' | 'cancelled';
```

Dart 中对应通常是：

```dart
enum OrderStatus {
  pending,
  paid,
  shipped,
  cancelled,
}
```

可以这样映射：

| TypeScript           | Dart                                       |
| -------------------- | ------------------------------------------ |
| string literal union | `enum`                                     |
| numeric enum         | `enum` / `int` 映射                        |
| discriminant string  | enum value / sealed class                  |
| union member         | enum case                                  |
| enum value to string | `.name`                                    |
| string to enum       | `values.byName(...)` / mapper              |
| backend enum string  | `@JsonEnum` / `@JsonValue` / custom mapper |
| exhaustive switch    | `switch` on enum                           |

---

## 1. TypeScript string literal union

```ts
type ProductStatus = 'draft' | 'published' | 'soldOut';
```

使用：

```ts
function renderStatus(status: ProductStatus) {
  switch (status) {
    case 'draft':
      return '草稿';
    case 'published':
      return '已发布';
    case 'soldOut':
      return '已售罄';
  }
}
```

这种模式轻量、常见，尤其适合接口状态字段。

---

## 2. Dart enum

```dart
enum ProductStatus {
  draft,
  published,
  soldOut,
}
```

使用：

```dart
String renderStatus(ProductStatus status) {
  return switch (status) {
    ProductStatus.draft => '草稿',
    ProductStatus.published => '已发布',
    ProductStatus.soldOut => '已售罄',
  };
}
```

Dart 的 `switch` 可以做穷尽检查，漏掉 enum case 时 analyzer 会提醒。

---

## 3. enum 和字符串互转

Dart enum 转字符串：

```dart
final name = ProductStatus.draft.name;
```

结果：

```text
draft
```

字符串转 enum：

```dart
final status = ProductStatus.values.byName('draft');
```

但 `byName` 找不到会抛错，所以接口解析时更建议封装：

```dart
ProductStatus parseProductStatus(String value) {
  return switch (value) {
    'draft' => ProductStatus.draft,
    'published' => ProductStatus.published,
    'sold_out' => ProductStatus.soldOut,
    _ => ProductStatus.draft,
  };
}
```

---

## 4. JSON 字段映射

后端可能返回：

```json
{
  "status": "sold_out"
}
```

Dart enum 是：

```dart
enum ProductStatus {
  draft,
  published,
  soldOut,
}
```

可以用：

```dart
@JsonEnum()
enum ProductStatus {
  draft,
  published,

  @JsonValue('sold_out')
  soldOut,
}
```

配合 `json_serializable` 解析。

---

## 5. enum 适合什么

适合：

```text
订单状态
商品状态
支付方式
排序类型
Tab 类型
展示模式
固定业务分类
```

例如：

```dart
enum SortType {
  latest,
  priceAsc,
  priceDesc,
}
```

---

## 6. 什么时候不用 enum

如果不同状态携带不同数据，`enum` 不够。

TypeScript：

```ts
type LoadState =
  | { type: 'loading' }
  | { type: 'success'; data: Product[] }
  | { type: 'error'; message: string };
```

Dart 更适合：

```dart
sealed class LoadState {}
```

或 Freezed union。

判断：

```text
只有固定值：enum
每种值还带不同字段：sealed class / Freezed union
```

---

一句话理解：

```text
TypeScript string literal union 常用来表达固定字符串集合；
Dart 中通常用 enum 表达固定状态集合。
接口字符串和 Dart enum 之间需要显式映射，
尤其是 snake_case、未知值和后端兼容场景。
```
