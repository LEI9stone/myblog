# Decimal / Number Precision vs `decimal`

Web/TypeScript 里 `number` 是双精度浮点数，处理金额、精确小数时容易出现精度问题。

Dart 里的 `double` 也有类似问题。Flutter 项目中如果涉及金额、价格、折扣、汇率等高精度小数，常用：

```dart
decimal
int cents
```

可以这样映射：

| Web / TypeScript         | Dart / Flutter                  |
| ------------------------ | ------------------------------- |
| `number`                 | `double` / `int` / `num`        |
| floating precision issue | double precision issue          |
| decimal.js               | `decimal` package               |
| cents integer            | `int` cents                     |
| price string             | `Decimal.parse(...)`            |
| format currency          | `intl` / formatter              |
| API numeric price        | `num` → `Decimal`               |
| money calculation        | `Decimal` / integer minor units |

---

## 1. JavaScript number 精度问题

Web：

```ts
0.1 + 0.2;
```

结果不是精确的：

```text
0.30000000000000004
```

因为 JavaScript `number` 是 IEEE 754 双精度浮点数。

所以金额计算不建议直接用 `number` 浮点运算。

---

## 2. Dart double 也有类似问题

Dart：

```dart
0.1 + 0.2
```

也会遇到二进制浮点精度问题。

所以这不是 JavaScript 独有问题，而是浮点数表示方式的问题。

---

## 3. 使用 decimal

Dart 可以用 `decimal` package：

```dart
final a = Decimal.parse('0.1');
final b = Decimal.parse('0.2');

final result = a + b;
```

结果是精确十进制：

```text
0.3
```

适合：

```text
金额
价格
折扣
汇率
重量/尺寸等需要十进制精确的业务
```

---

## 4. API 返回金额的常见处理

后端可能返回：

```json
{
  "price": "99.90"
}
```

Dart：

```dart
final price = Decimal.parse(json['price'] as String);
```

如果返回数字：

```json
{
  "price": 99.9
}
```

可以谨慎转换：

```dart
final price = Decimal.parse((json['price'] as num).toString());
```

更推荐后端对金额返回：

```text
字符串 decimal
或整数分
```

避免 JSON number 精度问题。

---

## 5. int cents 方案

电商常用更稳的方案：

```json
{
  "price_cent": 9990
}
```

Dart：

```dart
final priceCent = json['price_cent'] as int;
```

计算时用整数：

```dart
final totalCent = priceCent * quantity;
```

展示时格式化：

```dart
final priceText = '¥${(priceCent / 100).toStringAsFixed(2)}';
```

这种方式适合：

```text
人民币分
美元 cents
订单总价
支付金额
```

---

## 6. Decimal vs int cents 怎么选

| 场景                    | 推荐                    |
| ----------------------- | ----------------------- |
| 货币最小单位明确        | `int cents`             |
| 价格、订单、支付        | `int cents` 优先        |
| 汇率、折扣、小数比例    | `Decimal`               |
| 后端返回 decimal 字符串 | `Decimal.parse`         |
| 只展示不计算            | String / formatted text |
| 普通 UI 比例动画        | `double`                |

简单判断：

```text
支付金额：优先 int cents
十进制计算：用 Decimal
UI 尺寸/动画：用 double
```

---

## 7. 格式化

Dart 常用 `intl`：

```dart
final formatter = NumberFormat.currency(
  locale: 'zh_CN',
  symbol: '¥',
);

final text = formatter.format(price.toDouble());
```

如果是 `Decimal`，格式化前要注意转换和精度：

```dart
final text = '¥${price.toStringAsFixed(2)}';
```

根据项目要求封装统一价格 formatter 更稳。

---

## 8. 不要在 UI 中散落金额计算

不推荐：

```dart
Text('¥${product.price * quantity}')
```

推荐：

```dart
final total = cartItem.totalPrice;
Text(formatPrice(total))
```

或者：

```dart
PriceText(value: total)
```

金额计算最好集中在：

```text
Domain Model
Repository mapper
Price formatter
Cart calculator
```

---

一句话理解：

```text
TypeScript number 和 Dart double 都有浮点精度问题；
金额类业务不要直接用浮点数计算。
Flutter 中常用 decimal 做十进制精确计算，
或用 int cents 表示最小货币单位。
```
