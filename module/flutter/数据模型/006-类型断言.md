# Partial / Pick / Omit vs CopyWith / Model Split

TypeScript 里常用 Utility Types 从已有类型派生新类型：

```ts
Partial<T>;
Pick<T, K>;
Omit<T, K>;
Required<T>;
```

Dart 没有 TypeScript 这种类型编程能力，通常用：

```dart
copyWith
拆分 Model
单独定义 DTO/Form/Params
Freezed
```

来解决类似问题。

| TypeScript           | Dart                             |
| -------------------- | -------------------------------- |
| `Partial<T>`         | `copyWith` / nullable form model |
| `Pick<T, K>`         | 单独定义小 Model                 |
| `Omit<T, K>`         | 单独定义另一个 Model             |
| `Required<T>`        | `required` fields                |
| object spread update | `copyWith`                       |
| utility type 派生    | model split                      |
| form draft type      | form state class                 |
| create/update DTO    | request model class              |

---

## 1. TypeScript Utility Types

TypeScript：

```ts
type Product = {
  id: string;
  title: string;
  price: number;
  imageUrl?: string;
};

type ProductDraft = Partial<Product>;

type ProductSummary = Pick<Product, 'id' | 'title'>;

type CreateProductInput = Omit<Product, 'id'>;
```

这些类型不会生成运行时代码，只是在编译期复用类型结构。

---

## 2. Dart 没有 Pick/Omit/Partial

Dart 不能直接写：

```dart
Partial<Product>
Pick<Product, ['id', 'title']>
Omit<Product, ['id']>
```

如果需要不同形态的数据，通常显式定义不同 class：

```dart
class Product {
  const Product({
    required this.id,
    required this.title,
    required this.price,
  });

  final String id;
  final String title;
  final Decimal price;
}
```

```dart
class ProductSummary {
  const ProductSummary({
    required this.id,
    required this.title,
  });

  final String id;
  final String title;
}
```

---

## 3. Partial vs copyWith

TypeScript：

```ts
const nextProduct = {
  ...product,
  title: 'New title',
};
```

Dart：

```dart
final nextProduct = product.copyWith(
  title: 'New title',
);
```

如果用 Freezed，会自动生成 `copyWith`：

```dart
@freezed
abstract class Product with _$Product {
  const factory Product({
    required String id,
    required String title,
    required Decimal price,
  }) = _Product;
}
```

使用：

```dart
final nextProduct = product.copyWith(title: 'New title');
```

---

## 4. Pick/Omit vs Model Split

TypeScript：

```ts
type ProductCardProps = Pick<Product, 'id' | 'title' | 'imageUrl'>;
```

Dart 更推荐明确建模：

```dart
class ProductCardModel {
  const ProductCardModel({
    required this.id,
    required this.title,
    this.imageUrl,
  });

  final String id;
  final String title;
  final String? imageUrl;
}
```

这样虽然多写一点代码，但边界更清楚：

```text
Product 是完整业务模型；
ProductCardModel 是卡片展示模型；
CreateProductParams 是创建请求参数；
ProductFormState 是表单草稿状态。
```

## 5. Create / Update DTO

TypeScript：

```ts
type CreateProductDto = Omit<Product, 'id'>;
type UpdateProductDto = Partial<Omit<Product, 'id'>>;
```

Dart：

```dart
class CreateProductRequest {
  const CreateProductRequest({
    required this.title,
    required this.price,
  });

  final String title;
  final Decimal price;
}
```

```dart
class UpdateProductRequest {
  const UpdateProductRequest({
    this.title,
    this.price,
  });

  final String? title;
  final Decimal? price;
}
```

这里 `UpdateProductRequest` 接近 TypeScript 的 `Partial`。

---

## 6. Form State

TypeScript：

```ts
type ProductFormValues = Partial<Product>;
```

Dart 更建议单独定义：

```dart
class ProductFormState {
  const ProductFormState({
    this.title = '',
    this.priceText = '',
    this.imageUrl,
  });

  final String title;
  final String priceText;
  final String? imageUrl;
}
```

表单状态通常不应该直接等于业务模型，因为：

```text
输入框价格通常是 String
字段可能还没填完整
需要保存校验错误
需要区分草稿和已提交模型
```

---

## 7. 选择建议

| 需求                 | TypeScript 常用         | Dart 推荐          |
| -------------------- | ----------------------- | ------------------ |
| 更新已有对象部分字段 | object spread / Partial | `copyWith`         |
| 只取几个字段展示     | `Pick`                  | 单独 View Model    |
| 去掉 id 做创建参数   | `Omit`                  | `CreateXxxRequest` |
| 全部字段可选做更新   | `Partial`               | `UpdateXxxRequest` |
| 表单草稿             | `Partial<T>`            | `FormState`        |
| 不可变更新           | spread / Immer          | Freezed `copyWith` |

一句话理解：

```text
TypeScript 用 Partial/Pick/Omit 在类型层面派生新类型；
Dart 更倾向显式建模：
用 copyWith 做不可变更新，
用不同的 Model/DTO/FormState/Request class 表达不同数据形态。
```
