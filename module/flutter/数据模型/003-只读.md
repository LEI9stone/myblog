# Immutable Object vs Freezed Data Class

Web/TypeScript 里不可变对象通常靠约定、`readonly`、对象展开、Immer 或状态库约束实现。

Flutter/Dart 中常用 Freezed 生成不可变 Data Class，自动提供 `copyWith`、相等比较、`toString`、JSON 序列化等能力。

可以这样映射：

| TypeScript / Web     | Flutter / Dart                               |
| -------------------- | -------------------------------------------- |
| immutable object     | immutable data class                         |
| `readonly` field     | `final` field                                |
| object spread update | `copyWith`                                   |
| Immer                | Freezed copyWith / generated immutable model |
| DTO type             | Freezed model                                |
| discriminated union  | Freezed union                                |
| `as const`           | `const factory` / const object               |
| value equality       | generated `==` / `hashCode`                  |
| JSON mapper          | Freezed + json_serializable                  |

---

## 1. Web Immutable Object

TypeScript：

```ts
type Product = {
  readonly id: string;
  readonly title: string;
  readonly price: number;
};
```

更新：

```ts
const nextProduct = {
  ...product,
  title: 'New title',
};
```

如果是 Redux/Immer：

```ts
produce(state, (draft) => {
  draft.title = 'New title';
});
```

最终目标都是：

```text
不要直接修改旧对象；
生成一个新对象表示新状态。
```

---

## 2. Dart 手写 Immutable Class

Dart：

```dart
class Product {
  const Product({
    required this.id,
    required this.title,
    required this.price,
  });

  final String id;
  final String title;
  final double price;

  Product copyWith({
    String? id,
    String? title,
    double? price,
  }) {
    return Product(
      id: id ?? this.id,
      title: title ?? this.title,
      price: price ?? this.price,
    );
  }
}
```

更新：

```dart
final nextProduct = product.copyWith(
  title: 'New title',
);
```

问题是：

```text
字段多时代码很重复；
相等比较、hashCode、toString、JSON 都要手写。
```

---

## 3. Freezed Data Class

Freezed：

```dart
@freezed
abstract class Product with _$Product {
  const factory Product({
    required String id,
    required String title,
    required double price,
  }) = _Product;
}
```

它会生成：

```text
final 字段
copyWith
==
hashCode
toString
不可变数据类样板代码
```

更新：

```dart
final nextProduct = product.copyWith(
  title: 'New title',
);
```

---

## 4. JSON 支持

如果需要 JSON：

```dart
@freezed
abstract class Product with _$Product {
  const factory Product({
    required String id,
    required String title,
    required double price,
  }) = _Product;

  factory Product.fromJson(Map<String, dynamic> json) =>
      _$ProductFromJson(json);
}
```

还需要：

```dart
part 'product.freezed.dart';
part 'product.g.dart';
```

生成：

```bash
dart run build_runner build
```

---

## 5. Value Equality

TypeScript object：

```ts
{ id: '1' } === { id: '1' } // false
```

Dart 普通 class 默认也是引用相等。

Freezed 会生成值相等：

```dart
Product(id: '1', title: 'Cup', price: 99)
==
Product(id: '1', title: 'Cup', price: 99)
```

结果是：

```text
true
```

这对状态比较、测试、缓存都很有用。

---

## 6. 嵌套 copyWith

Freezed 支持更舒服的嵌套更新。

例如：

```dart
state = state.copyWith(
  user: state.user.copyWith(name: 'Tom'),
);
```

复杂模型中，Freezed 的 generated copyWith 会减少很多样板代码。

---

## 7. List 不可变注意

即使用 Freezed，也要注意集合字段。

```dart
const factory CartState({
  required List<CartItem> items,
}) = _CartState;
```

更新时仍然推荐：

```dart
state = state.copyWith(
  items: [...state.items, newItem],
);
```

不要：

```dart
state.items.add(newItem);
```

---

## 8. 什么时候用 Freezed

适合：

```text
接口模型
业务状态
复杂表单状态
union state
需要 copyWith
需要 JSON
需要值相等
字段较多的不可变对象
```

不一定需要：

```text
很小的临时对象
只有一两个字段且不需要 copyWith
纯 UI 局部状态
简单 enum
```

---

一句话理解：

```text
TypeScript 不可变对象通常靠 readonly、对象展开或 Immer；
Dart 中可以手写 final class + copyWith，
但复杂模型更常用 Freezed 生成不可变 Data Class，
自动获得 copyWith、值相等、toString 和 JSON 支持。
```
