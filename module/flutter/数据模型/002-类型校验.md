# Zod / Yup Schema vs `json_serializable` / Freezed

Web 里 Zod/Yup 常用于：

```text
运行时数据校验
表单校验
接口数据解析
类型推导
```

Flutter/Dart 里常用：

```dart
json_serializable
freezed
手写 validator
FormField validator
```

但要注意：`json_serializable` / Freezed 主要解决“模型生成与 JSON 转换”，不完全等价于 Zod/Yup 的运行时 schema 校验能力。

| Web                      | Flutter / Dart                         |
| ------------------------ | -------------------------------------- |
| Zod schema               | model class + fromJson / 手写校验      |
| Yup schema               | form validator / validation service    |
| `z.infer<typeof Schema>` | Dart class 类型                        |
| runtime validation       | fromJson 类型转换 / checked / 手写校验 |
| parse JSON               | `fromJson`                             |
| serialize JSON           | `toJson`                               |
| immutable model          | Freezed                                |
| generated mapper         | `json_serializable`                    |
| form validation          | `Form` / `TextFormField.validator`     |

---

## 1. Zod/Yup 的角色

Web：

```ts
const ProductSchema = z.object({
  id: z.string(),
  title: z.string(),
  price: z.number(),
});

type Product = z.infer<typeof ProductSchema>;
```

Zod/Yup 可以同时做：

```text
定义 schema
运行时校验
类型推导
错误信息生成
表单校验
```

---

## 2. json_serializable 的角色

Flutter：

```dart
@JsonSerializable()
class Product {
  const Product({
    required this.id,
    required this.title,
    required this.price,
  });

  final String id;
  final String title;
  final double price;

  factory Product.fromJson(Map<String, dynamic> json) =>
      _$ProductFromJson(json);

  Map<String, dynamic> toJson() => _$ProductToJson(this);
}
```

它主要负责：

```text
Map<String, dynamic> ↔ Dart Model
```

不是完整 schema validator。

---

## 3. Freezed 的角色

Freezed 更偏不可变模型和联合类型：

```dart
@freezed
abstract class Product with _$Product {
  const factory Product({
    required String id,
    required String title,
    required double price,
  }) = _Product;

  factory Product.fromJson(Map<String, dynamic> json) =>
      _$ProductFromJson(json);
}
```

它提供：

```text
不可变数据类
copyWith
==
hashCode
toString
union/sealed state
fromJson/toJson 集成
```

可以理解为：

```text
Freezed ≈ immutable model generator
json_serializable ≈ JSON mapper generator
```

---

## 4. 运行时校验差异

Zod：

```ts
const result = ProductSchema.safeParse(data);
```

它会返回明确的校验结果和错误信息。

Dart `fromJson`：

```dart
final product = Product.fromJson(json);
```

如果类型不符合，通常会抛运行时异常，比如 cast error。

所以差异是：

```text
Zod/Yup 主动校验并返回结构化错误；
json_serializable 主要做转换，失败时抛异常。
```

如果 Flutter 里也需要强校验，通常要：

```text
手写校验逻辑
在 Repository 层捕获解析异常
使用 checked json 配置
使用专门 validation package
```

## 5. 表单校验

Yup 常用于表单：

```ts
const schema = yup.object({
  name: yup.string().required(),
});
```

Flutter 表单通常写：

```dart
TextFormField(
  validator: (value) {
    if (value == null || value.isEmpty) {
      return '请输入名称';
    }

    return null;
  },
)
```

复杂表单可以把 validator 抽出去：

```dart
class ProductFormValidators {
  static String? name(String? value) {
    if (value == null || value.isEmpty) {
      return '请输入名称';
    }

    return null;
  }
}
```

## 6. 怎么类比更准确

| 需求           | Web                              | Flutter                    |
| -------------- | -------------------------------- | -------------------------- |
| 定义接口类型   | TypeScript type/interface        | Dart class / Freezed       |
| JSON 转模型    | Zod parse / manual mapper        | `fromJson`                 |
| 模型转 JSON    | manual / schema transform        | `toJson`                   |
| 不可变模型     | readonly / Immer / utility types | Freezed                    |
| 表单校验       | Yup / Zod / React Hook Form      | `Form` + validator         |
| 运行时接口校验 | Zod safeParse                    | 手写校验 / checked parsing |

---

一句话理解：

```text
Zod/Yup 是运行时 schema 校验工具；
json_serializable 是 JSON 序列化代码生成工具；
Freezed 是不可变模型和 union 类型生成工具。
在 Flutter 中，接口模型通常用 Freezed + json_serializable，
表单或严格运行时校验则需要额外 validator 逻辑。
```
