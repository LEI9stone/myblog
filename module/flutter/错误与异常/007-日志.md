# Logging vs Flutter / Dart Logging

Web 里常用：

```ts
console.log;
console.error;
logger;
Sentry;
Datadog;
```

Flutter/Dart 中对应：

```dart
debugPrint
developer.log
logging package
Crashlytics / Sentry
Dio log interceptor
```

可以这样映射：

| Web Logging       | Flutter / Dart                 |
| ----------------- | ------------------------------ |
| `console.log`     | `debugPrint`                   |
| `console.error`   | `debugPrint` / `developer.log` |
| logger library    | `logging` / custom logger      |
| network log       | Dio interceptor                |
| error reporting   | Sentry / Crashlytics           |
| source maps       | Dart symbols / debug info      |
| dev-only log      | `kDebugMode` guard             |
| production log    | remote logging/reporting       |
| performance marks | Timeline / DevTools            |

---

## 1. console.log vs debugPrint

Web：

```ts
console.log('data', data);
```

Flutter：

```dart
debugPrint('data: $data');
```

`debugPrint` 比普通 `print` 更适合 Flutter，因为它会对长日志做节流，避免一次性输出过长内容。

简单调试时优先用：

```dart
debugPrint
```

---

## 2. developer.log

Dart 也提供：

```dart
import 'dart:developer' as developer;

developer.log(
  'fetch products failed',
  name: 'ProductRepository',
  error: error,
  stackTrace: stackTrace,
);
```

适合：

```text
带 logger name
带 error/stackTrace
DevTools 中查看
```

---

## 3. logging package

如果项目需要更正式的日志分级，可以用：

```dart
package:logging
```

概念类似 Web logger：

```text
debug
info
warning
error
```

示意：

```dart
final log = Logger('ProductRepository');

log.info('fetch products');
log.warning('request retry');
log.severe('fetch failed', error, stackTrace);
```

---

## 4. Dio 请求日志

Web axios 可以加 interceptor 打日志。

Dio 也可以：

```dart
dio.interceptors.add(
  LogInterceptor(
    requestBody: true,
    responseBody: true,
  ),
);
```

但生产环境要谨慎：

```text
不要打印 token
不要打印密码
不要打印支付信息
不要打印过大的 response
不要泄露用户隐私
```

常用：

```dart
if (kDebugMode) {
  dio.interceptors.add(LogInterceptor(...));
}
```

---

## 5. 错误上报

生产环境不要只靠本地日志。常接入：

```text
Firebase Crashlytics
Sentry
自建日志系统
```

Flutter 常见全局错误入口：

```dart
FlutterError.onError
PlatformDispatcher.instance.onError
runZonedGuarded
```

然后上报：

```text
error
stackTrace
用户环境
App 版本
设备信息
route 信息
```

---

## 6. Debug log vs Production log

开发环境：

```dart
if (kDebugMode) {
  debugPrint('response: $data');
}
```

生产环境：

```text
只上报必要错误
脱敏
采样
避免影响性能
避免泄露隐私
```

不要把调试日志长期留在生产路径，尤其是：

```text
token
手机号
地址
订单详情
支付信息
接口完整响应
```

---

## 7. 推荐分层

| 日志类型        | 推荐位置                 |
| --------------- | ------------------------ |
| 临时调试        | `debugPrint`             |
| Repository 错误 | logger / error reporting |
| API 请求响应    | Dio interceptor          |
| UI 用户操作     | analytics service        |
| 全局异常        | FlutterError / Zone      |
| 性能问题        | DevTools / Timeline      |
| 生产崩溃        | Crashlytics / Sentry     |

一句话理解：

```text
Web 用 console/logger/监控平台打日志；
Flutter 中简单调试用 debugPrint，
结构化日志用 developer.log 或 logging package，
网络日志用 Dio interceptor，
生产错误用 Crashlytics/Sentry 等错误上报系统。
```
