# Empty State vs Empty View

Web 和 Flutter 里 Empty State 都表示“请求成功了，但没有可展示的数据”。

Flutter 中通常会封装成：

```dart
EmptyView
EmptyState
AppEmptyState
```

它不是错误态，也不是加载态。

可以这样映射：

| Web Empty State       | Flutter Empty View                     |
| --------------------- | -------------------------------------- |
| empty state component | `EmptyView` / `EmptyState` Widget      |
| no data               | empty list / null result               |
| search no result      | search empty view                      |
| filtered empty        | filtered empty view                    |
| first-use empty       | onboarding-style empty view            |
| error state           | `ErrorView`，不要混用                  |
| loading state         | `LoadingView`，不要混用                |
| retry CTA             | refresh / create / clear filter action |

---

## 1. Empty State 的定义

Empty State 表示：

```text
请求成功
没有错误
只是数据为空
```

例如：

```text
商品列表为空
搜索没有结果
订单列表为空
收藏夹为空
筛选后无匹配项
```

这和 API 失败不同。

---

## 2. Web 写法

React：

```tsx
if (loading) return <Loading />;
if (error) return <ErrorView />;
if (products.length === 0) return <EmptyState />;
return <ProductList products={products} />;
```

---

## 3. Flutter 写法

```dart
switch (products) {
  case AsyncLoading():
    return const LoadingView();

  case AsyncError(:final error):
    return ErrorView(error: error);

  case AsyncData(:final value) when value.isEmpty:
    return const EmptyState(
      title: '暂无商品',
    );

  case AsyncData(:final value):
    return ProductList(products: value);
}
```

状态顺序很重要：

```text
loading
error
empty
data
```

---

## 4. EmptyView 组件

```dart
class EmptyState extends StatelessWidget {
  const EmptyState({
    super.key,
    required this.title,
    this.description,
    this.action,
  });

  final String title;
  final String? description;
  final Widget? action;

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Text(title),
          if (description != null) Text(description!),
          if (action != null) action!,
        ],
      ),
    );
  }
}
```

实际项目中可以统一空状态视觉：

```text
图标
标题
说明
操作按钮
间距
颜色
```

---

## 5. 不同 Empty State 语义

| 场景           | 文案/操作            |
| -------------- | -------------------- |
| 首次无数据     | 引导创建             |
| 搜索无结果     | 修改关键词           |
| 筛选无结果     | 清除筛选             |
| 收藏为空       | 去浏览商品           |
| 订单为空       | 去下单               |
| 消息为空       | 无需操作             |
| 加载更多无数据 | 底部提示“没有更多了” |

不要所有空状态都写：

```text
暂无数据
```

要根据业务场景决定。

---

## 6. Empty 不是 Error

不要把空数组当错误：

```dart
if (products.isEmpty) {
  throw Exception('No data');
}
```

除非业务明确规定“没有数据就是异常”。

正常列表为空应该是：

```dart
AsyncData([])
```

然后 UI 显示 EmptyView。

---

## 7. Empty 和 Skeleton 的区别

| 状态     | 含义               |
| -------- | ------------------ |
| Skeleton | 数据还没回来       |
| Empty    | 数据回来了，但为空 |
| Error    | 数据请求失败       |
| Data     | 有数据可展示       |

一句话理解：

```text
Empty State 是“成功但没有数据”的 UI 状态；
Flutter 中通常封装成 EmptyView/EmptyState Widget。
它应该和 Loading、Error、Data 明确区分，
并根据业务场景提供合适文案和操作。
```
