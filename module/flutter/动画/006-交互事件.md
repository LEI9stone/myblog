# Web Gesture Events vs Flutter Gesture System

Web 里交互事件主要来自 DOM 事件系统：

```text
click
mousedown
mousemove
mouseup
touchstart
touchmove
touchend
pointerdown
pointermove
pointerup
```

Flutter 里没有 DOM Event，而是用 Flutter Gesture System 识别手势：

```dart
GestureDetector
InkWell
Listener
Draggable
Dismissible
InteractiveViewer
```

可以这样映射：

| Web Gesture / Event | Flutter                                        |
| ------------------- | ---------------------------------------------- |
| `click`             | `onTap`                                        |
| `dblclick`          | `onDoubleTap`                                  |
| `mousedown`         | `onTapDown` / `Listener.onPointerDown`         |
| `mouseup`           | `onTapUp` / `Listener.onPointerUp`             |
| `mousemove`         | `MouseRegion` / `Listener.onPointerMove`       |
| `touchstart`        | `onTapDown` / `Listener.onPointerDown`         |
| `touchmove`         | `onPanUpdate` / `onVerticalDragUpdate`         |
| `touchend`          | `onTapUp` / `onPanEnd`                         |
| `pointer events`    | `PointerEvent` / `Listener`                    |
| drag                | `onPanUpdate` / `Draggable`                    |
| swipe               | `onHorizontalDragEnd` / `Dismissible`          |
| pinch zoom          | `InteractiveViewer` / `ScaleGestureRecognizer` |
| event bubbling      | Flutter 手势命中测试 + gesture arena           |

---

## 1. Web 事件系统

Web：

```ts
element.addEventListener('click', handleClick);
element.addEventListener('touchmove', handleTouchMove);
```

React：

```tsx
<div
  onClick={handleClick}
  onMouseMove={handleMouseMove}
  onTouchStart={handleTouchStart}
/>
```

Web 事件通常围绕：

```text
DOM 节点
事件捕获
事件冒泡
preventDefault
stopPropagation
```

---

## 2. Flutter GestureDetector

Flutter 最常用的是：

```dart
GestureDetector(
  onTap: onTap,
  onLongPress: onLongPress,
  onPanUpdate: onPanUpdate,
  child: child,
)
```

常见手势：

```dart
GestureDetector(
  onTap: () {},
  onDoubleTap: () {},
  onLongPress: () {},
  onPanUpdate: (details) {},
  onHorizontalDragUpdate: (details) {},
  onVerticalDragUpdate: (details) {},
  child: child,
)
```

它不是监听 DOM 事件，而是让 Flutter 根据 pointer 输入识别成高级手势。

---

## 3. Pointer Event vs Gesture

Flutter 中要区分两层：

| 层级         | Flutter           |
| ------------ | ----------------- |
| 原始指针事件 | `Listener`        |
| 高级手势识别 | `GestureDetector` |

低层事件：

```dart
Listener(
  onPointerDown: (event) {},
  onPointerMove: (event) {},
  onPointerUp: (event) {},
  child: child,
)
```

高级手势：

```dart
GestureDetector(
  onTap: () {},
  onPanUpdate: (details) {},
  child: child,
)
```

通常业务交互优先用 `GestureDetector`，需要原始坐标、压力、设备类型时才用 `Listener`。

---

## 4. Drag / Swipe

Web：

```ts
onPointerDown;
onPointerMove;
onPointerUp;
```

Flutter 拖拽：

```dart
GestureDetector(
  onPanStart: (details) {},
  onPanUpdate: (details) {
    final delta = details.delta;
  },
  onPanEnd: (details) {},
  child: child,
)
```

只关心水平滑动：

```dart
GestureDetector(
  onHorizontalDragUpdate: (details) {},
  onHorizontalDragEnd: (details) {},
  child: child,
)
```

列表项滑动删除：

```dart
Dismissible(
  key: ValueKey(item.id),
  onDismissed: (_) => deleteItem(item),
  child: ItemTile(item: item),
)
```

---

## 5. Pinch Zoom

Web 里通常自己处理 touch 点位，或者用手势库。

Flutter 常用：

```dart
InteractiveViewer(
  minScale: 0.5,
  maxScale: 4,
  child: Image.network(imageUrl),
)
```

适合：

```text
图片缩放
画布缩放
地图类视图
编辑器画布
```

---

## 6. 事件冒泡差异

Web 有明确事件传播模型：

```text
capture → target → bubble
```

Flutter 没有 DOM 冒泡模型。

Flutter 通过：

```text
hit testing
gesture arena
recognizer competition
```

决定哪个 Widget 响应手势。

简单理解：

```text
Web 是事件沿 DOM 树传播；
Flutter 是命中测试后，多个手势识别器竞争，最终胜者处理手势。
```

---

## 7. Gesture Arena

如果一个手势同时可能被多个识别器处理，比如：

```text
横向拖动
纵向滚动
点击
长按
```

Flutter 会通过 Gesture Arena 判断最终哪个手势胜出。

典型例子：

```dart
ListView(
  children: [
    GestureDetector(
      onHorizontalDragUpdate: (_) {},
      child: ItemCard(),
    ),
  ],
)
```

这里可能存在：

```text
ListView 的垂直滚动
ItemCard 的水平拖动
```

Flutter 会根据用户移动方向和手势规则决定谁响应。

---

## 8. InkWell vs GestureDetector

如果只是普通点击：

```dart
GestureDetector(
  onTap: onTap,
  child: child,
)
```

如果是 Material 风格点击，更推荐：

```dart
InkWell(
  onTap: onTap,
  child: child,
)
```

`InkWell` 提供：

```text
水波纹
hover
focus
pressed state
语义支持
```

---

一句话理解：

```text
Web 手势基于 DOM Event、Pointer Event 和事件传播；
Flutter 手势基于 PointerEvent、Hit Test、GestureRecognizer 和 Gesture Arena。
普通业务交互用 GestureDetector/InkWell，
原始指针输入用 Listener，
缩放拖动画布用 InteractiveViewer 或自定义手势识别。
```
