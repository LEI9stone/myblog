# Loading State Animation vs Flutter Loading Widgets

Web 中加载状态常见表现是：

```text
spinner
progress bar
skeleton
button loading
page loading
infinite scroll loading
```

Flutter 里对应的是一组 Loading Widgets 和状态驱动 UI：

```dart
CircularProgressIndicator
LinearProgressIndicator
RefreshIndicator
Shimmer
AnimatedSwitcher
AsyncValue
```

可以这样映射：

| Web Loading UI         | Flutter                                |
| ---------------------- | -------------------------------------- |
| spinner                | `CircularProgressIndicator`            |
| progress bar           | `LinearProgressIndicator`              |
| skeleton               | `Shimmer` / Skeleton Widget            |
| button loading         | disabled button + spinner              |
| page loading           | full-page loading widget               |
| pull to refresh        | `RefreshIndicator`                     |
| infinite scroll footer | load more footer widget                |
| optimistic loading     | state-driven placeholder               |
| route loading          | route/page loading state               |
| suspense fallback      | `FutureBuilder` / `AsyncValue.loading` |

---

## 1. Spinner

Web：

```html
<div class="spinner"></div>
```

Flutter：

```dart
const CircularProgressIndicator()
```

常见居中：

```dart
const Center(
  child: CircularProgressIndicator(),
)
```

适合：

```text
短时间不确定进度
局部模块加载
按钮外的普通等待
```

---

## 2. Progress Bar

Web：

```html
<progress value="40" max="100"></progress>
```

Flutter：

```dart
const LinearProgressIndicator()
```

确定进度：

```dart
LinearProgressIndicator(
  value: progress, // 0.0 - 1.0
)
```

不确定进度：

```dart
const LinearProgressIndicator()
```

适合：

```text
上传
下载
分步骤任务
可量化进度
```

---

## 3. Button Loading

Web：

```tsx
<Button disabled={loading}>{loading ? <Spinner /> : 'Submit'}</Button>
```

Flutter：

```dart
ElevatedButton(
  onPressed: loading ? null : onSubmit,
  child: loading
      ? const SizedBox(
          width: 16,
          height: 16,
          child: CircularProgressIndicator(strokeWidth: 2),
        )
      : const Text('Submit'),
)
```

更平滑可以用：

```dart
AnimatedSwitcher(
  duration: const Duration(milliseconds: 150),
  child: loading
      ? const SizedBox(
          key: ValueKey('loading'),
          width: 16,
          height: 16,
          child: CircularProgressIndicator(strokeWidth: 2),
        )
      : const Text(
          'Submit',
          key: ValueKey('text'),
        ),
)
```

---

## 4. Page Loading

React 常见：

```tsx
if (loading) return <PageLoading />;
if (error) return <ErrorView />;
return <Content />;
```

Flutter：

```dart
if (loading) {
  return const Center(
    child: CircularProgressIndicator(),
  );
}

if (error != null) {
  return ErrorView(error: error);
}

return Content(data: data);
```

如果用 Riverpod：

```dart
switch (state) {
  case AsyncLoading():
    return const Center(child: CircularProgressIndicator());
  case AsyncError(:final error):
    return ErrorView(error: error);
  case AsyncData(:final value):
    return Content(data: value);
}
```

---

## 5. Skeleton / Shimmer

页面结构明确时，优先考虑 skeleton：

```dart
Shimmer.fromColors(
  baseColor: Colors.grey.shade300,
  highlightColor: Colors.grey.shade100,
  child: const ProductListSkeleton(),
)
```

适合：

```text
商品卡片
用户资料
图片列表
首屏内容
```

比纯 spinner 更能暗示页面结构。

---

## 6. Pull to Refresh

Web 移动端可能自己做下拉刷新。

Flutter 内置：

```dart
RefreshIndicator(
  onRefresh: refresh,
  child: ListView.builder(
    itemCount: items.length,
    itemBuilder: (context, index) {
      return ItemTile(item: items[index]);
    },
  ),
)
```

`onRefresh` 返回：

```dart
Future<void>
```

---

## 7. Infinite Scroll Loading

Web：

```text
列表底部显示 loading more
```

Flutter：

```dart
ListView.builder(
  itemCount: items.length + 1,
  itemBuilder: (context, index) {
    if (index == items.length) {
      return const LoadMoreFooter();
    }

    return ItemTile(item: items[index]);
  },
)
```

也可以用 `ScrollController` 监听接近底部时加载更多。

---

## 8. Loading 状态设计

常见状态不要只写一个 `loading: boolean`，复杂页面通常有多种 loading：

```text
首次加载
刷新中
加载更多中
提交中
局部模块加载
图片加载中
```

Flutter 中可以拆成：

```dart
isInitialLoading
isRefreshing
isLoadingMore
isSubmitting
```

或者用更明确的状态模型。

---

一句话理解：

```text
Web loading animation 常靠 spinner、progress、skeleton 和 CSS 动画；
Flutter 用 CircularProgressIndicator、LinearProgressIndicator、RefreshIndicator、Shimmer、AnimatedSwitcher 等 Widget，
再通过 loading/error/data 状态驱动 UI。
```
