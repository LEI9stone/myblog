# Skeleton Loading vs Shimmer

Web 里常见 Skeleton Loading：

```text
用灰色占位块模拟页面结构；
数据加载完成后替换成真实内容。
```

Flutter 里也常用 Skeleton Loading，常见实现是：

```dart
shimmer
自定义 Skeleton Widget
AnimatedContainer / AnimatedOpacity
占位灰块
```

可以这样映射：

| Web                        | Flutter                  |
| -------------------------- | ------------------------ |
| skeleton screen            | skeleton widget          |
| shimmer effect             | `shimmer` package        |
| loading placeholder        | placeholder Widget       |
| CSS keyframes shimmer      | Shimmer animation        |
| content layout placeholder | 与真实 Widget 同尺寸占位 |
| lazy image skeleton        | image placeholder        |
| loading card               | Skeleton Card Widget     |

---

## 1. Web Skeleton 心智

Web：

```html
<div class="skeleton-card">
  <div class="skeleton-image"></div>
  <div class="skeleton-line"></div>
  <div class="skeleton-line short"></div>
</div>
```

```css
.skeleton {
  background: linear-gradient(...);
  animation: shimmer 1.2s infinite;
}
```

核心是：

```text
先展示和真实内容接近的骨架；
减少加载时的空白和跳动。
```

---

## 2. Flutter Shimmer

Flutter 常用 `shimmer` 包：

```yaml
dependencies:
  shimmer: ^3.x.x
```

使用：

```dart
Shimmer.fromColors(
  baseColor: const Color(0xFFEAEAEA),
  highlightColor: const Color(0xFFF5F5F5),
  child: const SkeletonCard(),
)
```

项目中如果已有：

```yaml
shimmer: ^3.0.0
```

就可以直接使用。

---

## 3. Skeleton Widget

Flutter 通常会封装骨架组件：

```dart
class SkeletonBox extends StatelessWidget {
  const SkeletonBox({
    super.key,
    required this.width,
    required this.height,
    this.borderRadius = 4,
  });

  final double width;
  final double height;
  final double borderRadius;

  @override
  Widget build(BuildContext context) {
    return Container(
      width: width,
      height: height,
      decoration: BoxDecoration(
        color: Colors.white,
        borderRadius: BorderRadius.circular(borderRadius),
      ),
    );
  }
}
```

卡片骨架：

```dart
Shimmer.fromColors(
  baseColor: Colors.grey.shade300,
  highlightColor: Colors.grey.shade100,
  child: Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: const [
      SkeletonBox(width: double.infinity, height: 160),
      SizedBox(height: 12),
      SkeletonBox(width: 120, height: 14),
      SizedBox(height: 8),
      SkeletonBox(width: 80, height: 14),
    ],
  ),
)
```

## 4. 图片加载占位

Web：

```text
图片未加载时显示 skeleton；
加载完成后显示 img。
```

Flutter：

```dart
CachedNetworkImage(
  imageUrl: imageUrl,
  placeholder: (context, url) => const ImageSkeleton(),
  errorWidget: (context, url, error) => const ErrorImage(),
)
```

或原生：

```dart
Image.network(
  imageUrl,
  loadingBuilder: (context, child, progress) {
    if (progress == null) {
      return child;
    }

    return const ImageSkeleton();
  },
)
```

---

## 5. 保持尺寸一致

Skeleton 的关键不是闪光效果，而是：

```text
占位结构要接近真实内容尺寸。
```

例如真实商品卡片图片是固定比例：

```dart
AspectRatio(
  aspectRatio: 1,
  child: Image.network(...),
)
```

骨架也应该：

```dart
AspectRatio(
  aspectRatio: 1,
  child: SkeletonBox(...),
)
```

这样加载完成后不会大幅跳动。

## 6. 列表骨架

Web：

```text
渲染 6 个 skeleton card
```

Flutter：

```dart
GridView.builder(
  itemCount: 6,
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,
    crossAxisSpacing: 8,
    mainAxisSpacing: 8,
  ),
  itemBuilder: (context, index) {
    return const ProductCardSkeleton();
  },
)
```

或者：

```dart
ListView.separated(
  itemCount: 8,
  separatorBuilder: (_, __) => const SizedBox(height: 12),
  itemBuilder: (_, __) => const ListItemSkeleton(),
)
```

---

## 7. 什么时候不用 Skeleton

Skeleton 适合：

```text
列表页
卡片流
图片密集页面
首屏加载
结构稳定的内容
```

不一定适合：

```text
很短的请求
按钮级局部 loading
不可预测结构
一次性后台任务
```

这些场景可能用：

```dart
CircularProgressIndicator
LinearProgressIndicator
按钮 loading
```

更简单。

---

一句话理解：

```text
Web Skeleton Loading 通常用 CSS 占位块和 shimmer 动画；
Flutter 中常用 shimmer package + 自定义 Skeleton Widget。
关键是骨架尺寸和真实内容一致，避免加载完成后布局跳动。
```
