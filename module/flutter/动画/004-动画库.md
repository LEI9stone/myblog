# Framer Motion vs Flutter Animation APIs

Framer Motion 是 React 生态里高层动画库，强调声明式、手势、布局动画和组件切换动画。

Flutter 没有一个完全等价的内置库，但 Flutter Animation APIs 覆盖了从简单隐式动画到精确控制动画的多个层级。

可以这样映射：

| Framer Motion                  | Flutter                                  |
| ------------------------------ | ---------------------------------------- |
| `motion.div`                   | Animated Widget / Transition Widget      |
| `animate` prop                 | AnimatedContainer / Tween animation      |
| `initial` / `animate` / `exit` | AnimatedSwitcher / route transition      |
| `transition`                   | `duration` / `curve`                     |
| variants                       | enum/state + Widget 参数                 |
| layout animation               | AnimatedSize / AnimatedPositioned / Hero |
| drag gesture                   | GestureDetector + AnimationController    |
| spring                         | SpringSimulation / physics / packages    |
| shared layout transition       | Hero                                     |
| AnimatePresence                | AnimatedSwitcher / Navigator transition  |
| useAnimationControls           | AnimationController                      |

---

## 1. Framer Motion 心智

React：

```tsx
<motion.div
  initial={{ opacity: 0, y: 12 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.2 }}
>
  Content
</motion.div>
```

它的心智是：

```text
声明初始状态、目标状态和过渡参数；
Framer Motion 负责补间。
```

---

## 2. Flutter 简单过渡：隐式动画

Flutter：

```dart
AnimatedSlide(
  offset: visible ? Offset.zero : const Offset(0, 0.1),
  duration: const Duration(milliseconds: 200),
  curve: Curves.easeOut,
  child: AnimatedOpacity(
    opacity: visible ? 1 : 0,
    duration: const Duration(milliseconds: 200),
    child: child,
  ),
)
```

对应：

```text
Framer Motion animate prop
≈ Flutter 隐式动画 Widget 参数变化
```

---

## 3. AnimatedContainer 对应属性动画

Framer Motion：

```tsx
<motion.div animate={{ width: 120, borderRadius: 16 }} />
```

Flutter：

```dart
AnimatedContainer(
  duration: const Duration(milliseconds: 200),
  curve: Curves.ease,
  width: active ? 120 : 80,
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circular(active ? 16 : 8),
  ),
  child: child,
)
```

适合：

```text
颜色
尺寸
内边距
圆角
对齐
简单 transform
```

---

## 4. variants vs 状态枚举

Framer Motion：

```tsx
const variants = {
  idle: { opacity: 0.6 },
  active: { opacity: 1 },
};
```

Flutter 通常用状态驱动参数：

```dart
enum CardMotionState {
  idle,
  active,
}
```

```dart
final opacity = switch (state) {
  CardMotionState.idle => 0.6,
  CardMotionState.active => 1.0,
};

AnimatedOpacity(
  opacity: opacity,
  duration: const Duration(milliseconds: 200),
  child: child,
)
```

## 5. AnimatePresence vs AnimatedSwitcher

Framer Motion：

```tsx
<AnimatePresence>
  {visible && <motion.div exit={{ opacity: 0 }}>Content</motion.div>}
</AnimatePresence>
```

Flutter：

```dart
AnimatedSwitcher(
  duration: const Duration(milliseconds: 200),
  child: visible
      ? const Content(key: ValueKey('content'))
      : const SizedBox(key: ValueKey('empty')),
)
```

自定义切换：

```dart
AnimatedSwitcher(
  duration: const Duration(milliseconds: 200),
  transitionBuilder: (child, animation) {
    return FadeTransition(
      opacity: animation,
      child: SlideTransition(
        position: Tween<Offset>(
          begin: const Offset(0, 0.05),
          end: Offset.zero,
        ).animate(animation),
        child: child,
      ),
    );
  },
  child: currentChild,
)
```

---

## 6. layout animation vs AnimatedSize / Hero

Framer Motion：

```tsx
<motion.div layout />
```

Flutter 中常见：

```dart
AnimatedSize(
  duration: const Duration(milliseconds: 200),
  child: expanded ? ExpandedContent() : CompactContent(),
)
```

跨页面共享元素：

```dart
Hero(
  tag: product.id,
  child: ProductImage(product.imageUrl),
)
```

`Hero` 类似 shared element transition。

---

## 7. 手势动画

Framer Motion：

```tsx
<motion.div drag />
```

Flutter：

```dart
GestureDetector(
  onPanUpdate: (details) {
    controller.value += details.delta.dx / width;
  },
  onPanEnd: (_) {
    controller.fling();
  },
  child: AnimatedBuilder(
    animation: controller,
    builder: (context, child) {
      return Transform.translate(
        offset: Offset(controller.value * 100, 0),
        child: child,
      );
    },
    child: child,
  ),
)
```

Flutter 这里更底层，需要自己组合手势和动画控制器。

---

## 8. Spring 动画

Framer Motion 默认 spring 很方便。

Flutter 可以用物理模拟：

```dart
controller.animateWith(
  SpringSimulation(
    const SpringDescription(
      mass: 1,
      stiffness: 180,
      damping: 16,
    ),
    controller.value,
    1,
    0,
  ),
);
```

但业务里更常用：

```dart
Curves.easeOutBack
Curves.elasticOut
AnimationController.fling()
```

或使用第三方动画库。

---

## 9. 怎么选 Flutter API

| 需求             | Flutter 推荐                                           |
| ---------------- | ------------------------------------------------------ |
| 简单属性过渡     | `AnimatedContainer`                                    |
| 透明度           | `AnimatedOpacity`                                      |
| 平移/缩放/旋转   | `AnimatedSlide` / `AnimatedScale` / `AnimatedRotation` |
| 子组件切换       | `AnimatedSwitcher`                                     |
| 尺寸变化         | `AnimatedSize`                                         |
| Stack 中位置变化 | `AnimatedPositioned`                                   |
| 跨页面共享元素   | `Hero`                                                 |
| 手动控制动画     | `AnimationController`                                  |
| 每帧自定义绘制   | `CustomPainter` + animation                            |
| 手势驱动         | `GestureDetector` + `AnimationController`              |

一句话理解：

```text
Framer Motion 是 React 的高层声明式动画库；
Flutter 动画 API 是分层体系：
简单过渡用隐式动画 Widget，
复杂控制用 AnimationController，
页面共享元素用 Hero，
组件切换用 AnimatedSwitcher。
```
