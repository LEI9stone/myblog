# Page Transition vs Route Transition

Web 里页面切换动画通常发生在路由变化、组件挂载卸载、CSS transition 或动画库中。

Flutter 里页面切换动画属于 Route Transition，通常由：

```dart
Navigator
PageRoute
go_router
CustomTransitionPage
PageRouteBuilder
```

控制。

可以这样映射：

| Web Page Transition           | Flutter Route Transition                |
| ----------------------------- | --------------------------------------- |
| route change animation        | route transition                        |
| React Router page switch      | Navigator/go_router 页面切换            |
| CSS transition                | PageRoute transition                    |
| Framer Motion route animation | CustomTransitionPage / PageRouteBuilder |
| enter animation               | push transition                         |
| exit animation                | pop transition                          |
| shared element transition     | Hero                                    |
| modal transition              | showDialog / showModalBottomSheet       |
| browser history back          | Navigator.pop / system back             |

---

## 1. Web Page Transition

React Router 中常见：

```tsx
<Routes>
  <Route path="/products" element={<ProductList />} />
  <Route path="/products/:id" element={<ProductDetail />} />
</Routes>
```

页面动画可能通过：

```text
CSS class
Framer Motion
TransitionGroup
View Transition API
```

实现。

核心是：

```text
路由变化后，旧页面退出，新页面进入。
```

---

## 2. Flutter Route Transition

Flutter 页面切换通常是 route 入栈和出栈：

```dart
Navigator.of(context).push(
  MaterialPageRoute(
    builder: (context) => const ProductDetailPage(),
  ),
);
```

默认情况下：

```text
iOS 有平台风格侧滑转场；
Android 有 Material 风格转场。
```

如果用 `go_router`：

```dart
context.push('/products/1');
```

页面转场由 route/page 配置决定。

---

## 3. 自定义页面转场

Flutter 可以用 `PageRouteBuilder`：

```dart
Navigator.of(context).push(
  PageRouteBuilder(
    pageBuilder: (context, animation, secondaryAnimation) {
      return const ProductDetailPage();
    },
    transitionsBuilder: (context, animation, secondaryAnimation, child) {
      return FadeTransition(
        opacity: animation,
        child: child,
      );
    },
  ),
);
```

这里的 `animation` 可以理解为：

```text
页面进入进度：0 → 1
```

pop 时会反向：

```text
1 → 0
```

---

## 4. go_router 中的 CustomTransitionPage

如果项目使用 `go_router`，常用：

```dart
GoRoute(
  path: '/products/:id',
  pageBuilder: (context, state) {
    return CustomTransitionPage(
      key: state.pageKey,
      child: const ProductDetailPage(),
      transitionsBuilder: (context, animation, secondaryAnimation, child) {
        return FadeTransition(
          opacity: animation,
          child: child,
        );
      },
    );
  },
)
```

常见转场：

```dart
FadeTransition
SlideTransition
ScaleTransition
RotationTransition
```

---

## 5. Slide Transition

Web：

```css
.page-enter {
  transform: translateX(100%);
}
```

Flutter：

```dart
SlideTransition(
  position: Tween<Offset>(
    begin: const Offset(1, 0),
    end: Offset.zero,
  ).animate(animation),
  child: child,
)
```

从右侧进入：

```text
Offset(1, 0) → Offset.zero
```

从底部进入：

```dart
begin: const Offset(0, 1)
```

---

## 6. Shared Element：Hero

Web 中类似共享元素转场：

```text
列表图片 → 详情页图片
```

Flutter 用：

```dart
Hero(
  tag: product.id,
  child: Image.network(product.imageUrl),
)
```

列表页和详情页使用相同 `tag`：

```dart
Hero(
  tag: product.id,
  child: ProductImage(product.imageUrl),
)
```

Flutter 会自动在两个 route 之间做共享元素动画。

---

## 7. Modal Transition

Web：

```text
modal fade in
bottom sheet slide up
drawer slide in
```

Flutter 对应：

```dart
showDialog(...)
showModalBottomSheet(...)
showGeneralDialog(...)
Drawer
```

例如底部弹层：

```dart
showModalBottomSheet(
  context: context,
  builder: (context) => const ProductFilterSheet(),
);
```

这些也是 route，只是表现为弹层 route。

---

## 8. 怎么选

| 需求             | Flutter 推荐                                |
| ---------------- | ------------------------------------------- |
| 普通页面跳转     | `MaterialPageRoute` / `go_router`           |
| 自定义淡入淡出   | `CustomTransitionPage` / `PageRouteBuilder` |
| 左右滑动页面     | `SlideTransition`                           |
| 弹窗             | `showDialog`                                |
| 底部弹层         | `showModalBottomSheet`                      |
| 共享元素动画     | `Hero`                                      |
| 保持平台默认体验 | 使用默认 route transition                   |

一句话理解：

```text
Web Page Transition 通常围绕路由组件的进入和退出动画；
Flutter Route Transition 围绕 Navigator route 的 push/pop 动画。
普通页面用默认转场，
自定义转场用 PageRouteBuilder 或 go_router 的 CustomTransitionPage，
共享元素转场用 Hero。
```
