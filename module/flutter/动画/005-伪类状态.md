# Hover / Active / Focus vs `GestureDetector` / `InkWell` / `Focus`

Web 里常用伪类描述交互状态：

```css
:hover
:active
:focus
:disabled
```

Flutter 没有 CSS 伪类，而是用 Widget、状态和回调表达交互：

```dart
GestureDetector
InkWell
MouseRegion
Focus
FocusNode
WidgetStateProperty
```

可以这样映射：

| Web                | Flutter                                     |
| ------------------ | ------------------------------------------- |
| `:hover`           | `MouseRegion` / `InkWell.onHover`           |
| `:active`          | `InkWell` pressed state / Gesture callbacks |
| `:focus`           | `Focus` / `FocusNode`                       |
| `:disabled`        | `onPressed: null` / disabled state          |
| `cursor: pointer`  | `MouseRegion(cursor: ...)`                  |
| `onclick`          | `onTap` / `onPressed`                       |
| pointer event      | `Listener` / `GestureDetector`              |
| button state style | `WidgetStateProperty`                       |
| keyboard focus     | `Focus` / `Shortcuts` / `Actions`           |

---

## 1. 点击交互：GestureDetector

Web：

```tsx
<div onClick={handleClick}>Card</div>
```

Flutter：

```dart
GestureDetector(
  onTap: handleTap,
  child: CardContent(),
)
```

`GestureDetector` 适合：

```text
点击
长按
拖拽
缩放
滑动
自定义手势
```

例如：

```dart
GestureDetector(
  onTap: onTap,
  onLongPress: onLongPress,
  onPanUpdate: onPanUpdate,
  child: child,
)
```

---

## 2. Material 点击反馈：InkWell

Web：

```css
.button:active {
  background: #eee;
}
```

Flutter Material 风格中更常用：

```dart
InkWell(
  onTap: onTap,
  child: Padding(
    padding: const EdgeInsets.all(12),
    child: child,
  ),
)
```

`InkWell` 会提供：

```text
水波纹
hover 状态
focus 状态
pressed 状态
Material 语义
```

注意 `InkWell` 的水波纹通常需要有 `Material` 祖先：

```dart
Material(
  color: Colors.transparent,
  child: InkWell(
    onTap: onTap,
    child: child,
  ),
)
```

## 3. hover

Web：

```css
.card:hover {
  background: #f5f5f5;
}
```

Flutter：

```dart
MouseRegion(
  onEnter: (_) => setHovered(true),
  onExit: (_) => setHovered(false),
  cursor: SystemMouseCursors.click,
  child: AnimatedContainer(
    duration: const Duration(milliseconds: 150),
    color: hovered ? Colors.grey.shade100 : Colors.white,
    child: child,
  ),
)
```

如果用 `InkWell`：

```dart
InkWell(
  onHover: (hovering) {
    setHovered(hovering);
  },
  onTap: onTap,
  child: child,
)
```

Hover 主要用于：

```text
Flutter Web
桌面端
鼠标设备
```

移动端通常没有 hover。

## 4. active / pressed

Web：

```css
.button:active {
  transform: scale(0.98);
}
```

Flutter 可以用 `GestureDetector`：

```dart
GestureDetector(
  onTapDown: (_) => setPressed(true),
  onTapCancel: () => setPressed(false),
  onTapUp: (_) => setPressed(false),
  onTap: onTap,
  child: AnimatedScale(
    scale: pressed ? 0.98 : 1,
    duration: const Duration(milliseconds: 100),
    child: child,
  ),
)
```

或使用 ButtonStyle：

```dart
ButtonStyle(
  backgroundColor: WidgetStateProperty.resolveWith((states) {
    if (states.contains(WidgetState.pressed)) {
      return Colors.grey.shade300;
    }
    return Colors.white;
  }),
)
```

## 5. focus

Web：

```css
.input:focus {
  border-color: blue;
}
```

Flutter：

```dart
final focusNode = FocusNode();
```

```dart
TextField(
  focusNode: focusNode,
  decoration: InputDecoration(
    focusedBorder: OutlineInputBorder(
      borderSide: BorderSide(color: Colors.blue),
    ),
  ),
)
```

通用 Focus：

```dart
Focus(
  onFocusChange: (focused) {
    setFocused(focused);
  },
  child: child,
)
```

键盘快捷键和焦点系统常结合：

```dart
Shortcuts
Actions
FocusTraversalGroup
```

---

## 6. disabled

Web：

```html
<button disabled>Submit</button>
```

Flutter：

```dart
ElevatedButton(
  onPressed: enabled ? onSubmit : null,
  child: const Text('Submit'),
)
```

在 Flutter Material 组件里：

```text
onPressed 为 null 通常表示 disabled。
```

---

## 7. WidgetStateProperty

Web：

```css
.button:hover {
}
.button:active {
}
.button:disabled {
}
```

Flutter Material 组件中可用：

```dart
ButtonStyle(
  foregroundColor: WidgetStateProperty.resolveWith((states) {
    if (states.contains(WidgetState.disabled)) {
      return Colors.grey;
    }
    if (states.contains(WidgetState.pressed)) {
      return Colors.white;
    }
    return Colors.black;
  }),
)
```

常见状态：

```text
hovered
focused
pressed
disabled
selected
```

---

一句话理解：

```text
Web 用 :hover/:active/:focus 这类伪类描述交互状态；
Flutter 用 GestureDetector 处理手势，
用 InkWell 处理 Material 点击反馈，
用 MouseRegion 处理 hover，
用 Focus/FocusNode 处理焦点，
用 WidgetStateProperty 统一 Material 组件状态样式。
```
