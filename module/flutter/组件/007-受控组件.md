# Controlled Component vs State-driven Widget

React 里的 Controlled Component 指组件的值由外部 state 控制，比如 input 的 `value` 和 `onChange`。

Flutter 里没有完全同名概念，但对应的是 State-driven Widget：Widget 的显示由外部状态、Controller 或 Provider 状态驱动。

可以这样映射：

| React Controlled Component | Flutter State-driven Widget                        |
| -------------------------- | -------------------------------------------------- |
| `value` prop               | `controller.text` / external state                 |
| `onChange` prop            | `onChanged` callback                               |
| parent owns state          | parent / Provider owns state                       |
| input controlled by state  | `TextEditingController` / state drives `TextField` |
| uncontrolled input         | TextField 内部状态 / controller local              |
| form state                 | `Form` + controllers / Provider state              |
| controlled select          | `DropdownButton.value`                             |
| controlled checkbox        | `Checkbox.value`                                   |
| controlled tabs            | `TabController` / selected index state             |

---

## 1. React Controlled Component

React：

```tsx
function SearchBox() {
  const [keyword, setKeyword] = useState('');

  return <input value={keyword} onChange={(e) => setKeyword(e.target.value)} />;
}
```

核心是：

```text
输入框显示什么，由 React state 决定；
用户输入后通过 onChange 更新 state；
state 再驱动 UI。
```

## 2. Flutter TextField with Controller

Flutter 常用 `TextEditingController`：

```dart
class SearchBox extends StatefulWidget {
  const SearchBox({super.key});

  @override
  State<SearchBox> createState() => _SearchBoxState();
}

class _SearchBoxState extends State<SearchBox> {
  late final TextEditingController controller;

  @override
  void initState() {
    super.initState();
    controller = TextEditingController();
  }

  @override
  void dispose() {
    controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return TextField(
      controller: controller,
      onChanged: (value) {
        // update state or trigger search
      },
    );
  }
}
```

这里：

```text
controller 持有输入框文本；
TextField 根据 controller 显示文本；
用户输入会更新 controller。
```

## 3. 外部状态驱动

如果希望父级完全控制输入值，可以把状态上提。

Flutter：

```dart
class SearchBox extends StatelessWidget {
  const SearchBox({
    super.key,
    required this.controller,
    required this.onChanged,
  });

  final TextEditingController controller;
  final ValueChanged<String> onChanged;

  @override
  Widget build(BuildContext context) {
    return TextField(
      controller: controller,
      onChanged: onChanged,
    );
  }
}
```

父级：

```dart
final controller = TextEditingController(text: keyword);
```

不过注意：不要在 `build()` 中反复创建 controller，否则会丢光标和输入状态。

## 4. Checkbox / Switch 更像 React controlled

React：

```tsx
<input
  type="checkbox"
  checked={enabled}
  onChange={(e) => setEnabled(e.target.checked)}
/>
```

Flutter：

```dart
Checkbox(
  value: enabled,
  onChanged: (value) {
    setState(() {
      enabled = value ?? false;
    });
  },
)
```

Switch：

```dart
Switch(
  value: enabled,
  onChanged: (value) {
    setState(() {
      enabled = value;
    });
  },
)
```

这里非常接近 React controlled component：

```text
value 来自 state；
onChanged 更新 state。
```

## 5. Dropdown

React：

```tsx
<select value={category} onChange={...}>
  ...
</select>
```

Flutter：

```dart
DropdownButton<String>(
  value: category,
  items: categories.map((item) {
    return DropdownMenuItem(
      value: item.id,
      child: Text(item.name),
    );
  }).toList(),
  onChanged: (value) {
    setState(() {
      category = value;
    });
  },
)
```

## 6. Controller vs value/onChanged

Flutter 里有两种常见模式：

| 控件类型         | 常见控制方式            |
| ---------------- | ----------------------- |
| `TextField`      | `TextEditingController` |
| `Checkbox`       | `value` + `onChanged`   |
| `Switch`         | `value` + `onChanged`   |
| `Slider`         | `value` + `onChanged`   |
| `DropdownButton` | `value` + `onChanged`   |
| `TabBar`         | `TabController`         |
| `PageView`       | `PageController`        |
| `ScrollView`     | `ScrollController`      |

React 更统一地倾向于 `value/onChange`；Flutter 对复杂控件常使用 Controller。

## 7. Riverpod 场景

如果状态放在 Riverpod：

```dart
final keywordProvider = StateProvider<String>((ref) => '');
```

```dart
Consumer(
  builder: (context, ref, child) {
    final keyword = ref.watch(keywordProvider);

    return TextField(
      onChanged: (value) {
        ref.read(keywordProvider.notifier).state = value;
      },
    );
  },
)
```

如果要同步 controller，需要处理初始化和监听，避免每次 rebuild 重置输入。

---

一句话理解：

```text
React Controlled Component 用 value + onChange 让外部 state 完全控制表单控件；
Flutter 的 State-driven Widget 用 state、controller、value/onChanged 或 Provider 状态驱动 UI。
TextField 常用 TextEditingController，
Checkbox/Switch/Dropdown 更接近 React 的 controlled value 模式。
```
