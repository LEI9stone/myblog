# Function Component vs `StatelessWidget`

React 的 Function Component 和 Flutter 的 `StatelessWidget` 都适合表达“输入决定输出”的 UI。

它们本质上都接收外部参数，然后返回一段声明式界面结构。

| React Function Component | Flutter StatelessWidget                                     |
| ------------------------ | ----------------------------------------------------------- |
| function component       | `StatelessWidget`                                           |
| props                    | constructor parameters                                      |
| JSX return               | `build()` return Widget                                     |
| 无内部状态组件           | 无内部可变状态 Widget                                       |
| re-render                | rebuild                                                     |
| children prop            | `child` / `children`                                        |
| default props            | 构造参数默认值                                              |
| memo                     | `const` constructor / 局部优化                              |
| hooks                    | 不属于 `StatelessWidget`，通常用 Riverpod 或 StatefulWidget |

---

## 1. 基本写法

React：

```tsx
type ProductCardProps = {
  title: string;
  price: number;
};

function ProductCard({ title, price }: ProductCardProps) {
  return (
    <div>
      <h3>{title}</h3>
      <p>{price}</p>
    </div>
  );
}
```

Flutter：

```dart
class ProductCard extends StatelessWidget {
  const ProductCard({
    super.key,
    required this.title,
    required this.price,
  });

  final String title;
  final double price;

  @override
  Widget build(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(title),
        Text('$price'),
      ],
    );
  }
}
```

核心映射：

```text
React props
≈ Flutter constructor parameters
```

```text
React return JSX
≈ Flutter build return Widget
```

---

## 2. StatelessWidget 没有内部可变状态

React Function Component 可以用 hooks 拥有状态：

```tsx
function Counter() {
  const [count, setCount] = useState(0);

  return <button>{count}</button>;
}
```

但 Flutter 的 `StatelessWidget` 不能自己持有可变 UI 状态。

如果需要内部状态，要用：

```dart
StatefulWidget
```

如果状态由外部管理，比如 Riverpod，可以用：

```dart
ConsumerWidget
```

所以更准确的映射是：

```text
无 useState 的 Function Component
≈ StatelessWidget
```

有 `useState` 的 Function Component 更接近：

```text
StatefulWidget / ConsumerWidget + Provider state
```

---

## 3. props vs final fields

React：

```tsx
<ProductCard title="Cup" price={99} />
```

Flutter：

```dart
const ProductCard(
  title: 'Cup',
  price: 99,
)
```

Flutter 中参数通常保存为 `final` 字段：

```dart
final String title;
final double price;
```

这符合 Widget 的不可变设计。

---

## 4. children vs child/children

React：

```tsx
function Card({ children }: { children: React.ReactNode }) {
  return <div className="card">{children}</div>;
}
```

Flutter：

```dart
class AppCard extends StatelessWidget {
  const AppCard({
    super.key,
    required this.child,
  });

  final Widget child;

  @override
  Widget build(BuildContext context) {
    return Container(
      child: child,
    );
  }
}
```

使用：

```dart
AppCard(
  child: Text('Product'),
)
```

多个 children：

```dart
class AppSection extends StatelessWidget {
  const AppSection({
    super.key,
    required this.children,
  });

  final List<Widget> children;

  @override
  Widget build(BuildContext context) {
    return Column(
      children: children,
    );
  }
}
```

## 5. 默认参数

React：

```tsx
function Button({ size = 'medium' }) {
  return <button>{size}</button>;
}
```

Flutter：

```dart
class AppButton extends StatelessWidget {
  const AppButton({
    super.key,
    this.size = AppButtonSize.medium,
  });

  final AppButtonSize size;

  @override
  Widget build(BuildContext context) {
    return Text('$size');
  }
}
```

---

## 6. rebuild vs re-render

React Function Component 会随着 props/state/context 变化重新执行。

Flutter `StatelessWidget` 的 `build()` 也会在父级 rebuild、参数变化、依赖的 inherited data 变化时重新执行。

这很正常：

```text
React function component 可以频繁 re-render；
Flutter StatelessWidget 可以频繁 rebuild。
```

Flutter 中 Widget 很轻量，不要把 rebuild 理解成昂贵的 DOM 重建。

---

## 7. const 优化

Flutter 中如果 Widget 参数都是编译期常量，可以写：

```dart
const ProductCard(
  title: 'Cup',
  price: 99,
)
```

`const` 可以减少重复创建 Widget 对象。

React 中粗略类比是：

```text
React.memo 用来减少不必要 re-render；
Flutter const 用来减少不必要 Widget 实例创建。
```

但两者机制不同，不要完全等同。

---

一句话理解：

```text
React Function Component 接收 props 返回 JSX；
Flutter StatelessWidget 接收构造参数，在 build 中返回 Widget。
无内部状态的 Function Component 最接近 StatelessWidget；
如果用了 useState，则更接近 StatefulWidget 或外部状态管理方案。
```
