# Stateful Component vs `StatefulWidget`

React 中有状态的组件通常用：

```tsx
useState
useReducer
class component state
```

Flutter 中组件内部有可变状态时，通常用：

```dart
StatefulWidget
```

可以这样映射：

| React Stateful Component | Flutter StatefulWidget                      |
| ------------------------ | ------------------------------------------- |
| `useState`               | `State` 字段 + `setState`                   |
| `useReducer`             | `State` 字段 / 外部状态管理                 |
| component state          | `State<T>`                                  |
| `setState` / setter      | `setState(() {})`                           |
| render                   | `build()`                                   |
| mount                    | `initState()`                               |
| unmount                  | `dispose()`                                 |
| props update             | `didUpdateWidget()`                         |
| effect                   | `initState` / `didUpdateWidget` / `dispose` |
| ref                      | `GlobalKey` / controller / focus node       |

---

## 1. React 有状态组件

React：

```tsx
function Counter() {
  const [count, setCount] = useState(0);

  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

Flutter：

```dart
class Counter extends StatefulWidget {
  const Counter({super.key});

  @override
  State<Counter> createState() => _CounterState();
}

class _CounterState extends State<Counter> {
  var count = 0;

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () {
        setState(() {
          count++;
        });
      },
      child: Text('$count'),
    );
  }
}
```

核心映射：

```text
React useState state
≈ Flutter State 对象里的字段
```

```text
setCount(...)
≈ setState(() { ... })
```

---

## 2. StatefulWidget 和 State 是分开的

Flutter 里有两个类：

```dart
StatefulWidget
State<StatefulWidget>
```

例如：

```dart
class Counter extends StatefulWidget {}
class _CounterState extends State<Counter> {}
```

可以理解为：

| Flutter          | 作用                     |
| ---------------- | ------------------------ |
| `StatefulWidget` | 不可变配置，接收外部参数 |
| `State`          | 持有可变状态和生命周期   |

React Function Component 把 props、state、effect 写在一个函数里；Flutter 把 Widget 配置和 State 状态对象拆开。

---

## 3. setState

Flutter：

```dart
setState(() {
  count++;
});
```

含义：

```text
修改 State 字段；
通知 Flutter 重新调用 build。
```

注意：

```text
不要在 build() 里直接 setState；
不要在 dispose 后 setState；
异步回调 setState 前注意 mounted。
```

常见写法：

```dart
if (!mounted) return;

setState(() {
  loading = false;
});
```

---

## 4. props 更新：widget.xxx

React：

```tsx
function ProductCard({ product }) {
  return <div>{product.title}</div>;
}
```

Flutter `State` 中访问外部参数：

```dart
widget.product
```

例如：

```dart
class ProductCard extends StatefulWidget {
  const ProductCard({
    super.key,
    required this.product,
  });

  final Product product;

  @override
  State<ProductCard> createState() => _ProductCardState();
}

class _ProductCardState extends State<ProductCard> {
  @override
  Widget build(BuildContext context) {
    return Text(widget.product.title);
  }
}
```

## 5. 生命周期映射

| React                    | Flutter                                     |
| ------------------------ | ------------------------------------------- |
| first render / mount     | `initState()`                               |
| render                   | `build()`                                   |
| props change             | `didUpdateWidget()`                         |
| effect cleanup / unmount | `dispose()`                                 |
| layout effect            | `addPostFrameCallback` / layout callbacks   |
| dependency change effect | `didUpdateWidget` / external state listener |

常见：

```dart
@override
void initState() {
  super.initState();
  // 初始化 controller、发起一次性任务
}

@override
void dispose() {
  controller.dispose();
  super.dispose();
}
```

---

## 6. Controller 类状态

Flutter 中很多输入和动画都需要 controller：

```dart
late final TextEditingController controller;

@override
void initState() {
  super.initState();
  controller = TextEditingController();
}

@override
void dispose() {
  controller.dispose();
  super.dispose();
}
```

对应 React 中常见：

```tsx
const inputRef = useRef(...)
```

或 controlled input state。

---

## 7. 什么时候用 StatefulWidget

适合：

```text
输入框 controller
动画 controller
TabController
PageController
局部展开/收起
局部 hover/pressed 状态
只属于该组件的小状态
```

不适合把所有业务状态都放进去。跨页面、跨组件、可缓存、需要测试的状态更适合：

```text
Riverpod / Provider / Bloc / Repository state
```

---

一句话理解：

```text
React Stateful Component 通常用 useState/useEffect 管内部状态；
Flutter StatefulWidget 把不可变 Widget 配置和可变 State 对象拆开，
用 State 字段保存局部状态，
用 setState 触发 rebuild。
```
