# Render Props vs Builder Pattern

React 里的 Render Props 是把“如何渲染”作为函数传给组件。

Flutter 里对应的是 Builder Pattern，也就是把 `Widget Function(...)` 传给 Widget，让调用方根据上下文、数据或状态返回 UI。

可以这样映射：

| React Render Props        | Flutter Builder Pattern                               |
| ------------------------- | ----------------------------------------------------- |
| `render={(data) => ...}`  | `builder: (context, data) => ...`                     |
| `children` as function    | `builder` callback                                    |
| scoped slot               | `builder` callback                                    |
| render item               | `itemBuilder`                                         |
| render loading/error/data | `FutureBuilder` / `StreamBuilder` / `AsyncValue.when` |
| render by layout          | `LayoutBuilder`                                       |
| render by context         | `Builder`                                             |
| render list item          | `ListView.builder`                                    |

---

## 1. React Render Props

React：

```tsx
<DataLoader render={(data) => <ProductList products={data} />} />
```

或者：

```tsx
<DataLoader>{(data) => <ProductList products={data} />}</DataLoader>
```

核心是：

```text
组件负责拿数据或状态；
调用方负责决定怎么渲染。
```

---

## 2. Flutter builder

Flutter：

```dart
DataLoader(
  builder: (context, data) {
    return ProductList(products: data);
  },
)
```

自定义类型通常是：

```dart
final Widget Function(BuildContext context, T data) builder;
```

例如：

```dart
class DataLoader<T> extends StatelessWidget {
  const DataLoader({
    super.key,
    required this.data,
    required this.builder,
  });

  final T data;
  final Widget Function(BuildContext context, T data) builder;

  @override
  Widget build(BuildContext context) {
    return builder(context, data);
  }
}
```

---

## 3. ListView.builder

React：

```tsx
{
  items.map((item) => <ItemCard key={item.id} item={item} />);
}
```

Flutter：

```dart
ListView.builder(
  itemCount: items.length,
  itemBuilder: (context, index) {
    return ItemCard(item: items[index]);
  },
)
```

`itemBuilder` 是 Flutter 最常见的 Builder Pattern。

优点：

```text
按需构建列表项；
避免一次性创建全部 Widget；
适合长列表。
```

## 4. FutureBuilder

React：

```tsx
<DataLoader>
  {({ loading, error, data }) => {
    if (loading) return <Loading />;
    if (error) return <ErrorView />;
    return <Content data={data} />;
  }}
</DataLoader>
```

Flutter：

```dart
FutureBuilder<Product>(
  future: fetchProduct(),
  builder: (context, snapshot) {
    if (snapshot.connectionState == ConnectionState.waiting) {
      return const LoadingView();
    }

    if (snapshot.hasError) {
      return ErrorView(error: snapshot.error);
    }

    return ProductView(product: snapshot.data!);
  },
)
```

---

## 5. LayoutBuilder

Web 中类似 container query 的场景，React 可能用 render prop：

```tsx
<Measure>{({ width }) => (width < 300 ? <Compact /> : <Regular />)}</Measure>
```

Flutter：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth < 300) {
      return const CompactView();
    }

    return const RegularView();
  },
)
```

---

## 6. Builder Widget

Flutter 还有一个直接叫 `Builder` 的 Widget：

```dart
Builder(
  builder: (context) {
    return Text(
      Theme.of(context).colorScheme.primary.toString(),
    );
  },
)
```

它常用于拿到一个新的 `BuildContext`。

比如在某个 Widget 子树内部读取刚创建的 Theme、Scaffold、Provider 上下文。

---

## 7. 自定义 builder 参数命名

Flutter 常见命名：

| 参数名               | 场景        |
| -------------------- | ----------- |
| `builder`            | 通用构建    |
| `itemBuilder`        | 列表/网格项 |
| `separatorBuilder`   | 分隔符      |
| `transitionBuilder`  | 动画过渡    |
| `pageBuilder`        | 路由页面    |
| `errorBuilder`       | 错误 UI     |
| `loadingBuilder`     | 加载 UI     |
| `placeholderBuilder` | 占位 UI     |

---

一句话理解：

```text
React Render Props 把渲染函数传给组件；
Flutter Builder Pattern 把 Widget builder 回调传给 Widget。
它常用于列表、异步状态、布局测量、动画转场和可扩展组件插槽。
```
