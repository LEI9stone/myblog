# CSS Overflow vs Clip/ScrollView

Web 里用 `overflow` 控制内容超出容器后怎么处理：

```css
overflow: visible;
overflow: hidden;
overflow: auto;
overflow: scroll;
```

Flutter 里没有统一的 `overflow` CSS 属性，而是用不同 Widget 明确表达：

```dart
ClipRect
ClipRRect
SingleChildScrollView
ListView
GridView
CustomScrollView
OverflowBox
```

可以这样映射：

| CSS / Web              | Flutter                                                                     |
| ---------------------- | --------------------------------------------------------------------------- |
| `overflow: visible`    | 默认部分场景可见 / `OverflowBox`                                            |
| `overflow: hidden`     | `ClipRect` / `ClipRRect` / `ClipPath`                                       |
| `overflow: scroll`     | `SingleChildScrollView` / `ListView`                                        |
| `overflow: auto`       | 根据内容选择 ScrollView                                                     |
| `overflow-x`           | 横向 `SingleChildScrollView` / `ListView(scrollDirection: Axis.horizontal)` |
| `overflow-y`           | 纵向 `SingleChildScrollView` / `ListView`                                   |
| text overflow          | `TextOverflow.ellipsis`                                                     |
| border-radius + hidden | `ClipRRect` / `Material(clipBehavior: ...)`                                 |
| long list scroll       | `ListView.builder`                                                          |
| complex scroll         | `CustomScrollView` + Sliver                                                 |

---

## 1. Flutter 不用一个 overflow 属性解决所有问题

Web：

```css
.card {
  overflow: hidden;
}
```

Flutter：

```dart
ClipRRect(
  borderRadius: BorderRadius.circular(8),
  child: child,
)
```

Web：

```css
.list {
  overflow-y: auto;
}
```

Flutter：

```dart
ListView(
  children: [...],
)
```

Flutter 更倾向于：

```text
裁剪用 Clip；
滚动用 ScrollView/ListView；
文本溢出用 TextOverflow；
特殊越界用 OverflowBox。
```

---

## 2. overflow hidden vs Clip

Web：

```css
.avatar {
  width: 48px;
  height: 48px;
  border-radius: 50%;
  overflow: hidden;
}
```

Flutter：

```dart
ClipOval(
  child: Image.network(
    avatarUrl,
    width: 48,
    height: 48,
    fit: BoxFit.cover,
  ),
)
```

圆角裁剪：

```dart
ClipRRect(
  borderRadius: BorderRadius.circular(8),
  child: Image.network(imageUrl),
)
```

矩形裁剪：

```dart
ClipRect(
  child: child,
)
```

---

## 3. overflow scroll vs ScrollView

Web：

```css
.container {
  height: 400px;
  overflow-y: auto;
}
```

Flutter：

```dart
SizedBox(
  height: 400,
  child: ListView(
    children: items.map((item) => ItemTile(item)).toList(),
  ),
)
```

如果只有一个内容块需要滚动：

```dart
SingleChildScrollView(
  child: Column(
    children: [...],
  ),
)
```

选择建议：

| 场景              | Flutter                                      |
| ----------------- | -------------------------------------------- |
| 单个大内容滚动    | `SingleChildScrollView`                      |
| 长列表            | `ListView.builder`                           |
| 网格滚动          | `GridView.builder`                           |
| 复杂吸顶/组合滚动 | `CustomScrollView`                           |
| 横向滚动          | `ListView(scrollDirection: Axis.horizontal)` |

---

## 4. Text overflow

Web：

```css
.title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

Flutter：

```dart
Text(
  title,
  maxLines: 1,
  overflow: TextOverflow.ellipsis,
)
```

多行省略：

```dart
Text(
  description,
  maxLines: 2,
  overflow: TextOverflow.ellipsis,
)
```

---

## 5. 默认溢出行为差异

Web 中很多内容溢出后仍可能可见，或者撑开父容器。

Flutter 中如果 child 超过父级约束，经常会直接报布局溢出提示，例如：

```text
A RenderFlex overflowed by xx pixels
```

典型场景：

```dart
Row(
  children: [
    Text(longTitle),
    Icon(Icons.chevron_right),
  ],
)
```

修复通常是：

```dart
Row(
  children: [
    Expanded(
      child: Text(
        longTitle,
        maxLines: 1,
        overflow: TextOverflow.ellipsis,
      ),
    ),
    Icon(Icons.chevron_right),
  ],
)
```

也就是说：

```text
Flutter 里溢出通常是布局约束问题，需要明确约束、滚动或裁剪。
```

---

## 6. OverflowBox

如果你确实希望子元素超出父级约束，可以用：

```dart
OverflowBox(
  maxWidth: double.infinity,
  child: child,
)
```

但这不是常规布局首选，更多用于特殊视觉效果。

---

一句话理解：

```text
CSS overflow 是一个统一样式属性；
Flutter 把溢出拆成明确的 Widget：
要裁剪用 Clip，
要滚动用 ScrollView/ListView，
要文本省略用 TextOverflow，
要允许越界才用 OverflowBox。
```
