# CSS Box Model vs Flutter Layout Model

Web 里布局的核心是 CSS Box Model。

Flutter 里布局的核心是 Constraints 约束模型。

可以这样映射：

| CSS / Web             | Flutter                             |
| --------------------- | ----------------------------------- |
| Box Model             | Constraints Layout Model            |
| content box           | child size                          |
| padding               | `Padding` / `Container.padding`     |
| border                | `BoxDecoration.border`              |
| margin                | `Container.margin` / 外层 `Padding` |
| width / height        | `SizedBox` / `ConstrainedBox`       |
| min-width / max-width | `BoxConstraints`                    |
| display flex          | `Row` / `Column` / `Flex`           |
| position              | `Stack` / `Positioned`              |
| overflow              | `Clip` / `ScrollView`               |
| box-sizing            | 无直接等价，靠约束和 Widget 组合    |

---

## 1. CSS Box Model

Web 中一个元素通常由这些部分组成：

```text
margin
  border
    padding
      content
```

例如：

```css
.card {
  width: 200px;
  padding: 16px;
  border: 1px solid #ddd;
  margin: 12px;
}
```

浏览器会根据 CSS 规则、父容器、盒模型和布局上下文计算最终尺寸。

---

## 2. Flutter Layout Model

Flutter 不使用 CSS Box Model，而是使用约束传递：

```text
父 Widget 给子 Widget 约束
子 Widget 在约束内决定自己的尺寸
父 Widget 决定子 Widget 的位置
```

经典规则是：

```text
Constraints go down.
Sizes go up.
Parent sets position.
```

可以理解为：

```text
约束向下传递；
尺寸向上返回；
父级决定位置。
```

---

## 3. Padding / Margin 映射

Web：

```css
.card {
  margin: 12px;
  padding: 16px;
}
```

Flutter：

```dart
Container(
  margin: const EdgeInsets.all(12),
  padding: const EdgeInsets.all(16),
  child: const Text('Product'),
)
```

或者更明确地组合：

```dart
Padding(
  padding: const EdgeInsets.all(12),
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: const Text('Product'),
  ),
)
```

Flutter 里 `margin` 不是所有 Widget 都有，通常是 `Container` 的便利属性，或者用外层 `Padding` 表达。

---

## 4. width / height 映射

Web：

```css
.box {
  width: 200px;
  height: 100px;
}
```

Flutter：

```dart
SizedBox(
  width: 200,
  height: 100,
  child: child,
)
```

或者：

```dart
Container(
  width: 200,
  height: 100,
  child: child,
)
```

如果需要 min/max：

```dart
ConstrainedBox(
  constraints: const BoxConstraints(
    minWidth: 100,
    maxWidth: 300,
    minHeight: 80,
    maxHeight: 200,
  ),
  child: child,
)
```

---

## 5. border / background 映射

Web：

```css
.card {
  background: white;
  border: 1px solid #eee;
  border-radius: 8px;
}
```

Flutter：

```dart
Container(
  decoration: BoxDecoration(
    color: Colors.white,
    border: Border.all(color: const Color(0xFFEEEEEE)),
    borderRadius: BorderRadius.circular(8),
  ),
  child: child,
)
```

注意：

```text
Flutter 的 padding、size、decoration 是不同职责；
复杂样式通常通过多个 Widget 组合。
```

---

## 6. box-sizing 差异

Web 里有：

```css
box-sizing: content-box;
box-sizing: border-box;
```

Flutter 没有完全等价的 `box-sizing`。

Flutter 的尺寸由约束和 Widget 组合决定。例如：

```dart
SizedBox(
  width: 200,
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: child,
  ),
)
```

这里整体宽度是 200，padding 会占用内部空间。

如果反过来：

```dart
Padding(
  padding: const EdgeInsets.all(16),
  child: SizedBox(
    width: 200,
    child: child,
  ),
)
```

整体宽度会变成：

```text
200 + 左右 padding
```

所以 Flutter 中 Widget 嵌套顺序会直接影响布局结果。

---

## 7. 主要心智差异

Web 中你常想：

```text
这个元素的 width、padding、border、margin 加起来是多少？
```

Flutter 中你更应该想：

```text
父级给了什么约束？
当前 Widget 如何改变约束？
子 Widget 会返回什么尺寸？
父级把它放在哪里？
```

一句话理解：

```text
CSS Box Model 是元素自身盒子的尺寸计算模型；
Flutter Layout Model 是父子 Widget 之间传递约束、返回尺寸、确定位置的布局协议。
```
