# CSS Display/Flex/Grid vs Flutter Row/Column/Grid

Web 里通过 `display` 决定元素的布局上下文：

```css
display: block;
display: inline;
display: flex;
display: grid;
```

Flutter 里没有 `display` 属性，而是直接选择对应的布局 Widget：

```dart
Row
Column
Flex
Wrap
Stack
GridView
CustomScrollView
```

可以这样映射：

| CSS / Web                | Flutter                                            |
| ------------------------ | -------------------------------------------------- |
| `display: block`         | `Column` 中的普通 child / `SizedBox` / `Container` |
| `display: inline`        | `TextSpan` / `Wrap` / `Row`                        |
| `display: flex`          | `Row` / `Column` / `Flex`                          |
| `flex-direction: row`    | `Row`                                              |
| `flex-direction: column` | `Column`                                           |
| `justify-content`        | `mainAxisAlignment`                                |
| `align-items`            | `crossAxisAlignment`                               |
| `gap`                    | `spacing` / `SizedBox` / `Wrap.spacing`            |
| `flex: 1`                | `Expanded` / `Flexible`                            |
| `display: grid`          | `GridView` / `SliverGrid`                          |
| `grid-template-columns`  | `SliverGridDelegate`                               |
| `flex-wrap`              | `Wrap`                                             |
| `position` layout        | `Stack` / `Positioned`                             |

---

## 1. Flutter 没有 `display`

Web：

```css
.card-list {
  display: flex;
  flex-direction: row;
}
```

Flutter：

```dart
Row(
  children: [
    ProductCard(),
    ProductCard(),
  ],
)
```

在 Flutter 里，布局行为不是某个 `display` 属性决定的，而是由你选择的 Widget 决定。

```text
想横向排列：Row
想纵向排列：Column
想网格：GridView
想层叠：Stack
想换行：Wrap
```

---

## 2. Flexbox vs Row/Column

Web：

```css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

Flutter：

```dart
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  crossAxisAlignment: CrossAxisAlignment.center,
  children: [
    Text('Left'),
    Text('Right'),
  ],
)
```

映射：

| Flexbox                  | Flutter              |
| ------------------------ | -------------------- |
| 主轴                     | mainAxis             |
| 交叉轴                   | crossAxis            |
| `justify-content`        | `mainAxisAlignment`  |
| `align-items`            | `crossAxisAlignment` |
| `flex-direction: row`    | `Row`                |
| `flex-direction: column` | `Column`             |

---

## 3. `flex: 1` vs Expanded/Flexible

Web：

```css
.sidebar {
  width: 240px;
}

.content {
  flex: 1;
}
```

Flutter：

```dart
Row(
  children: [
    const SizedBox(width: 240, child: Sidebar()),
    Expanded(
      child: Content(),
    ),
  ],
)
```

`Expanded` 可以理解为：

```text
占用主轴剩余空间。
```

`Flexible` 更松一些：

```dart
Flexible(
  child: Content(),
)
```

简单理解：

| Flutter    | 含义                           |
| ---------- | ------------------------------ |
| `Expanded` | 必须填满剩余空间               |
| `Flexible` | 可以占用剩余空间，但不强制填满 |
| `Spacer`   | 空白 Expanded                  |

---

## 4. gap 映射

Web：

```css
.row {
  display: flex;
  gap: 12px;
}
```

Flutter 新版本部分布局支持 `spacing`，也常用 `SizedBox`：

```dart
Row(
  spacing: 12,
  children: [
    Text('A'),
    Text('B'),
  ],
)
```

或者：

```dart
Row(
  children: const [
    Text('A'),
    SizedBox(width: 12),
    Text('B'),
  ],
)
```

纵向：

```dart
Column(
  children: const [
    Text('A'),
    SizedBox(height: 12),
    Text('B'),
  ],
)
```

## 5. Grid vs GridView

Web：

```css
.grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 12px;
}
```

Flutter：

```dart
GridView.builder(
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,
    crossAxisSpacing: 12,
    mainAxisSpacing: 12,
  ),
  itemCount: products.length,
  itemBuilder: (context, index) {
    return ProductCard(product: products[index]);
  },
)
```

简单静态网格也可以：

```dart
GridView.count(
  crossAxisCount: 2,
  crossAxisSpacing: 12,
  mainAxisSpacing: 12,
  children: [
    ProductCard(),
    ProductCard(),
  ],
)
```

注意：

```text
Flutter GridView 默认是可滚动列表；
Web CSS Grid 默认只是布局上下文。
```

如果只是少量固定网格，也可以考虑 `Wrap` 或自定义布局。

---

## 6. inline / wrap 映射

Web：

```css
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}
```

Flutter：

```dart
Wrap(
  spacing: 8,
  runSpacing: 8,
  children: [
    Tag('New'),
    Tag('Hot'),
    Tag('Sale'),
  ],
)
```

`Wrap` 适合：

```text
标签
按钮组
自动换行的小元素
```

---

## 7. 常见选择

| 需求         | Flutter Widget              |
| ------------ | --------------------------- |
| 横向排列     | `Row`                       |
| 纵向排列     | `Column`                    |
| 剩余空间填充 | `Expanded`                  |
| 主轴留白     | `Spacer`                    |
| 自动换行     | `Wrap`                      |
| 层叠定位     | `Stack`                     |
| 普通长列表   | `ListView`                  |
| 网格列表     | `GridView`                  |
| 复杂滚动组合 | `CustomScrollView` + Sliver |

一句话理解：

```text
CSS 通过 display 切换布局模式；
Flutter 通过选择不同布局 Widget 表达布局意图：
Row/Column 对应 Flex，
Wrap 对应 flex-wrap，
GridView/SliverGrid 对应网格列表。
```
