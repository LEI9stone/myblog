# Web 可访问性 vs Flutter Semantics

Web 可访问性主要围绕语义化 HTML、ARIA、键盘导航、焦点管理和屏幕阅读器支持。

Flutter 中对应的是 Semantics 系统、Focus 系统、可访问性标签、触控目标和平台辅助能力。

可以这样映射：

| Web Accessibility     | Flutter                                  |
| --------------------- | ---------------------------------------- |
| semantic HTML         | `Semantics` / Material Widgets           |
| ARIA label            | `Semantics(label: ...)`                  |
| ARIA role             | `Semantics` properties                   |
| `alt`                 | `Semantics(label: ...)`                  |
| button semantics      | `Button` 类 Widget 自带语义              |
| keyboard navigation   | `Focus` / `FocusNode` / `Shortcuts`      |
| screen reader         | TalkBack / VoiceOver                     |
| tab order             | `FocusTraversalGroup`                    |
| visually hidden text  | `Semantics` label / exclude visual child |
| `aria-hidden`         | `ExcludeSemantics`                       |
| `role="presentation"` | `ExcludeSemantics` / decorative child    |
| live region           | `SemanticsService.announce`              |

---

## 1. Web 里的语义来源

Web 中推荐优先使用语义化 HTML：

```html
<button>Submit</button>
<img src="banner.png" alt="Product banner" />
<nav>...</nav>
<main>...</main>
```

需要补充语义时使用 ARIA：

```html
<button aria-label="Close dialog">×</button>
```

屏幕阅读器依赖这些语义理解页面结构。

---

## 2. Flutter 的 Semantics

Flutter 没有 HTML 标签，所以语义不是来自 DOM，而是来自 Semantics Tree。

简单例子：

```dart
Semantics(
  label: '关闭弹窗',
  button: true,
  child: IconButton(
    icon: const Icon(Icons.close),
    onPressed: onClose,
  ),
)
```

很多 Material Widget 已经自带基础语义，比如：

```text
ElevatedButton
TextButton
IconButton
Checkbox
Switch
TextField
Slider
```

但自定义组件、图片、图标按钮通常需要补充语义。

---

## 3. 图片 alt vs Semantics label

Web：

```html
<img src="/product.png" alt="红色马克杯" />
```

Flutter：

```dart
Semantics(
  label: '红色马克杯',
  image: true,
  child: Image.network(imageUrl),
)
```

如果是纯装饰图，不希望被读屏读出：

```dart
ExcludeSemantics(
  child: Image.asset('assets/images/decorative.png'),
)
```

---

## 4. aria-label vs tooltip/semanticLabel

Web：

```html
<button aria-label="搜索">
  <SearchIcon />
</button>
```

Flutter：

```dart
IconButton(
  tooltip: '搜索',
  icon: const Icon(Icons.search),
  onPressed: onSearch,
)
```

`IconButton.tooltip` 通常也会提供可访问性提示。

也可以显式：

```dart
Semantics(
  label: '搜索',
  button: true,
  child: IconButton(
    icon: const Icon(Icons.search),
    onPressed: onSearch,
  ),
)
```

---

## 5. aria-hidden vs ExcludeSemantics

Web：

```html
<span aria-hidden="true">★</span>
```

Flutter：

```dart
ExcludeSemantics(
  child: Icon(Icons.star),
)
```

如果想替换子节点语义：

```dart
Semantics(
  label: '五星评分',
  child: ExcludeSemantics(
    child: StarRating(value: 5),
  ),
)
```

---

## 6. 键盘导航与焦点

Web：

```text
Tab
Shift + Tab
Enter
Space
```

Flutter 中可用：

```dart
Focus
FocusNode
FocusTraversalGroup
Shortcuts
Actions
```

例如桌面/Web Flutter 应用中，焦点顺序和快捷键需要额外关注。

移动端主要关注：

```text
触控目标尺寸
屏幕阅读器顺序
输入框焦点
键盘弹出后的布局
```

---

## 7. 动态播报

Web 可以使用 live region：

```html
<div aria-live="polite">保存成功</div>
```

Flutter：

```dart
SemanticsService.announce(
  '保存成功',
  TextDirection.ltr,
);
```

适合：

```text
操作成功
表单错误
状态变化
异步加载完成
```

---

## 8. 实战检查清单

Flutter 中常见需要检查：

```text
图标按钮是否有 tooltip/semantic label
图片是否有语义或被排除
自定义点击区域是否暴露 button 语义
文字缩放后是否溢出
触控目标是否足够大
表单错误是否能被读到
弹窗打开后焦点是否合理
列表顺序是否符合视觉顺序
```

一句话理解：

```text
Web 可访问性依赖语义化 HTML + ARIA；
Flutter 可访问性依赖 Semantics Tree + Focus 系统。
普通 Material 控件已有基础语义，
自定义组件、图标、图片和复杂交互需要主动补充 Semantics。
```
