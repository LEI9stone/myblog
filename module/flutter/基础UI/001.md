# HTML 标签 vs Flutter Widget

Web 里用 HTML 标签描述页面结构：

```html
div span img button input ul li
```

Flutter 里用 Widget 描述界面结构：

```dart
Container
Text
Image
ElevatedButton
TextField
ListView
```

可以这样映射：

| HTML / Web   | Flutter                                        |
| ------------ | ---------------------------------------------- |
| `<div>`      | `Container` / `SizedBox` / `DecoratedBox`      |
| `<span>`     | `Text` / `RichText`                            |
| `<p>`        | `Text`                                         |
| `<img>`      | `Image` / `Image.asset` / `Image.network`      |
| `<button>`   | `ElevatedButton` / `TextButton` / `IconButton` |
| `<input>`    | `TextField` / `TextFormField`                  |
| `<textarea>` | `TextField(maxLines: ...)`                     |
| `<select>`   | `DropdownButton` / `DropdownMenu`              |
| `<form>`     | `Form`                                         |
| `<ul>/<ol>`  | `ListView` / `Column`                          |
| `<li>`       | item Widget                                    |
| `<a>`        | `InkWell` / `GestureDetector` + route/url      |
| `<header>`   | `AppBar` / custom header Widget                |
| `<main>`     | page body Widget                               |
| `<footer>`   | bottom bar / custom footer Widget              |
| `<section>`  | `Container` / custom section Widget            |
| `<nav>`      | `NavigationBar` / `BottomNavigationBar`        |
| `<dialog>`   | `Dialog` / `AlertDialog` / `showDialog`        |
| `<canvas>`   | `CustomPaint`                                  |
| `<video>`    | `VideoPlayer`                                  |

---

## 1. Flutter 没有 HTML 标签

Flutter 不使用：

```text
HTML
DOM
CSS selector
className
```

Flutter 写 UI 的方式是：

```dart
Widget build(BuildContext context) {
  return const Text('Hello');
}
```

而不是：

```html
<p>Hello</p>
```

Flutter 里的每个 UI 单元都是 Widget。

---

## 2. `<div>` 不等于永远用 `Container`

Web 开发者刚接触 Flutter 时，容易把所有 `<div>` 都映射成 `Container`。

但 Flutter 里更推荐按目的选择 Widget：

| 目的          | Flutter Widget                       |
| ------------- | ------------------------------------ |
| 只占尺寸      | `SizedBox`                           |
| 只加内边距    | `Padding`                            |
| 只居中        | `Center`                             |
| 只加背景/边框 | `DecoratedBox` / `Container`         |
| 只排列子元素  | `Row` / `Column`                     |
| 需要点击      | `GestureDetector` / `InkWell`        |
| 需要滚动      | `SingleChildScrollView` / `ListView` |

所以：

```text
Container 是组合型便利 Widget，
不是 Flutter 里的万能 div。
```

---

## 3. 文本标签映射

HTML：

```html
<h1>Title</h1>
<p>Description</p>
<span>Price</span>
```

Flutter：

```dart
Column(
  crossAxisAlignment: CrossAxisAlignment.start,
  children: const [
    Text('Title'),
    Text('Description'),
    Text('Price'),
  ],
)
```

Flutter 不靠 `h1/p/span` 语义决定样式，而是通过：

```dart
TextStyle
Theme.of(context).textTheme
```

决定视觉表现。

---

## 4. 图片标签映射

HTML：

```html
<img src="/banner.png" alt="Banner" />
```

Flutter：

```dart
Image.asset('assets/images/banner.png')
```

网络图片：

```dart
Image.network('https://example.com/banner.png')
```

实际项目里常用缓存图片：

```dart
CachedNetworkImage(imageUrl: imageUrl)
```

---

## 5. 表单标签映射

HTML：

```html
<form>
  <input />
  <textarea></textarea>
  <button>Submit</button>
</form>
```

Flutter：

```dart
Form(
  child: Column(
    children: [
      TextFormField(),
      TextFormField(maxLines: 4),
      ElevatedButton(
        onPressed: submit,
        child: const Text('Submit'),
      ),
    ],
  ),
)
```

Flutter 中输入框、按钮、校验、焦点管理都是 Widget 和 Controller 组合出来的。

---

## 6. 列表标签映射

HTML：

```html
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
```

Flutter：

```dart
ListView(
  children: const [
    Text('Item 1'),
    Text('Item 2'),
  ],
)
```

如果列表很长，通常用：

```dart
ListView.builder(
  itemCount: items.length,
  itemBuilder: (context, index) {
    return Text(items[index].title);
  },
)
```

---

## 7. 语义标签差异

HTML 有语义标签：

```html
header main section article nav footer
```

Flutter 没有这些标签的直接等价物。Flutter 更关注 UI 组合和平台语义。

如果需要可访问性语义，可以使用：

```dart
Semantics(
  label: 'Product card',
  child: ProductCard(product: product),
)
```

---

一句话理解：

```text
HTML 标签是浏览器 DOM 结构；
Flutter Widget 是 Dart 对 UI 的声明式配置。
不要机械地把标签逐个翻译成 Widget，
而要按布局、样式、交互、语义目的选择合适的 Widget。
```
