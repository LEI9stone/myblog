# CSS Position vs Stack/Positioned/Align

Web 里用 `position` 控制元素相对谁定位：

```css
position: relative;
position: absolute;
position: fixed;
position: sticky;
```

Flutter 没有 CSS `position` 属性，常用：

```dart
Stack
Positioned
Align
Center
Overlay
SliverPersistentHeader
```

可以这样映射：

| CSS / Web                   | Flutter                             |
| --------------------------- | ----------------------------------- |
| `position: relative`        | 普通父 Widget / `Stack` 参照容器    |
| `position: absolute`        | `Stack` + `Positioned`              |
| `top/right/bottom/left`     | `Positioned(top/right/bottom/left)` |
| `z-index`                   | `Stack.children` 顺序               |
| `position: fixed`           | `Overlay` / `Scaffold` 固定区域     |
| `position: sticky`          | `SliverPersistentHeader`            |
| `transform: translate` 居中 | `Align` / `Center`                  |
| `inset: 0`                  | `Positioned.fill`                   |

---

## 1. absolute vs Stack + Positioned

Web：

```css
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

Flutter：

```dart
Stack(
  children: [
    ProductImage(),
    Positioned(
      top: 8,
      right: 8,
      child: Badge(),
    ),
  ],
)
```

可以理解为：

```text
Stack 提供定位上下文；
Positioned 指定子元素在 Stack 里的位置。
```

---

## 2. relative 的心智差异

Web 里常写：

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

Flutter 中不需要给父级写 `position: relative`，只要父级是 `Stack`：

```dart
Stack(
  children: [
    CardContent(),
    Positioned(
      top: 8,
      right: 8,
      child: Badge(),
    ),
  ],
)
```

所以对应关系是：

```text
CSS relative 父容器 + absolute 子元素
≈ Flutter Stack + Positioned 子元素
```

---

## 3. z-index vs children 顺序

Web：

```css
.modal {
  z-index: 1000;
}
```

Flutter 的 `Stack` 里，后面的 child 画在前面：

```dart
Stack(
  children: [
    Background(), // 在下面
    Content(),    // 在中间
    Badge(),      // 在上面
  ],
)
```

也就是说：

```text
Stack.children 越靠后，视觉层级越高。
```

Flutter 没有直接的 `z-index` 属性。

---

## 4. Positioned.fill vs inset: 0

Web：

```css
.overlay {
  position: absolute;
  inset: 0;
}
```

Flutter：

```dart
Positioned.fill(
  child: OverlayContent(),
)
```

常用于：

```text
遮罩层
图片上的渐变层
整块点击区域
全覆盖 loading
```

---

## 5. Align vs absolute 居中

Web 常见居中：

```css
.child {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```

Flutter 通常不用这种方式，而是：

```dart
Stack(
  children: [
    Background(),
    Align(
      alignment: Alignment.center,
      child: PlayButton(),
    ),
  ],
)
```

或：

```dart
Center(
  child: PlayButton(),
)
```

常见对齐：

```dart
Align(
  alignment: Alignment.topRight,
  child: Badge(),
)
```

---

## 6. fixed 定位映射

Web：

```css
.tabbar {
  position: fixed;
  bottom: 0;
}
```

Flutter 中底部固定区域通常不是用 `Stack`，而是用 `Scaffold`：

```dart
Scaffold(
  body: PageContent(),
  bottomNavigationBar: BottomNavigationBar(
    items: [],
  ),
)
```

顶部固定：

```dart
Scaffold(
  appBar: AppBar(title: const Text('Home')),
  body: PageContent(),
)
```

如果是浮层：

```dart
Overlay
showDialog
showModalBottomSheet
```

---

## 7. sticky 定位映射

Web：

```css
.header {
  position: sticky;
  top: 0;
}
```

Flutter 中常用 Sliver：

```dart
CustomScrollView(
  slivers: [
    SliverPersistentHeader(
      pinned: true,
      delegate: HeaderDelegate(),
    ),
    SliverList(...),
  ],
)
```

也可以用：

```dart
SliverAppBar(
  pinned: true,
)
```

---

一句话理解：

```text
CSS position 通过 relative/absolute/fixed/sticky 控制定位上下文；
Flutter 通过 Stack + Positioned 做局部绝对定位，
通过 Align/Center 做对齐，
通过 Scaffold/Overlay/Sliver 处理固定、浮层和吸顶场景。
```
