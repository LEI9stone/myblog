# CSS Units vs Flutter Logical Pixels

Web 里有很多 CSS 单位：

```css
px
%
rem
em
vw
vh
fr
```

Flutter 里最常用的是 logical pixels，也就是逻辑像素。

Flutter 不直接使用 CSS 的 `rem`、`em`、`vw`、`vh`、`fr`，但可以通过约束、比例、屏幕信息和布局 Widget 表达类似效果。

| CSS / Web                     | Flutter                                               |
| ----------------------------- | ----------------------------------------------------- |
| `px`                          | logical pixel                                         |
| physical pixel                | device pixel                                          |
| `rem`                         | Theme text scale / design token / ScreenUtil          |
| `em`                          | 基于 TextStyle 的相对设计，较少直接对应               |
| `%`                           | `FractionallySizedBox` / `Expanded` / `LayoutBuilder` |
| `vw` / `vh`                   | `MediaQuery.sizeOf(context)`                          |
| `fr`                          | `Expanded(flex: ...)`                                 |
| `min()` / `max()` / `clamp()` | `BoxConstraints` / `clamp()` / `LayoutBuilder`        |
| `calc()`                      | Dart 表达式 / LayoutBuilder                           |
| `auto`                        | child 自然尺寸 / 约束协商                             |

---

## 1. Flutter 的数字不是物理像素

Flutter：

```dart
SizedBox(width: 100, height: 50)
```

这里的 `100` 和 `50` 不是设备物理像素，而是 logical pixels。

可以理解为类似 CSS px：

```text
Flutter logical pixel ≈ CSS px 的心智
```

它会根据设备像素密度映射到实际物理像素。

例如高密度屏幕上：

```text
100 logical px 可能对应 200 或 300 physical px
```

---

## 2. px vs logical pixel

Web：

```css
.card {
  width: 100px;
}
```

Flutter：

```dart
SizedBox(
  width: 100,
  child: child,
)
```

大多数 UI 尺寸迁移时，可以先按：

```text
CSS px → Flutter logical pixel
```

理解。

---

## 3. % 百分比

Web：

```css
.card {
  width: 50%;
}
```

Flutter 可以用：

```dart
FractionallySizedBox(
  widthFactor: 0.5,
  child: child,
)
```

也可以在布局中用：

```dart
Expanded(
  flex: 1,
  child: child,
)
```

或通过 `LayoutBuilder`：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    return SizedBox(
      width: constraints.maxWidth * 0.5,
      child: child,
    );
  },
)
```

---

## 4. vw / vh

Web：

```css
.hero {
  height: 100vh;
}
```

Flutter：

```dart
final size = MediaQuery.sizeOf(context);

SizedBox(
  height: size.height,
  child: child,
)
```

或者：

```dart
SizedBox(
  height: MediaQuery.sizeOf(context).height * 0.5,
  child: child,
)
```

注意：

```text
移动端还要考虑 SafeArea、键盘、状态栏、导航栏。
```

所以实际页面中经常结合：

```dart
SafeArea
MediaQuery
Scaffold
```

---

## 5. rem / em

Web：

```css
html {
  font-size: 16px;
}

.title {
  font-size: 1.25rem;
}
```

Flutter 没有内置 `rem` 体系。常见做法是：

```text
使用 ThemeData.textTheme
使用 AppTextStyles
使用设计 token
使用 flutter_screenutil 等适配工具
```

例如：

```dart
Text(
  'Title',
  style: Theme.of(context).textTheme.titleLarge,
)
```

或：

```dart
Text(
  'Title',
  style: AppTextStyles.titleLarge,
)
```

---

## 6. fr vs flex

CSS Grid：

```css
grid-template-columns: 1fr 2fr;
```

Flutter：

```dart
Row(
  children: [
    Expanded(
      flex: 1,
      child: Left(),
    ),
    Expanded(
      flex: 2,
      child: Right(),
    ),
  ],
)
```

`flex` 可以理解为类似 `fr` 的比例分配。

---

## 7. clamp / calc

Web：

```css
width: calc(100vw - 32px);
font-size: clamp(14px, 2vw, 20px);
```

Flutter：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    final width = constraints.maxWidth - 32;
    final fontSize = (constraints.maxWidth * 0.02).clamp(14.0, 20.0);

    return SizedBox(
      width: width,
      child: Text(
        'Title',
        style: TextStyle(fontSize: fontSize),
      ),
    );
  },
)
```

不过 Flutter 里不建议随 viewport 频繁缩放字体，通常更推荐稳定的 text theme 和响应式布局。

---

## 8. 实战迁移建议

Web 设计稿迁 Flutter 时，可以先这样处理：

| Web 单位  | Flutter 处理                                          |
| --------- | ----------------------------------------------------- |
| `px`      | 直接用 logical pixel                                  |
| `%`       | `Expanded` / `FractionallySizedBox` / `LayoutBuilder` |
| `vw/vh`   | `MediaQuery`                                          |
| `rem/em`  | `ThemeData.textTheme` / AppTextStyles                 |
| `fr`      | `Expanded(flex)`                                      |
| `auto`    | 让 child 自然布局                                     |
| `min/max` | `ConstrainedBox` / `BoxConstraints`                   |

一句话理解：

```text
CSS 有多种布局单位；
Flutter 主要用 logical pixels + constraints + flex + MediaQuery 表达尺寸。
Web 的 px 可以近似理解为 Flutter logical pixel，
但百分比、视口单位和 rem/em 需要换成 Flutter 的布局模型来表达。
```
