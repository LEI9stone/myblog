# DOM Tree vs Widget Tree

Web 中的页面结构是 DOM Tree。

Flutter 中的界面结构是 Widget Tree。

它们都可以理解成“UI 的树状结构”，但生命周期、可变性和渲染方式差异很大。

| Web                | Flutter                                 |
| ------------------ | --------------------------------------- |
| DOM Tree           | Widget Tree                             |
| DOM Node           | Widget                                  |
| HTML/JSX 生成 DOM  | Dart 构建 Widget                        |
| DOM 节点相对持久   | Widget 轻量、不可变、可频繁重建         |
| 修改 DOM 更新 UI   | 重建 Widget 更新 UI                     |
| CSS 选择器命中 DOM | Widget 参数/Theme 传递样式              |
| Browser 渲染 DOM   | Flutter 渲染 Widget 对应的 RenderObject |
| DOM API            | 无 DOM API                              |
| Virtual DOM diff   | Widget diff / Element reconciliation    |

---

## 1. DOM Tree

Web 中：

```html
<div class="card">
  <h2>Product</h2>
  <p>Price</p>
</div>
```

会形成类似：

```text
div
  h2
  p
```

React/Vue/Svelte 最终也会把 UI 更新到 DOM 上。

例如 React：

```tsx
function ProductCard() {
  return (
    <div className="card">
      <h2>Product</h2>
      <p>Price</p>
    </div>
  );
}
```

最终仍然对应浏览器 DOM。

---

## 2. Widget Tree

Flutter 中：

```dart
Column(
  children: const [
    Text('Product'),
    Text('Price'),
  ],
)
```

会形成 Widget Tree：

```text
Column
  Text
  Text
```

Widget Tree 是你声明 UI 的方式。

```text
Widget 描述“界面应该是什么样”。
```

---

## 3. 最大区别：DOM 可变，Widget 不可变

Web 中可以直接修改 DOM：

```ts
element.textContent = 'New Product';
element.classList.add('active');
```

Flutter 中不会修改某个 Widget 实例。

Flutter 的 Widget 是不可变配置：

```dart
const Text('Product')
```

状态变化时，会重新执行：

```dart
build()
```

生成新的 Widget Tree，然后 Flutter 通过 Element Tree 复用已有实例关系并更新 RenderObject。

所以心智模型是：

```text
Web：修改 DOM
Flutter：状态变化 → rebuild → 新 Widget Tree
```

---

## 4. React 类比

React 开发者可以这样理解：

| React                       | Flutter                      |
| --------------------------- | ---------------------------- |
| JSX 返回 React Element Tree | build 返回 Widget Tree       |
| React Element 轻量不可变    | Widget 轻量不可变            |
| Fiber 维护组件实例          | Element 维护 Widget 实例位置 |
| ReactDOM 更新 DOM           | Flutter 更新 RenderObject    |
| CSS 负责样式                | Widget 参数/Theme 负责样式   |

但关键差异是：

```text
React 最终还是更新浏览器 DOM；
Flutter 没有 DOM，最终更新自己的 RenderObject Tree。
```

---

## 5. Widget Tree 不等于真正渲染树

Flutter 实际有三棵重要树：

```text
Widget Tree      描述 UI 配置
Element Tree     维护 Widget 实例位置和状态
RenderObject Tree 负责布局、绘制和命中测试
```

Widget Tree 是最常接触的开发层。

但真正负责布局和绘制的是：

```text
RenderObject Tree
```

这点类似 Web 中：

```text
DOM + CSSOM → Render Tree → Layout/Paint
```

---

## 6. 样式系统差异

Web：

```html
<div class="card"></div>
```

```css
.card {
  padding: 16px;
  border-radius: 8px;
}
```

CSS 通过 selector 作用到 DOM 节点。

Flutter：

```dart
Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circular(8),
  ),
  child: const Text('Product'),
)
```

Flutter 没有 CSS selector。样式通常由：

```text
Widget 参数
Theme
InheritedWidget
自定义组件封装
```

传递。

---

一句话理解：

```text
DOM Tree 是浏览器页面的可变节点树；
Widget Tree 是 Flutter 用 Dart 声明出来的轻量不可变 UI 配置树。
Web 常见操作是更新 DOM；
Flutter 常见操作是状态变化后重建 Widget Tree。
```
