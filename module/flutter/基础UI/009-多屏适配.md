# Responsive Web vs Flutter 多屏适配

Responsive Web 主要解决：

```text
同一个网页在不同浏览器视口下如何布局。
```

Flutter 多屏适配解决的是：

```text
同一个 App 在不同设备、屏幕尺寸、方向、像素密度、安全区域下如何布局。
```

可以这样映射：

| Responsive Web   | Flutter 多屏适配                       |
| ---------------- | -------------------------------------- |
| viewport         | screen size / window size              |
| CSS media query  | `MediaQuery`                           |
| container query  | `LayoutBuilder`                        |
| fluid layout     | constraints-based layout               |
| breakpoint       | app breakpoints                        |
| rem/em           | text theme / design token              |
| vw/vh            | `MediaQuery.sizeOf(context)`           |
| flex/grid        | `Row` / `Column` / `Wrap` / `GridView` |
| safe-area env    | `SafeArea` / `MediaQuery.paddingOf`    |
| responsive image | `BoxFit` / adaptive assets             |
| mobile-first     | compact-first / adaptive layout        |

---

## 1. Web 响应式的核心

Web 常见思路：

```css
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
}

@media (max-width: 768px) {
  .container {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 480px) {
  .container {
    grid-template-columns: 1fr;
  }
}
```

核心是：

```text
根据 viewport 宽度切换 CSS 规则。
```

---

## 2. Flutter 多屏适配的核心

Flutter 更常见的是：

```text
根据约束选择不同 Widget 结构。
```

例如：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth < 600) {
      return const CompactProductGrid();
    }

    if (constraints.maxWidth < 840) {
      return const MediumProductGrid();
    }

    return const ExpandedProductGrid();
  },
)
```

不是切换 CSS，而是切换布局 Widget。

---

## 3. 页面级 vs 组件级适配

页面级适配：

```dart
final width = MediaQuery.sizeOf(context).width;

return width < 600
    ? const MobileHomePage()
    : const TabletHomePage();
```

组件级适配：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    return constraints.maxWidth < 320
        ? const CompactProductCard()
        : const ProductCard();
  },
)
```

选择原则：

| 适配目标                   | 推荐                      |
| -------------------------- | ------------------------- |
| 整页结构变化               | `MediaQuery`              |
| 某个组件在不同容器里自适应 | `LayoutBuilder`           |
| 横竖屏切换                 | `OrientationBuilder`      |
| 安全区域                   | `SafeArea`                |
| 键盘遮挡                   | `MediaQuery.viewInsetsOf` |

---

## 4. Breakpoint 映射

Web：

```text
mobile: < 640
tablet: 640 - 1024
desktop: > 1024
```

Flutter 可以定义：

```dart
class AppBreakpoints {
  static const compact = 600.0;
  static const medium = 840.0;
  static const expanded = 1200.0;
}
```

常见 Material 适配心智：

```text
compact
medium
expanded
```

对应：

```text
手机
折叠屏/小平板
平板/桌面
```

---

## 5. 不要只按屏幕等比缩放

Web 开发者容易把多屏适配理解为：

```text
屏幕越大，所有尺寸同比例放大。
```

Flutter 中更推荐：

```text
布局结构响应式；
字体和控件尺寸保持稳定；
必要时增加列数、边距、内容密度。
```

例如商品列表：

| 屏幕   | 更合理的变化        |
| ------ | ------------------- |
| 手机   | 2 列商品            |
| 小平板 | 3 列商品            |
| 平板   | 4 列商品            |
| 桌面   | 更宽内容区 + 更多列 |

而不是：

```text
把手机上的 2 列卡片单纯放大。
```

---

## 6. SafeArea 与系统区域

Web 中处理刘海屏可能用：

```css
env(safe-area-inset-bottom)
```

Flutter：

```dart
SafeArea(
  child: PageContent(),
)
```

底部固定按钮：

```dart
Padding(
  padding: EdgeInsets.only(
    bottom: MediaQuery.paddingOf(context).bottom,
  ),
  child: ButtonBar(),
)
```

---

## 7. 图片和媒体适配

Web：

```css
img {
  width: 100%;
  object-fit: cover;
}
```

Flutter：

```dart
Image.network(
  imageUrl,
  width: double.infinity,
  fit: BoxFit.cover,
)
```

常见映射：

| Web                   | Flutter                       |
| --------------------- | ----------------------------- |
| `object-fit: cover`   | `BoxFit.cover`                |
| `object-fit: contain` | `BoxFit.contain`              |
| `aspect-ratio`        | `AspectRatio`                 |
| responsive image      | 根据尺寸选择 asset / CDN 参数 |

---

一句话理解：

```text
Responsive Web 主要通过 CSS media query 改样式；
Flutter 多屏适配主要通过 MediaQuery/LayoutBuilder 读尺寸，
再选择合适的 Widget 结构和约束。
核心不是等比缩放，而是按设备宽度调整布局密度和信息结构。
```
