# Media Query vs Flutter `MediaQuery` / `LayoutBuilder`

Web 里用 CSS Media Query 根据屏幕、视口、设备特征切换样式：

```css
@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
```

Flutter 里常用：

```dart
MediaQuery
LayoutBuilder
OrientationBuilder
```

它们分别解决不同层级的响应式问题。

| Web                   | Flutter                                                    |
| --------------------- | ---------------------------------------------------------- |
| CSS Media Query       | `MediaQuery`                                               |
| Container Query       | `LayoutBuilder`                                            |
| viewport width/height | `MediaQuery.sizeOf(context)`                               |
| breakpoint            | 自定义断点判断                                             |
| orientation           | `MediaQuery.orientationOf(context)` / `OrientationBuilder` |
| prefers-color-scheme  | `MediaQuery.platformBrightnessOf(context)` / Theme         |
| safe area inset       | `MediaQuery.paddingOf(context)` / `SafeArea`               |
| devicePixelRatio      | `MediaQuery.devicePixelRatioOf(context)`                   |

---

## 1. `MediaQuery`：看整个屏幕环境

Flutter：

```dart
final size = MediaQuery.sizeOf(context);
final width = size.width;
final height = size.height;
```

可以类比 Web 的：

```ts
window.innerWidth;
window.innerHeight;
```

或 CSS：

```css
@media (max-width: 768px) {
}
```

示例：

```dart
final width = MediaQuery.sizeOf(context).width;
final isMobile = width < 600;

return isMobile ? MobileLayout() : DesktopLayout();
```

适合判断：

```text
屏幕宽高
横竖屏
系统字体缩放
安全区域
深色模式
设备像素比
```

---

## 2. `LayoutBuilder`：看父容器给了多大空间

Web 里的 Media Query 看 viewport，Container Query 看容器。

Flutter 的 `LayoutBuilder` 更接近 Container Query：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    final maxWidth = constraints.maxWidth;

    if (maxWidth < 360) {
      return CompactCard();
    }

    return RegularCard();
  },
)
```

它判断的不是屏幕宽度，而是：

```text
当前 Widget 从父级拿到的布局约束。
```

所以它更适合组件内部响应式。

---

## 3. MediaQuery vs LayoutBuilder 怎么选

| 场景                         | 推荐                                |
| ---------------------------- | ----------------------------------- |
| 整个页面按屏幕切换布局       | `MediaQuery`                        |
| 组件根据自身可用宽度变化     | `LayoutBuilder`                     |
| 判断横竖屏                   | `OrientationBuilder` / `MediaQuery` |
| 处理刘海屏/状态栏/底部安全区 | `SafeArea` / `MediaQuery.paddingOf` |
| 处理键盘弹起                 | `MediaQuery.viewInsetsOf`           |
| 组件复用在不同容器里         | `LayoutBuilder`                     |

简单判断：

```text
看屏幕：MediaQuery
看父容器：LayoutBuilder
看横竖屏：OrientationBuilder
```

## 4. 断点写法

Web：

```css
@media (max-width: 600px) {
  .product-card {
    flex-direction: column;
  }
}
```

Flutter：

```dart
class AppBreakpoints {
  static const compact = 600.0;
  static const medium = 840.0;
}
```

使用：

```dart
final width = MediaQuery.sizeOf(context).width;

if (width < AppBreakpoints.compact) {
  return const CompactLayout();
}

if (width < AppBreakpoints.medium) {
  return const MediumLayout();
}

return const ExpandedLayout();
```

组件内部：

```dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth < 280) {
      return const CompactProductCard();
    }

    return const ProductCard();
  },
)
```

## 5. Safe Area

Web 里可能处理：

```css
env(safe-area-inset-top)
env(safe-area-inset-bottom)
```

Flutter：

```dart
SafeArea(
  child: PageContent(),
)
```

或读取：

```dart
final padding = MediaQuery.paddingOf(context);
```

常见：

```dart
padding.top
padding.bottom
```

---

## 6. 键盘与可视区域

移动端 Web 中常遇到虚拟键盘影响 viewport。

Flutter 中通常读取：

```dart
final bottomInset = MediaQuery.viewInsetsOf(context).bottom;
```

键盘弹出时，`bottomInset` 会变大。

`Scaffold` 默认也会根据键盘调整 body：

```dart
Scaffold(
  resizeToAvoidBottomInset: true,
  body: FormPage(),
)
```

---

一句话理解：

```text
Web 的 Media Query 主要根据 viewport 和设备特征切换 CSS；
Flutter 的 MediaQuery 读取整个屏幕环境，
LayoutBuilder 读取当前组件的可用约束。
页面级响应式看 MediaQuery，
组件级响应式看 LayoutBuilder。
```
