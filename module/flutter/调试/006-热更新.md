# Hot Reload vs Vite HMR

Vite HMR 和 Flutter Hot Reload 都是“改代码后快速看到结果”的开发体验。

但它们工作的层级不同：Vite HMR 更新浏览器里的 JavaScript 模块；Flutter Hot Reload 把新的 Dart 代码注入正在运行的 Dart VM，并触发 Widget rebuild。

可以这样映射：

| Vite HMR               | Flutter Hot Reload                   |
| ---------------------- | ------------------------------------ |
| Hot Module Replacement | Hot Reload                           |
| 更新 JS 模块           | 注入更新后的 Dart 代码               |
| 保留前端状态           | 尽量保留 App 状态                    |
| React Fast Refresh     | Flutter rebuild Widget tree          |
| CSS HMR                | Widget/style 参数热更新              |
| dev server             | `flutter run`                        |
| full reload            | Hot Restart                          |
| browser refresh        | App restart / hot restart            |
| module boundary        | Dart VM / Flutter framework boundary |

---

## 1. Vite HMR

Web：

```text
改 React/Vue/Svelte 文件
Vite 推送更新模块
浏览器替换模块
尽量保留组件状态
```

React 中还会通过 Fast Refresh 尽量保留 hooks state。

CSS 改动通常更快：

```text
直接替换 style
不刷新页面
```

---

## 2. Flutter Hot Reload

Flutter：

```text
改 Dart 代码
保存
Hot Reload
Dart VM 注入新代码
Flutter 重新 build
尽量保留当前 App 状态
```

常用命令：

```bash
flutter run
```

运行中按：

```text
r = hot reload
R = hot restart
```

IDE 通常会保存后自动 hot reload。

---

## 3. 状态保留

Vite HMR：

```text
尽量保留 JS/组件状态
```

Flutter Hot Reload：

```text
保留当前 State 对象
保留当前路由栈
保留输入框、滚动等运行时状态
```

例如你在详情页，Hot Reload 后通常还在详情页。

---

## 4. Hot Reload 不是什么都能更新

Flutter Hot Reload 适合：

```text
改 build 方法
改 Widget 参数
改样式
改布局
改普通方法逻辑
新增 Widget
```

但有些改动可能需要 Hot Restart：

```text
修改 main 初始化逻辑
修改全局变量初始化
修改 initState 中只执行一次的逻辑
修改 enum/class 泛型结构导致状态不兼容
插件/原生代码变更
资源/pubspec 变更
```

---

## 5. Hot Restart

Flutter Hot Restart 会：

```text
重启 Dart isolate
重新执行 main()
清空当前运行时状态
重新启动 App
```

类似 Web 的：

```text
刷新页面 / full reload
```

但不等同于重新安装 App。

---

## 6. Vite Dev Server vs flutter run

Web：

```bash
npm run dev
```

Vite 启动 dev server，浏览器访问本地地址。

Flutter：

```bash
flutter run
```

连接模拟器/真机/桌面/Web，把 App 跑起来，然后支持 Hot Reload。

---

## 7. 常见心智差异

Web：

```text
浏览器是运行容器；
HMR 更新浏览器中的模块。
```

Flutter：

```text
App 是运行容器；
Hot Reload 更新运行中的 Dart VM 代码。
```

所以 Flutter 中某些启动期、平台层、资源层变化，不一定能 Hot Reload 生效。

---

一句话理解：

```text
Vite HMR 是浏览器开发环境中的模块热替换；
Flutter Hot Reload 是把新的 Dart 代码注入运行中的 App。
两者都尽量保留状态，
但涉及 main/initState/原生插件/pubspec/assets 的改动通常需要 Hot Restart 或重新运行。
```
