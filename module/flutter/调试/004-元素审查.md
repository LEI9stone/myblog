# Elements Panel vs Widget Inspector

Web 里的 Elements Panel 用来查看和调试 DOM、CSS、盒模型、Flex/Grid 布局。

Flutter 中对应的是 Flutter DevTools 的 Widget Inspector，用来查看 Widget Tree、布局属性、约束、RenderObject 和源码位置。

可以这样映射：

| Browser Elements Panel | Flutter Widget Inspector          |
| ---------------------- | --------------------------------- |
| DOM Tree               | Widget Tree / Element Tree        |
| HTML element           | Widget                            |
| CSS styles             | Widget properties / Theme         |
| computed style         | resolved properties / layout info |
| box model              | constraints / size / padding      |
| flex overlay           | Layout Explorer                   |
| inspect element        | Select Widget Mode                |
| edit CSS live          | hot reload / 修改 Widget 参数     |
| DOM attributes         | Widget constructor params         |
| event listeners        | gesture/callback widgets          |
| accessibility tree     | Semantics debugger                |

---

## 1. Web Elements Panel

Web 中可以看：

```text
HTML DOM 结构
CSS 规则
computed styles
盒模型
布局 overlay
事件监听
无障碍属性
```

还可以临时改 CSS：

```text
调颜色
改 margin
开关 class
验证布局
```

---

## 2. Flutter Widget Inspector

Flutter Inspector 可以看：

```text
Widget Tree
选中屏幕上的 Widget
Widget 属性
RenderObject 信息
尺寸和约束
源码位置
布局边界
rebuild 情况
```

它帮助你理解：

```text
这个 UI 是哪个 Widget 画出来的
它的父子结构是什么
它拿到了什么尺寸
为什么 Row/Column 溢出
```

---

## 3. DOM Tree vs Widget Tree

Web：

```html
<div class="card">
  <h3>Title</h3>
</div>
```

Elements Panel 看到 DOM。

Flutter：

```dart
Container(
  child: Text('Title'),
)
```

Inspector 看到 Widget Tree：

```text
Container
  Text
```

但 Flutter 还涉及：

```text
Widget
Element
RenderObject
```

Inspector 可以辅助查看不同层级的信息。

---

## 4. CSS 样式 vs Widget 属性

Web：

```css
.card {
  padding: 16px;
  border-radius: 8px;
}
```

Elements Panel 显示 CSS rules 和 computed style。

Flutter：

```dart
Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circular(8),
  ),
)
```

Inspector 显示的是：

```text
padding
decoration
constraints
alignment
```

Flutter 没有 CSS cascade，所以重点不是“哪个 selector 生效”，而是“哪个 Widget 参数生效”。

---

## 5. Box Model vs Constraints

Web Elements Panel 有盒模型：

```text
margin
border
padding
content
```

Flutter Inspector/布局调试更关注：

```text
constraints
size
parent data
RenderFlex
padding widget
sized box
alignment
```

Flutter 布局核心是：

```text
Constraints go down, sizes go up, parent sets position.
```

---

## 6. Select Widget Mode

类似 Web 的 inspect element。

Flutter DevTools 中可以启用 Select Widget Mode，然后点击 App 界面上的某个区域，Inspector 会定位对应 Widget。

适合排查：

```text
这个间距是谁加的
这个文字来自哪个 Widget
这个按钮为什么不可点
这个图片为什么尺寸不对
```

---

## 7. Layout Explorer

Web 有 Flex/Grid overlay。

Flutter 有 Layout Explorer，尤其适合看：

```text
Row
Column
Flex
Expanded
Flexible
alignment
overflow
```

当遇到：

```text
A RenderFlex overflowed by xx pixels
```

Widget Inspector 和 Layout Explorer 通常比肉眼猜更有效。

---

一句话理解：

```text
Browser Elements Panel 调试 DOM、CSS 和盒模型；
Flutter Widget Inspector 调试 Widget Tree、Widget 参数、布局约束和 RenderObject。
Web 查 selector 和 computed style，
Flutter 查 Widget 组合、constraints、size 和 parent-child 关系。
```
