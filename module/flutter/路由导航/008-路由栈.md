# Browser History vs Navigator Stack

Web 里的页面导航由 Browser History 记录。

Flutter 里的页面导航由 Navigator Stack 管理。

两者都可以表达“前进、返回、替换当前位置”，但 Web 以 URL history 为核心，Flutter 以 route stack 为核心。

可以这样映射：

| Browser History        | Flutter Navigator Stack                         |
| ---------------------- | ----------------------------------------------- |
| history stack          | navigator route stack                           |
| `history.pushState`    | `Navigator.push` / `context.push`               |
| `history.replaceState` | `Navigator.pushReplacement` / `context.replace` |
| browser back           | `Navigator.pop` / system back                   |
| URL entry              | Route                                           |
| current location       | top route                                       |
| back button            | AppBar back / Android back gesture              |
| forward button         | 无完全等价，通常重新 push                       |
| history length         | navigator stack depth                           |
| nested history         | nested Navigator                                |

---

## 1. Browser History

Web 中访问：

```text
/
→ /products
→ /products/123
```

浏览器 history 里大致是：

```text
[
  '/',
  '/products',
  '/products/123'
]
```

点击返回：

```text
/products/123 → /products
```

再次返回：

```text
/products → /
```

---

## 2. Navigator Stack

Flutter 中：

```dart
Navigator.of(context).push(
  MaterialPageRoute(builder: (_) => const ProductListPage()),
);

Navigator.of(context).push(
  MaterialPageRoute(builder: (_) => const ProductDetailPage()),
);
```

Navigator stack 类似：

```text
HomePage
ProductListPage
ProductDetailPage
```

`pop()` 后：

```text
HomePage
ProductListPage
```

顶部 route 被移除，回到上一页。

---

## 3. push

Web：

```ts
history.pushState(null, '', '/products/123');
```

go_router：

```dart
context.push('/products/123');
```

Navigator：

```dart
Navigator.of(context).push(
  MaterialPageRoute(
    builder: (context) => const ProductDetailPage(),
  ),
);
```

含义：

```text
压入新历史记录/新 route，可返回。
```

---

## 4. replace

Web：

```ts
history.replaceState(null, '', '/login');
```

go_router：

```dart
context.replace('/login');
```

Navigator：

```dart
Navigator.of(context).pushReplacement(
  MaterialPageRoute(
    builder: (context) => const LoginPage(),
  ),
);
```

含义：

```text
替换当前页面，不保留当前页面作为返回目标。
```

适合：

```text
登录成功后进入首页
启动页跳主页面
表单提交成功后跳结果页
```

---

## 5. pop / back

Web：

```ts
history.back();
```

Flutter：

```dart
Navigator.of(context).pop();
```

go_router：

```dart
context.pop();
```

AppBar 自动返回按钮通常也是 pop。

Android 系统返回键也会尝试 pop 当前 route。

---

## 6. go vs push 的栈差异

go_router：

```dart
context.push('/detail');
```

通常会增加 stack。

```dart
context.go('/home');
```

更像切换当前位置或路由分支，常用于：

```text
底部 Tab
主页面切换
登录态重定向
```

不要把所有跳转都写成 `go`，否则可能丢失期望的返回栈。

---

## 7. Nested Navigator

Web 里某些布局可能有嵌套 history。

Flutter 里可以有 nested Navigator，比如每个底部 Tab 保留自己的栈：

```text
Home tab stack:
  HomePage → ProductDetail

Order tab stack:
  OrderPage → OrderDetail
```

go_router 中通常用：

```text
StatefulShellRoute
```

来管理多分支 Navigator stack。

---

## 8. 关键差异

Web：

```text
URL 是 history entry；
刷新后可以从 URL 还原页面；
浏览器有 back/forward。
```

Flutter mobile：

```text
Route 是 stack entry；
App 返回栈存在内存中；
外部 deep link 需要显式解析；
通常没有浏览器 forward 按钮。
```

Flutter Web：

```text
Navigator stack 可以和 Browser History 同步。
```

一句话理解：

```text
Browser History 是 Web 的 URL 历史栈；
Navigator Stack 是 Flutter 的页面 Route 栈。
push 增加一层，
replace 替换当前层，
pop 返回上一层。
移动端更关注 Navigator stack，
Web 更关注 URL history。
```
