# Path Params vs Route Path Parameters

Web 里的 Path Params 是 URL 路径中的动态片段：

```text
/products/:id
```

例如：

```text
/products/123
```

其中 `123` 就是 `id`。

Flutter 中如果使用 `go_router`，对应的是：

```dart
state.pathParameters
```

可以这样映射：

| Web Path Params       | Flutter / go_router          |
| --------------------- | ---------------------------- |
| `/products/:id`       | `path: '/products/:id'`      |
| `useParams()`         | `state.pathParameters`       |
| `params.id`           | `state.pathParameters['id']` |
| dynamic route segment | `:paramName`                 |
| nested path param     | nested `GoRoute` path        |
| optional segment      | 通常拆 route 或用 query      |
| type parsing          | 手动 parse                   |
| route matching        | go_router route matching     |

---

## 1. Web Path Params

React Router：

```tsx
<Route path="/products/:id" element={<ProductDetailPage />} />
```

读取：

```tsx
const { id } = useParams();
```

访问：

```text
/products/123
```

得到：

```text
id = "123"
```

---

## 2. go_router Path Parameters

Flutter：

```dart
GoRoute(
  path: '/products/:id',
  builder: (context, state) {
    final id = state.pathParameters['id']!;

    return ProductDetailPage(productId: id);
  },
)
```

跳转：

```dart
context.push('/products/123');
```

读取：

```dart
final id = state.pathParameters['id'];
```

类型是：

```dart
String?
```

所以如果确定必有，可以：

```dart
final id = state.pathParameters['id']!;
```

---

## 3. 多个 Path Params

Web：

```text
/shops/:shopId/products/:productId
```

Flutter：

```dart
GoRoute(
  path: '/shops/:shopId/products/:productId',
  builder: (context, state) {
    final shopId = state.pathParameters['shopId']!;
    final productId = state.pathParameters['productId']!;

    return ProductDetailPage(
      shopId: shopId,
      productId: productId,
    );
  },
)
```

访问：

```text
/shops/10/products/123
```

---

## 4. Nested Route 中的参数

```dart
GoRoute(
  path: '/shops/:shopId',
  builder: (context, state) {
    final shopId = state.pathParameters['shopId']!;
    return ShopPage(shopId: shopId);
  },
  routes: [
    GoRoute(
      path: 'products/:productId',
      builder: (context, state) {
        final shopId = state.pathParameters['shopId']!;
        final productId = state.pathParameters['productId']!;

        return ProductDetailPage(
          shopId: shopId,
          productId: productId,
        );
      },
    ),
  ],
)
```

子 route 可以读取父 route 中的 path parameter。

---

## 5. 参数类型解析

Path params 也是字符串。

如果需要 int：

```dart
final idText = state.pathParameters['id']!;
final id = int.parse(idText);
```

更安全：

```dart
final id = int.tryParse(state.pathParameters['id'] ?? '');

if (id == null) {
  return const InvalidRoutePage();
}
```

如果是 enum：

```dart
final tab = ProductTab.values.byName(
  state.pathParameters['tab']!,
);
```

实际项目建议封装解析，避免页面里到处 `int.tryParse`。

---

## 6. Path Params vs Query Params

| 场景         | 推荐                  |
| ------------ | --------------------- |
| 资源身份     | Path Params           |
| 商品 ID      | `/products/:id`       |
| 店铺 ID      | `/shops/:shopId`      |
| 订单 ID      | `/orders/:orderId`    |
| 搜索关键词   | Query Params          |
| 筛选条件     | Query Params          |
| 排序、分页   | Query Params          |
| tab 展示状态 | Query Params 或子路径 |

例子：

```text
/products/123?tab=reviews
```

其中：

```text
123 是 path param，表示资源是谁；
tab=reviews 是 query param，表示怎么看。
```

---

一句话理解：

```text
Path Params 表达路径中的资源身份；
go_router 中用 :paramName 声明，
用 state.pathParameters 读取。
读取到的值始终是 String，需要自己转换成 int、enum 等业务类型。
```
