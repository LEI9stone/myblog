# Query Params vs Route Query Parameters

Web 里的 Query Params 是 URL `?` 后面的参数：

```text
/products?keyword=cup&page=2
```

Flutter 里如果使用 `go_router`，对应的是：

```dart
state.uri.queryParameters
```

可以这样映射：

| Web Query Params     | Flutter / go_router                    |
| -------------------- | -------------------------------------- |
| `?keyword=cup`       | `state.uri.queryParameters['keyword']` |
| `URLSearchParams`    | `Uri.queryParameters`                  |
| `useSearchParams()`  | `state.uri.queryParameters`            |
| `navigate('/x?a=1')` | `context.go('/x?a=1')`                 |
| query object         | `Uri(queryParameters: ...)`            |
| multi-value query    | `queryParametersAll`                   |
| optional query       | nullable String                        |
| parsing number/bool  | manual parse                           |

---

## 1. Web Query Params

Web：

```text
/search?keyword=cup&page=2
```

React Router：

```tsx
const [searchParams] = useSearchParams();

const keyword = searchParams.get('keyword');
const page = Number(searchParams.get('page') ?? 1);
```

---

## 2. go_router 读取 Query

Flutter：

```dart
GoRoute(
  path: '/search',
  builder: (context, state) {
    final keyword = state.uri.queryParameters['keyword'];
    final pageText = state.uri.queryParameters['page'];
    final page = int.tryParse(pageText ?? '') ?? 1;

    return SearchPage(
      keyword: keyword,
      page: page,
    );
  },
)
```

这里：

```dart
state.uri.queryParameters
```

类型是：

```dart
Map<String, String>
```

如果参数不存在，返回：

```dart
null
```

---

## 3. 跳转时带 Query

Web：

```ts
navigate('/search?keyword=cup&page=2');
```

Flutter：

```dart
context.go('/search?keyword=cup&page=2');
```

更推荐用 `Uri` 生成，避免手动拼接转义问题：

```dart
final uri = Uri(
  path: '/search',
  queryParameters: {
    'keyword': 'cup',
    'page': '2',
  },
);

context.go(uri.toString());
```

---

## 4. push / go 都可以带 Query

```dart
context.push('/products?category=hot');
```

```dart
context.go('/products?category=hot');
```

选择规则不变：

```text
push：压入新页面
go：切换到目标路径
```

---

## 5. 多值 Query

Web：

```text
/search?tag=a&tag=b
```

Dart：

```dart
final tags = state.uri.queryParametersAll['tag'] ?? [];
```

`queryParameters` 只适合单值：

```dart
final tag = state.uri.queryParameters['tag'];
```

多值要用：

```dart
queryParametersAll
```

---

## 6. 类型解析

Query 参数天然是字符串。

Web：

```ts
const page = Number(searchParams.get('page') ?? 1);
const inStock = searchParams.get('inStock') === 'true';
```

Flutter：

```dart
final page = int.tryParse(
      state.uri.queryParameters['page'] ?? '',
    ) ??
    1;

final inStock = state.uri.queryParameters['inStock'] == 'true';
```

建议把解析逻辑封装，避免散落在页面里。

---

## 7. 什么时候用 Query Params

适合放 query：

```text
搜索关键词
筛选条件
排序方式
分页页码
tab
临时展示模式
可分享的页面状态
```

不适合：

```text
敏感 token
大对象 JSON
复杂表单草稿
不希望暴露的内部状态
```

---

一句话理解：

```text
Web Query Params 是 URL ? 后面的键值参数；
go_router 中通过 state.uri.queryParameters 读取，
通过 Uri(queryParameters: ...) 生成。
Query 参数始终是字符串，需要自己解析成 int、bool、enum 等业务类型。
```
