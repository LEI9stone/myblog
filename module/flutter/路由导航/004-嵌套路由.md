# Nested Routes vs `ShellRoute` / Nested Navigation

Web 里的 Nested Routes 用来表达“父布局不变，子页面切换”，比如后台系统的侧边栏、账户中心、商品详情下的子 tab。

Flutter 里对应常见两种：

```dart
ShellRoute
StatefulShellRoute
Nested Navigator
```

可以这样映射：

| Web Nested Routes | Flutter                     |
| ----------------- | --------------------------- |
| parent route      | `ShellRoute`                |
| child route       | nested `GoRoute`            |
| layout route      | `ShellRoute.builder`        |
| `<Outlet />`      | `child` 参数                |
| nested navigation | nested `Navigator`          |
| tab route state   | `StatefulShellRoute`        |
| route branch      | `StatefulShellBranch`       |
| persistent shell  | MainScaffold / Shell Widget |

---

## 1. Web Nested Routes

React Router：

```tsx
<Route path="/account" element={<AccountLayout />}>
  <Route path="profile" element={<ProfilePage />} />
  <Route path="orders" element={<OrdersPage />} />
</Route>
```

`AccountLayout` 中：

```tsx
<Sidebar />
<Outlet />
```

核心是：

```text
父级 layout 保持不变；
子 route 渲染到 Outlet。
```

---

## 2. go_router ShellRoute

Flutter：

```dart
ShellRoute(
  builder: (context, state, child) {
    return AccountScaffold(
      child: child,
    );
  },
  routes: [
    GoRoute(
      path: '/account/profile',
      builder: (context, state) => const ProfilePage(),
    ),
    GoRoute(
      path: '/account/orders',
      builder: (context, state) => const OrdersPage(),
    ),
  ],
)
```

这里的：

```dart
child
```

就类似 React Router 的：

```tsx
<Outlet />
```

---

## 3. App 主框架：底部 Tab

很多 Flutter App 会有：

```text
首页
分类
订单
我的
```

这些页面共享底部导航栏。

Web 中可能是 layout route：

```tsx
<Route element={<MainLayout />}>
  <Route path="/" element={<Home />} />
  <Route path="/orders" element={<Orders />} />
</Route>
```

Flutter：

```dart
ShellRoute(
  builder: (context, state, child) {
    return MainScaffold(child: child);
  },
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const HomePage(),
    ),
    GoRoute(
      path: '/orders',
      builder: (context, state) => const OrdersPage(),
    ),
  ],
)
```

---

## 4. StatefulShellRoute

如果每个 Tab 都需要保留自己的导航栈，比如：

```text
首页 tab 内进入商品详情
订单 tab 内进入订单详情
切换 tab 后返回原来的位置
```

更适合：

```dart
StatefulShellRoute
```

概念上类似：

```text
每个 tab 有自己的 nested navigator。
```

示意：

```dart
StatefulShellRoute.indexedStack(
  builder: (context, state, navigationShell) {
    return MainScaffold(
      navigationShell: navigationShell,
    );
  },
  branches: [
    StatefulShellBranch(
      routes: [
        GoRoute(
          path: '/',
          builder: (context, state) => const HomePage(),
        ),
      ],
    ),
    StatefulShellBranch(
      routes: [
        GoRoute(
          path: '/orders',
          builder: (context, state) => const OrdersPage(),
        ),
      ],
    ),
  ],
)
```

---

## 5. ShellRoute vs StatefulShellRoute

| 场景                       | 推荐                 |
| -------------------------- | -------------------- |
| 只需要共享外壳             | `ShellRoute`         |
| 子页面切换不需要保存独立栈 | `ShellRoute`         |
| 底部 Tab 各自保留历史      | `StatefulShellRoute` |
| 每个分支有独立 Navigator   | `StatefulShellRoute` |
| 简单嵌套路由               | nested `GoRoute`     |

---

## 6. Nested Navigator

有些复杂场景会手动放一个 `Navigator`：

```dart
Navigator(
  key: nestedNavigatorKey,
  onGenerateRoute: ...,
)
```

适合：

```text
复杂 tab 内导航
局部流程导航
嵌入式 wizard
独立模块导航
```

但如果已经使用 `go_router`，优先考虑 `ShellRoute` / `StatefulShellRoute`，不要过早手写 nested navigator。

---

## 7. 路由组织心智

Web：

```text
Layout Route
  Outlet
    Child Route
```

Flutter：

```text
ShellRoute
  child
    GoRoute page
```

Bottom tab 多栈：

```text
StatefulShellRoute
  Branch 1 Navigator
  Branch 2 Navigator
  Branch 3 Navigator
```

一句话理解：

```text
Web Nested Routes 用父 route + Outlet 复用布局；
Flutter go_router 中用 ShellRoute + child 复用页面外壳，
需要每个 tab 保留独立导航栈时用 StatefulShellRoute / Nested Navigator。
```
