# Browser URL vs Flutter Route

Web 里页面位置主要由 Browser URL 表达：

```text
https://example.com/products/123?tab=reviews
```

Flutter 里页面位置由 Route 表达，常见实现是：

```dart
Navigator
go_router
Route
Page
```

如果是 Flutter Web，也可以把 Route 同步到浏览器 URL。

可以这样映射：

| Web Browser URL    | Flutter Route                              |
| ------------------ | ------------------------------------------ |
| URL path           | route path                                 |
| query string       | query parameters                           |
| hash               | fragment / 特定路由策略                    |
| browser history    | Navigator stack                            |
| `pushState`        | `context.push` / `Navigator.push`          |
| `replaceState`     | `context.go` / `Navigator.pushReplacement` |
| back button        | `Navigator.pop` / system back              |
| deep link          | route parsing                              |
| React Router route | go_router route                            |
| page component     | page Widget                                |

---

## 1. Web Browser URL

Web：

```text
/products/123?tab=reviews
```

通常包含：

```text
path: /products/123
path param: 123
query: tab=reviews
```

React Router：

```tsx
<Route path="/products/:id" element={<ProductDetail />} />
```

读取：

```ts
const { id } = useParams();
const [searchParams] = useSearchParams();
```

---

## 2. Flutter Route

Flutter 原生：

```dart
Navigator.of(context).push(
  MaterialPageRoute(
    builder: (context) => ProductDetailPage(productId: '123'),
  ),
);
```

这里重点不是 URL，而是：

```text
把一个 Route 推入 Navigator stack。
```

移动端 App 中，页面栈比 URL 更核心。

---

## 3. go_router 路径式路由

如果用 `go_router`，Flutter 写法就更接近 Web Router：

```dart
GoRoute(
  path: '/products/:id',
  builder: (context, state) {
    final id = state.pathParameters['id']!;
    final tab = state.uri.queryParameters['tab'];

    return ProductDetailPage(
      productId: id,
      initialTab: tab,
    );
  },
)
```

跳转：

```dart
context.push('/products/123?tab=reviews');
```

这很接近：

```text
React Router navigate('/products/123?tab=reviews')
```

---

## 4. push vs go

Web：

```ts
navigate('/products/123');
```

有时是 push，有时是 replace。

go_router：

```dart
context.push('/products/123');
```

表示压入新页面，类似 browser history push。

```dart
context.go('/products/123');
```

表示切换当前位置，常用于主导航 tab 或根页面切换。

粗略映射：

| Web                    | go_router                   |
| ---------------------- | --------------------------- |
| `history.pushState`    | `context.push`              |
| `history.replaceState` | `context.go` / `replace`    |
| browser back           | `context.pop` / system back |

---

## 5. Navigator Stack vs Browser History

Web：

```text
浏览器 history stack
```

Flutter：

```text
Navigator route stack
```

例如：

```text
HomePage
  → ProductListPage
    → ProductDetailPage
```

按返回：

```text
ProductDetailPage pop
回到 ProductListPage
```

移动端返回键也会触发 route pop。

---

## 6. Deep Link

Web URL 天然支持直接访问：

```text
/products/123
```

Flutter App 如果要支持从外部打开：

```text
rouzao://products/123
https://example.com/products/123
```

需要配置：

```text
Android App Links
iOS Universal Links
go_router route parsing
```

对应 Web 的 deep link 心智。

---

## 7. 关键差异

Web：

```text
URL 是页面状态的核心来源；
刷新页面会重新从 URL 进入应用。
```

Flutter mobile：

```text
Route stack 是页面导航的核心；
URL 不一定存在；
App 可能从 cold start、push notification、deep link、内部导航进入页面。
```

Flutter Web：

```text
Route 可以映射到浏览器 URL。
```

一句话理解：

```text
Browser URL 是 Web 应用的页面地址和历史记录载体；
Flutter Route 是 App 内页面栈中的一个页面。
在 Flutter mobile 中重点是 Navigator stack，
在 Flutter Web 或 go_router 中才更接近 Web URL 路由心智。
```
