# React Router vs `go_router`

React Router 是 React 生态常用的路由库。

`go_router` 是 Flutter 生态常用的声明式路由库，基于 Flutter `Navigator`，提供路径路由、嵌套路由、重定向、参数解析、ShellRoute 等能力。

可以这样映射：

| React Router           | go_router                            |
| ---------------------- | ------------------------------------ |
| `<BrowserRouter>`      | `MaterialApp.router`                 |
| `<Routes>`             | `GoRouter(routes: [...])`            |
| `<Route path element>` | `GoRoute(path, builder/pageBuilder)` |
| `useNavigate()`        | `context.go` / `context.push`        |
| `useParams()`          | `state.pathParameters`               |
| `useSearchParams()`    | `state.uri.queryParameters`          |
| nested routes          | nested `routes`                      |
| layout route           | `ShellRoute`                         |
| redirect               | `redirect`                           |
| route guard            | `redirect` + auth provider           |
| not found route        | errorBuilder / fallback route        |

---

## 1. React Router 基本结构

React：

```tsx
<BrowserRouter>
  <Routes>
    <Route path="/" element={<HomePage />} />
    <Route path="/products/:id" element={<ProductDetailPage />} />
  </Routes>
</BrowserRouter>
```

跳转：

```tsx
navigate('/products/123');
```

---

## 2. go_router 基本结构

Flutter：

```dart
final router = GoRouter(
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const HomePage(),
    ),
    GoRoute(
      path: '/products/:id',
      builder: (context, state) {
        final id = state.pathParameters['id']!;

        return ProductDetailPage(productId: id);
      },
    ),
  ],
);
```

接入 App：

```dart
MaterialApp.router(
  routerConfig: router,
)
```

跳转：

```dart
context.push('/products/123');
```

或：

```dart
context.go('/products/123');
```

---

## 3. `go` vs `push`

React Router 里：

```ts
navigate('/products/123');
```

通常对应 history push。

go_router 里要区分：

```dart
context.push('/products/123');
context.go('/products/123');
```

| go_router | 含义                             |
| --------- | -------------------------------- |
| `push`    | 压入一个新页面，可返回           |
| `go`      | 切换到目标路径，通常替换当前分支 |
| `pop`     | 返回上一页                       |
| `replace` | 替换当前 route                   |

简单理解：

```text
详情页跳转通常 push；
底部 tab/主页面切换通常 go。
```

---

## 4. 路由参数

React Router：

```tsx
const { id } = useParams();
```

go_router：

```dart
final id = state.pathParameters['id']!;
```

Query 参数：

React：

```tsx
const [params] = useSearchParams();
const tab = params.get('tab');
```

Flutter：

```dart
final tab = state.uri.queryParameters['tab'];
```

---

## 5. 嵌套路由

React：

```tsx
<Route path="/account" element={<AccountLayout />}>
  <Route path="profile" element={<ProfilePage />} />
  <Route path="orders" element={<OrdersPage />} />
</Route>
```

go_router：

```dart
GoRoute(
  path: '/account',
  builder: (context, state) => const AccountPage(),
  routes: [
    GoRoute(
      path: 'profile',
      builder: (context, state) => const ProfilePage(),
    ),
    GoRoute(
      path: 'orders',
      builder: (context, state) => const OrdersPage(),
    ),
  ],
)
```

---

## 6. Layout Route vs ShellRoute

React Router layout route：

```tsx
<Route element={<MainLayout />}>
  <Route path="/" element={<HomePage />} />
  <Route path="/orders" element={<OrdersPage />} />
</Route>
```

go_router：

```dart
ShellRoute(
  builder: (context, state, child) {
    return MainScaffold(child: child);
  },
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const HomePage(),
    ),
    GoRoute(
      path: '/orders',
      builder: (context, state) => const OrdersPage(),
    ),
  ],
)
```

`ShellRoute` 适合：

```text
底部 Tab
侧边栏布局
主框架复用
页面外壳固定，内部内容切换
```

## 7. Redirect / Guard

React Router 中可能写：

```tsx
if (!user) return <Navigate to="/login" />;
```

go_router：

```dart
GoRouter(
  redirect: (context, state) {
    final loggedIn = authState.loggedIn;
    final loggingIn = state.uri.path == '/login';

    if (!loggedIn && !loggingIn) {
      return '/login';
    }

    if (loggedIn && loggingIn) {
      return '/';
    }

    return null;
  },
  routes: [...],
)
```

如果认证状态来自 Riverpod，通常会把 router 也做成 provider。

---

## 8. pageBuilder vs builder

简单页面：

```dart
builder: (context, state) => const HomePage()
```

需要自定义转场、key、页面类型：

```dart
pageBuilder: (context, state) {
  return CustomTransitionPage(
    key: state.pageKey,
    child: const HomePage(),
    transitionsBuilder: ...,
  );
}
```

---

一句话理解：

```text
React Router 管理 React Web 的 URL 和页面组件；
go_router 管理 Flutter 的路径路由和 Navigator 页面栈。
两者心智很接近：
Route 配 path，页面读 params/query，跳转用 navigate/context.go/push，
布局路由在 Flutter 中主要对应 ShellRoute。
```
