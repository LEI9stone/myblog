# Page Component vs Screen/Page Widget

Web 里 Page Component 通常指被路由直接挂载的页面组件，例如：

```text
HomePage
ProductListPage
ProductDetailPage
```

Flutter 里对应的是 Screen / Page Widget，通常也是被路由直接返回的顶层页面 Widget。

可以这样映射：

| Web Page Component    | Flutter Screen/Page Widget           |
| --------------------- | ------------------------------------ |
| `HomePage.tsx`        | `home_page.dart`                     |
| `ProductListPage.tsx` | `product_list_page.dart`             |
| route element         | GoRoute builder 返回的 Widget        |
| page component        | Page / Screen Widget                 |
| layout component      | Scaffold / ShellRoute / MainScaffold |
| page-level state      | page provider / StatefulWidget       |
| page effects          | provider/notifier/lifecycle          |
| SEO metadata          | mobile 中无直接等价，Web 可单独处理  |
| document title        | route/page title / AppBar title      |

---

## 1. Web Page Component

React Router：

```tsx
<Route path="/products" element={<ProductListPage />} />
```

页面组件：

```tsx
function ProductListPage() {
  return (
    <MainLayout>
      <ProductList />
    </MainLayout>
  );
}
```

Page Component 通常负责：

```text
读取路由参数
请求页面数据
组织页面布局
组合业务组件
处理页面级状态
```

---

## 2. Flutter Page Widget

go_router：

```dart
GoRoute(
  path: '/products',
  builder: (context, state) {
    return const ProductListPage();
  },
)
```

页面 Widget：

```dart
class ProductListPage extends StatelessWidget {
  const ProductListPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Products')),
      body: const ProductListView(),
    );
  }
}
```

Flutter Page Widget 通常负责：

```text
页面 Scaffold
AppBar / body / bottomNavigationBar
读取 Provider 状态
组合 feature widgets
处理页面级交互
```

---

## 3. Page vs Widget 没有硬边界

Flutter 中 Page 本质上也是 Widget。

区别只是角色不同：

| 类型                 | 角色                    |
| -------------------- | ----------------------- |
| Page / Screen Widget | 被路由直接打开          |
| Feature Widget       | 页面内部业务模块        |
| Core Widget          | 跨业务复用组件          |
| Layout Widget        | Row/Column/Stack 等布局 |
| App Shell            | 全局页面框架            |

也就是说：

```text
Page 是一种特殊角色的 Widget，不是不同技术类型。
```

---

## 4. Scaffold 类似页面外壳

Web：

```tsx
<MainLayout>
  <ProductListPage />
</MainLayout>
```

Flutter：

```dart
Scaffold(
  appBar: AppBar(...),
  body: ProductListView(),
)
```

如果多个页面共享底部 Tab 或导航框架，通常用：

```dart
ShellRoute
MainScaffold
```

而不是每个页面重复写完整外壳。

---

## 5. Page-level State

Web：

```tsx
function ProductListPage() {
  const { data, loading } = useProducts();
}
```

Flutter + Riverpod：

```dart
class ProductListPage extends ConsumerWidget {
  const ProductListPage({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final products = ref.watch(productsProvider);

    return products.when(
      loading: () => const LoadingView(),
      error: (error, stack) => ErrorView(error: error),
      data: (items) => ProductList(items: items),
    );
  }
}
```

页面级状态也可以由：

```text
StatefulWidget
Provider
AsyncNotifier
Controller
```

承担。

---

## 6. 命名习惯

Web：

```text
ProductListPage.tsx
ProductDetailPage.tsx
```

Flutter：

```text
product_list_page.dart
product_detail_page.dart
```

类名：

```dart
ProductListPage
ProductDetailPage
```

有些团队用：

```text
Screen
Page
View
```

建议统一：

| 命名     | 常见含义             |
| -------- | -------------------- |
| `Page`   | route 直接打开的页面 |
| `Screen` | 更偏移动端整屏页面   |
| `View`   | 页面内部某个视图区域 |

---

一句话理解：

```text
Web Page Component 是路由直接渲染的页面组件；
Flutter Screen/Page Widget 是路由直接打开的页面 Widget。
它们都负责组织页面结构、读取路由/状态，并组合更小的业务组件。
```
