# Navigation Guard vs Redirect / Auth Guard

Web 里的 Navigation Guard 通常用于控制路由是否允许进入，比如未登录跳登录页、无权限跳错误页、已登录用户不能再进登录页。

Flutter `go_router` 中对应的是：

```dart
redirect
```

配合认证状态、权限状态或 Riverpod provider 实现 Auth Guard。

可以这样映射：

| Web Navigation Guard | Flutter / go_router        |
| -------------------- | -------------------------- |
| route guard          | `redirect`                 |
| auth guard           | auth state + `redirect`    |
| beforeEnter          | route-level `redirect`     |
| global guard         | GoRouter-level `redirect`  |
| protected route      | redirect to login          |
| guest-only route     | logged-in redirect to home |
| permission guard     | role/permission check      |
| loading auth state   | splash/loading route       |
| returnUrl            | query parameter            |

---

## 1. Web Navigation Guard

React Router 中常见：

```tsx
function ProtectedRoute({ children }) {
  const user = useAuth();

  if (!user) {
    return <Navigate to="/login" />;
  }

  return children;
}
```

Vue Router 中常见：

```ts
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !isLoggedIn) {
    return '/login';
  }
});
```

核心是：

```text
路由切换前检查状态；
不满足条件就重定向。
```

## 2. go_router redirect

Flutter：

```dart
final router = GoRouter(
  redirect: (context, state) {
    final loggedIn = authState.loggedIn;
    final loggingIn = state.uri.path == '/login';

    if (!loggedIn && !loggingIn) {
      return '/login';
    }

    if (loggedIn && loggingIn) {
      return '/';
    }

    return null;
  },
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const HomePage(),
    ),
    GoRoute(
      path: '/login',
      builder: (context, state) => const LoginPage(),
    ),
  ],
);
```

返回值含义：

| 返回值     | 含义                   |
| ---------- | ---------------------- |
| `null`     | 允许继续进入当前 route |
| `'/login'` | 重定向到 `/login`      |
| 其他路径   | 重定向到指定路径       |

## 3. Auth Guard

常见规则：

```text
未登录访问受保护页面 → 跳登录
已登录访问登录页 → 跳首页
认证状态未恢复 → 停在启动页/加载页
```

示例：

```dart
redirect: (context, state) {
  final path = state.uri.path;
  final loggedIn = authState.loggedIn;
  final checkingAuth = authState.isLoading;

  final isLogin = path == '/login';
  final isSplash = path == '/splash';

  if (checkingAuth) {
    return isSplash ? null : '/splash';
  }

  if (!loggedIn) {
    return isLogin ? null : '/login';
  }

  if (loggedIn && isLogin) {
    return '/';
  }

  return null;
}
```

## 4. 保留 returnUrl

Web 中常见：

```text
/login?redirect=/orders/123
```

Flutter 也可以这样做：

```dart
redirect: (context, state) {
  final loggedIn = authState.loggedIn;
  final path = state.uri.toString();

  if (!loggedIn && state.uri.path != '/login') {
    final loginUri = Uri(
      path: '/login',
      queryParameters: {
        'redirect': path,
      },
    );

    return loginUri.toString();
  }

  return null;
}
```

登录成功后：

```dart
final redirect = state.uri.queryParameters['redirect'] ?? '/';
context.go(redirect);
```

## 5. Route-level redirect

有些检查只属于某个 route，可以写在 `GoRoute` 上：

```dart
GoRoute(
  path: '/admin',
  redirect: (context, state) {
    if (!authState.isAdmin) {
      return '/403';
    }

    return null;
  },
  builder: (context, state) => const AdminPage(),
)
```

全局规则放 `GoRouter.redirect`，局部权限放 route-level `redirect`。

## 6. 和 Riverpod 配合

如果认证状态来自 Riverpod，通常会把 router 也做成 provider：

```dart
final routerProvider = Provider<GoRouter>((ref) {
  final authState = ref.watch(authProvider);

  return GoRouter(
    redirect: (context, state) {
      final loggedIn = authState.loggedIn;

      if (!loggedIn && state.uri.path != '/login') {
        return '/login';
      }

      return null;
    },
    routes: [...],
  );
});
```

然后：

```dart
final router = ref.watch(routerProvider);

return MaterialApp.router(
  routerConfig: router,
);
```

## 7. 常见 Guard 类型

| Guard 类型         | 示例                      |
| ------------------ | ------------------------- |
| Auth Guard         | 未登录不能进订单页        |
| Guest Guard        | 已登录不能进登录页        |
| Role Guard         | 非管理员不能进后台        |
| Onboarding Guard   | 未完成引导先去 onboarding |
| Feature Flag Guard | 功能未开启跳 404/提示页   |
| Auth Loading Guard | token 恢复中停在 splash   |

一句话理解：

```text
Web Navigation Guard 是路由进入前的拦截逻辑；
go_router 中主要用 redirect 实现。
Auth Guard 通常读取登录状态，
未登录跳 login，
已登录跳目标页，
权限不足跳 403 或 fallback route。
```
